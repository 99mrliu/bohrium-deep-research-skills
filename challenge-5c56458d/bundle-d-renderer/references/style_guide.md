# 科研图渲染规范（style guide）v1

`render_chart.py` 的 rcParams 即按本规范硬编码；任何偏离必须在
figure.json 中声明理由。

## 必须

- 分辨率 ≥200 dpi；物理尺寸单栏约 6.4×4.0 in。
- 坐标轴标签 = 字段名（单位）；单位来自数据字典/口径声明，缺单位的图
  不得交付。
- 条形图 y 轴从零开始；箱线图显示离群点。
- 图注（figure_caption.py 生成）必须含：图型、来源表/查询、n、单位、
  库 sha256（可得时）、注意事项。
- 无头渲染（Agg）；同输入必得同图——不使用随机样式、不在图内嵌时间戳。

## 禁止

- 3D 效果、阴影、渐变填充、无意义配色（chartjunk）。
- 双 y 轴（口径易误读；确需时拆两图）。
- 手工截图代替脚本渲染；图必须可由 figure.json 重新生成。
- 在图中标注未经复算/未注明来源的数字。

## 色板

默认 `#4C72B0`（蓝），强调/中位线 `#C44E52`（红）；分组图用 matplotlib
默认分类色环。色盲安全优先：不依赖红绿对比。
