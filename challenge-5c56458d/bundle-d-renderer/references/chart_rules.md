# 图表选择规则（chart selection rules）

每条规则有编号；`chart_select.py` 的推荐必须记录命中的规则号，便于复核
与否决。

| 规则 | 情形 | 选择 | 理由 |
|-|-|-|-|
| R1 | 1 个类别维度（≤25 水平）× 1 个聚合数值 | 条形图（y 轴从零开始） | 类别间量级比较；条形长度与数值成正比，截断轴会夸大差异 |
| R2 | 单个数值列的分布问题 | 直方图（箱线图作补充） | 分布形态、离群、偏态一目了然；条形图不能表达分布 |
| R3 | 两个数值变量、问关系/相关 | 散点图 | 展示逐点关系与离群；相关结论须另附统计量 |
| R4 | 有序 x（时间、龄期、剂量）× 数值 | 折线图 | 顺序连接表达趋势；类别无序时禁止折线 |
| R5 | 2 个类别维度 × 聚合数值 | 分组条形图 | 双维度比较；超过 3 个维度改用小倍数或表格 |
| R6 | 类别 >25 水平 / 无规则命中 | 格式化表格 | 过密图形不可读；表格保留精度 |

## 否决与例外

- 任务或期刊明确指定图型时从其指定，但图注中仍写明数据口径。
- 对数轴仅在跨数量级数据且图注明确标注时使用。
- 饼图默认不使用（比例用堆叠条或表格）；任务指定除外。
