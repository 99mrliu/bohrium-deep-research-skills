# 运行治理协议

## 哈希口径

- 文件哈希：SHA-256，原始字节。
- 阶段产物哈希：对产物对象先剔除易变字段（`ts`、`generated_at`、`frozen_at`、`timestamp`），再按 `sort_keys=True` 序列化为规范 JSON 后取 SHA-256。这使复跑比对不受时间戳影响，又能捕捉任何数据漂移。

## 复跑纪律

1. 交付前必须执行一次 `--replay`；`replay_verdict.json` 随 result.json 一并交付。
2. 漂移 = 任一阶段哈希不一致。处理顺序：先比对输入文件哈希（输入变了 → 不是漂移，是新材料，需重跑主流程）；输入一致而阶段漂移 → 代码或环境非确定，必须查明后再交付。
3. 禁止为了让复跑通过而删除或改写既有产物；修正后从主流程重跑。

## 独立复核抽检

- 抽样：确定性步长抽样（每第 3 条），不掺随机数，保证复跑抽到同一批。
- 复核实现必须与主管线**算法不同**（本技能：包含率 vs Jaccard），否则复核失去意义。
- 一致率 < 1.0 时：分歧记录全部列出并转人工；主管线状态保留但在 uncertainty 中逐条声明。禁止用复核结果静默覆盖主管线，也禁止不报告分歧。

## 证据绑定

- 报告中的关键数字（分母、命中、漏检、覆盖率、抽检量、一致率）必须携带绑定号；
- 绑定号 → 账本 JSON 路径的映射写入 binding_map.json；路径必须真实存在于对应账本文件；
- 审稿人复核一个数字最多需要两次文件打开：binding_map.json + 对应账本。

## 已知边界

- 规范 JSON 剔除时间戳意味着"同一输入不同时间运行"视为一致——这是有意设计；输入或逻辑的实质变化仍会被捕获。
- SVG 为文本渲染，供快速目检；正式图形可在运行时环境用 matplotlib 重绘，运行产物不受技能文本约束。
