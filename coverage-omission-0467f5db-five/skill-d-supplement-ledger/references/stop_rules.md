# 停止规则与残余遗漏估计方法

## 查询账本口径

- **边际收益**（marginal_yield）：该查询为参考集**首次**挽回的文献数。一条记录被多个查询命中时，只记在按（轮次, 顺序）排序后首个命中它的查询上。
- **零收益轮**：一轮内所有查询 marginal_yield = 0。零收益轮是"补检空转"的直接证据，必须原样呈现，禁止润色为"巩固了结果"。

## 停止规则

| 规则 | 触发条件 | 证据 |
|---|---|---|
| S1 zero_gain_round | 最新一轮全部查询零新挽回，且总轮数 ≥2 | 该轮全部账本行号 |
| S2 low_marginal_yield | 最近两轮平均每查询边际收益 < 0.5 | 最近两轮全部账本行号 |
| S3 budget_exhausted | 案例材料声明的查询预算已耗尽 | 预算字段引用；无预算字段时声明"不可评估" |

建议停止 = 任一规则触发。继续补检时必须说明：下一轮要检验哪个漏检类别、预期新查询与已有查询的实质差异是什么——写不出实质差异就不该继续。

## 残余遗漏估计（捕获-再捕获）

把两个不同来源的查询族视为两次独立捕获：

- $n_1$：族 A 挽回的参考集记录数；$n_2$：族 B 挽回数；$m$：两族都挽回数；
- Chapman 校正估计：$\hat N = \frac{(n_1+1)(n_2+1)}{m+1} - 1$；
- 残余遗漏估计：$\hat N - |A \cup B|$（下界截断为 0）。

**假设（必须随结果一并报告）**：

1. 族内等可捕获性——实际上主题异质性会违反此假设；
2. 两族独立——实际上两个来源共享检索偏差时估计偏低；
3. 封闭总体——以冻结参考集为总体，不外推到"全世界相关文献"。

**使用纪律**：该估计用于说明"残余遗漏的大致规模"，与逐条漏检清单并列报告；它是下界启发式，不得用作"遗漏已清零"的证明，也不得在单一来源时计算。
