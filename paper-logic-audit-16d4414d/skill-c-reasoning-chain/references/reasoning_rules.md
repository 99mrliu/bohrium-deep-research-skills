# R1–R4 推理链候选规则与判据

## 设计—措辞对齐矩阵（R1 的判定底表）

| 设计 \ 措辞 | 相关/关联 | 提示/可能 | 表明/显示 | 导致/决定/驱动 |
|-|-|-|-|-|
| 随机对照 / 干预实验 | 保守 | 可 | 可 | 可（限干预指标） |
| 准实验 / 前后对照 | 可 | 可 | 谨慎 | 不可 |
| 观察性 / 横断面 / 回顾 | 可 | 可 | 谨慎（限描述） | 不可 |
| 相关性分析 | 可 | 可 | 不可 | 不可 |

"不可"格出现的措辞即 R1 成立候选；定案时把矩阵单元写进 basis。

## R1 因果超出设计

定义：设计线索为观察性/横断面/回顾/相关性且无随机化线索，而摘要、讨论或
结论用因果动词。误报边界：因果句若是转述（带引用标记）或作者自注假设，
不按 R1 计；可单独立引用支持待复核条。

## R2 前提未交付（推理跳跃）

定义：讨论/结论句的关键词 ≥70% 在结果章零覆盖。这是机械近似，三种典型
误报必须人工排除：
1. 前提以图为载体（图标题句无正文关键词）→ 目检图后驳回；
2. 前提是定性结果（无数值、关键词不同表述）→ 回结果章通读；
3. 讨论句是文献对比而非本文结果延伸 → 驳回并记理由。
定案标准：在结果章确实找不到任何支撑该句对象的前提句。

## R3 替代解释未讨论

论文级候选。成立条件：讨论章没有任何段落讨论局限、混杂或替代解释。
注意：作者写"我们没有讨论 X"本身就是披露，不算未讨论——此时降级为
info 建议"补替代解释分析"。

## R4 小样本全称结论

定义：检出样本量 n≤5，结论位使用全称表述（所有/任何/均/all/every）。
成立条件：全称结论直接由该小样本支撑且适用范围未限缩。
误报边界：n 来自预实验而主结论由大样本支撑 → 驳回。

## 两端锚定规范

每条推理 finding：
- conclusion_sentence_id：结论句（quote 取该句逐字子串）；
- premise_sentence_ids：支撑或应当支撑该结论的前提句；前提缺席时留空
  数组并在 basis 写明"结果章无对应前提"；
- basis 必须指出断裂发生在哪一环：前提缺失 / 前提→结论强度跳跃 /
  设计→措辞越界 / 替代解释未排除。

## 严重度判据

| 级 | 判据（满足其一） |
|-|-|
| critical | 摘要/结论核心句 R1 或 R2 成立，主结论随之不成立 |
| major | 关键中间结论 R1/R2 成立；R3 成立且设计有明显混杂源 |
| minor | R4 成立；非结论位措辞越界 |
| info | 推理链可加强的建议（补敏感性分析、补替代解释讨论） |
