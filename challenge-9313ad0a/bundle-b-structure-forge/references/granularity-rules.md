# 粒度规则与自动修复边界

本文件给出思维导图层级结构的粒度准则（深度、扇出、标签长度、近似重复判据），
并明确 `tree_rebalance.py` 自动修复的权限边界。

## 1. 深度：2–5 层为宜

- 深度自根节点起算，根为第 1 层；建议导图深度保持在 2–5 层。
- 深度 < 2：导图退化为平铺列表，未利用层级结构。
- 深度 > 5：读者难以追踪路径，通常意味着中间层缺失（应提升概括层）或粒度过细
  （应合并叶子）。`tree_lint.py` 的 `depth` 检查对深度超过 5 的节点发出 WARN。
- 常见修正：为同层细节节点插入一层概括节点，或将过细叶子并入其父节点标签。

## 2. 扇出：兄弟节点不超过 7

- 同一父节点的子节点数以 3–7 为宜；超过 7 视为分支过载（`overloaded`，WARN）。
- 拆分策略（`split_overloaded` 自动执行）：
  1. 按 `kind` 将子节点分组；
  2. 为每组插入中间分组节点，标签为“<kind>类”，id 为
     `<parentid>-grp-<kind>`（按 kind 字典序排列）；
  3. 单一 kind 组内仍超过 7 个时，按每 7 个一段分块（id 追加 `-1`、`-2`…）；
  4. 若分组数本身超过 7，保留最大的 6 组，其余并入“other类”。
- 拆分为机械操作，分组轴是否恰当须人工复核；kind 标注混乱时应先修正标注。

## 3. 标签长度：不超过 40 显示字符

- 标签应是名词性短语或短句，而非完整段落；显示长度按每字符 1 计（中日韩全角
  字符同样按 1 计），上限 40。
- 超长标签由 `truncate_label` 自动截断为前 39 字符加“…”（总长 40），原文记
  录于 `changes.jsonl`；建议随后人工改写为精炼标签，而非依赖截断。

## 4. 单子链

- 逐级仅有一个子节点、长度不少于 3 的链属于冗余嵌套（`single_child_chain`，
  WARN）。
- `collapse_chain` 自动折叠：恰有一个子节点**且无兄弟节点**的节点并入其子节
  点（保留子节点及其标签），迭代至不动点；被移除节点的原始 label/kind 记录于
  变更行。

## 5. 近似重复判据

- 规范化：标签转小写，删除全部空白与 Unicode 标点（P 类）。
- 判定（`sibling_near_duplicate`，WARN，仅限兄弟节点之间）：
  1. 规范化后字符串完全相等；或
  2. 一方包含另一方且较短者与较长者的长度比 > 0.8。
- 自动合并（`merge_duplicate`）仅适用于情形 1（规范化完全相等）：保留 id 字典
  序最小者，其余节点的子节点改挂至保留节点；**绝不跨父节点合并**。情形 2 仅
  报告，由人工裁决。
- 语义同义（如“合成方法”与“制备路线”）不在识别范围内。

## 6. 自动修复的权限边界

`tree_rebalance.py` 只做**结构性**操作，固定顺序为
`merge_duplicate → collapse_chain → split_overloaded → truncate_label`，全程
确定、可审计（每次操作一行 JSONL）。它**不会**：

- 修复多根、环、孤儿节点或 parent 引用缺失——此类错误涉及语义归属，仅由
  `tree_lint.py` 报告，须人工裁决；
- 新增实质内容节点（分组节点仅为结构容器）；
- 改写标签语义（仅截断，且保留原文于变更记录）；
- 跨父节点合并重复标签；
- 静默丢弃任何节点的 label/kind 信息（一律记录在 `changes.jsonl`）。

幂等性：对已符合规则的导图再运行再平衡，输出与输入逐字节一致，变更记录为空文
件。该性质可用于验证流水线确定性。
