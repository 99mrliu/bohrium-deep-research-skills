# 确定性预览布局契约

本契约规定 `render_preview.py` 的布局算法、画布规则、字体策略与可读性底线。任何修改必须保持「同一输入 → 同一版面」的确定性。

## 布局算法

1. **子节点顺序**：所有节点的子列表按节点 `id` 字典序排列；该顺序同时决定深度优先遍历次序。
2. **纵向坐标（y）**：深度优先遍历，叶节点依次取得整数坐标 0, 1, 2, …；内部节点 y = 其全部子节点 y 的算术平均，即垂直居中于直接子树。
3. **横向坐标（x）**：`x = depth × spacing`，`depth` 为到根的层数；`spacing = max(3.0, 0.32 × 全局最长标签字符数 + 2.0)`。
4. **连接线**：父子之间绘制肘形（elbow）折线——自父节点水平出线至中点 x，垂直转接至子节点高度，再水平入子节点；灰色实线，置于文本下层。
5. **节点**：文本居中绘制于节点坐标，圆角底色框（根节点暖色、其余冷色），zorder 高于连线。

## 画布尺寸规则

- `width_in = max(8.0, (最大深度 + 1) × spacing × 0.55 + 3.0)`；
- `height_in = max(5.0, (叶节点数 + 1) × 0.95 + 1.5)`；
- PNG 以 dpi=150 输出，画布像素尺寸 = 英寸 × 150，记录于 `render_manifest.json` 的 `canvas` 字段；
- 坐标轴范围四周留白（x 方向 0.75 × spacing，y 方向 1.2），防止边缘节点底框被裁剪。

## 字体发现顺序

依次在 matplotlib `font_manager` 已注册字体中查找，取首个命中者：

1. Noto Sans CJK SC
2. Noto Sans CJK JP
3. PingFang SC
4. Hiragino Sans GB
5. WenQuanYi Zen Hei
6. SimHei
7. Microsoft YaHei
8. Arial Unicode MS

命中后写入 `rcParams["font.sans-serif"]`（后随 DejaVu Sans 兜底），并设 `axes.unicode_minus=False`。全部未命中时仍渲染，`render_manifest.json` 中 `font.chosen=null`、`font.fallback=true`，交付说明须声明中文可能显示为缺字框。选中的字体名称必须记录于 manifest。

## 关系弧线样式

- 红色（#cc2222）虚线弧线，`arc3` 连接样式，带箭头；
- 弧度按确定性规则自适应：按 `(0.3, 0.55, 0.8, 1.05) × (正, 负)` 的固定顺序枚举曲率与凸向，对弧线采样点计算到非端点节点椭圆包围盒的最小净距，取首个净距 ≥ 0.3 的候选；均不满足时取净距最大者；
- 关系类型文本置于弧线顶点沿凸向稍外侧，白底、zorder 高于节点底框，保证不被遮挡；
- 全部计算仅依赖输入图结构与固定常数，无随机性。

## 可读性底线（强制）

预览图必须通过人工目视检查方可交付：

- 节点文本不得相互重叠、不得被关系线或关系标注压字；
- 节点与标签不得被画布边缘裁剪；
- CJK 字符不得出现缺字（豆腐块）——出现时检查 manifest 的 `font` 字段并按字体缺失流程处理；
- 发现任何不可读情况，必须通过重平衡标签（缩短、拆分）或重构树（折叠、分图）修复后重跑；**禁止静默交付不可读预览**。

## 确定性说明

文本类输出（`.mm/.opml/.md/.mmd/.html`）在同一输入下字节级一致；预览输出（PNG/PDF/manifest）在同一运行环境（Python 与 matplotlib 版本、已装字体集合）下逐字节一致——PDF 已去除创建时间元数据。跨环境的字形差异不属于缺陷，以 manifest 记录为准。
