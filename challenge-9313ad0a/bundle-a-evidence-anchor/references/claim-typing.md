# 节点陈述类型判定规范（claim-typing）

本规范定义思维导图节点 `basis` 字段（fact / summary / inference）的判定规则，以及审计缺陷进入隔离清单（quarantine）与不确定性列表（uncertainty）的分流原则。

## 三种 basis 的判定规则

### fact（事实性陈述）

**定义**：与材料某处文本直接对应、可用逐字引文证明的陈述。

**判定标准**：能够为节点提供至少一条 evidence，其 `quote` 是所引 `file` + `pdf_page` 页文本的逐字连续子串，且节点 `label` 未超出该引文所支持的范围。

**示例**：材料第 2 页写有"材料X 经过 5 次循环使用后活性保持率为 92.0%。"，节点 label 为"材料X 循环 5 次后活性保持率 92.0%"，basis=fact，quote 逐字摘录原句。

**义务**：必须携带 evidence；引文逐字；页码正确；label 中的数字必须在材料中出现。

### summary（概括性陈述）

**定义**：对材料多处内容进行压缩、归并或上位概括的陈述，无法由单条逐字引文直接证明。

**判定标准**：陈述的每个组成事实都能在材料中找到依据，但组合后的表述本身并非原文句子。

**示例**：材料分别记载了合成方法与催化性能，节点 label 为"材料X 兼具可控制备与良好催化活性"，basis=summary。

**义务**：建议附 evidence（若干支撑引文）以增强可复核性；审计不对 summary 的引文做逐字强制校验，但 label 中的数字仍须在材料中出现；概括不得引入材料中没有的新事实。

### inference（推理性陈述）

**定义**：由材料内容出发、经过外推、假设或评价得出的陈述，材料并未直接表述。

**判定标准**：陈述中包含材料之外的判断词或外推结构（"有望""可能""说明""提示""优于""适用于"等），或结论需要多条事实加外部常识才能得出。

**示例**：材料仅报告了实验室降解性能，节点 label 为"材料X 有望用于工业废水处理"，basis=inference。

**义务**：**必须填写 `note`**，写明推理链（由哪些材料事实、经何种假设推出）；缺少 note 时审计给出 warning。

## 隔离（quarantine）与不确定性（uncertainty）的分流

**进入 quarantine（必须修正或删除，不得出现在最终导图）**：

| 缺陷判定 | 含义 | 处置 |
|---|---|---|
| fabricated | 引文在整份材料中不存在，疑似改写或杜撰 | 回到原文重新逐字摘录；无法锚定则删除节点或降级为 inference 并补 note |
| unanchored | basis=fact 却无任何证据 | 补充逐字证据；无法补充则降级或删除 |
| number_not_found | 标签数字在全部材料中不存在 | 核对数字来源；系记忆或推测则删除数字并改 basis |
| page_out_of_range | 证据页码超出文件页范围，或所引文件未入库 | 修正文件标识或页码后重跑审计 |

**进入 uncertainty（如实记录，可保留交付）**：

- mislocated 节点的更正过程记录（更正页码后重跑至 verified 即可解除）。
- 材料不可读（加密 PDF、缺失文件）导致的覆盖缺口。
- PDF 页与印刷页不一致时的页码口径说明。
- summary / inference 节点中无法进一步收敛的概括或假设。
- 规范化规则可能掩盖的排版歧义（如表格错行）。

**原则**：quarantine 处理"陈述与材料的关系被破坏"的硬缺陷；uncertainty 处理"结论成立但置信度或口径需声明"的软风险。任何硬缺陷未清除前，result.json 的状态不得记为 success。
