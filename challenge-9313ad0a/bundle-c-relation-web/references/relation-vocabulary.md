# 关系类型词表（10 元）

本文件定义 relation-web 技能的十元关系词表。每条目含：定义、方向性、示例、材料证据模式，以及**何时不画此边**。方向约定：`from` 为主动方/先行方/承载方，`to` 为承受方/后行方/被指向方。

---

## 1. causes（导致）

- **定义**：`from` 是 `to` 的原因或致因机制。
- **方向性**：有向；原因 → 结果。不可随意反转。
- **示例**："焙烧温度过高 causes 活性组分烧结"。
- **证据模式**：材料中出现"由于……导致……""……使得……""as a result of"等明确因果措辞。
- **何时不画**：仅时间先后或统计相关而无因果措辞时；此时至多画 `precedes`，或记 inference 并在 note 中说明为推测。

## 2. depends_on（依赖）

- **定义**：`from` 的成立、运行或获取以 `to` 为前置条件。
- **方向性**：有向；依赖方 → 被依赖方。
- **示例**："动力学实验 depends_on 恒温反应装置"。
- **证据模式**："在……基础上""需先……""基于……方可……"。
- **何时不画**：仅为主题包含关系（属层级，入树不画边）；仅为弱相关性。

## 3. supports（支撑）

- **定义**：`from`（证据、数据、实验）为 `to`（结论、假设、论断）提供支持。
- **方向性**：有向；证据 → 结论。
- **示例**："原位红外谱图 supports 双位点机理假设"。
- **证据模式**："……表明/证实/支持……""consistent with……"。
- **何时不画**：材料仅并列陈述而无支撑措辞；结论与证据间还存在未被材料连接的中介环节。

## 4. contrasts_with（对比）

- **定义**：`from` 与 `to` 在某些维度上存在系统性差异，但二者并不互斥（可同真）。
- **方向性**：对称关系；存其一宜存互逆边，缺互逆边时闸门记警告。
- **示例**："浸渍法 contrasts_with 共沉淀法（分散度不同）"。
- **证据模式**："相比之下""不同于""whereas/in contrast to"。
- **何时不画**：二者取值直接互斥（应画 `conflicts_with`）；差异未被材料指出。

## 5. conflicts_with（冲突）

- **定义**：`from` 与 `to` 对同一对象的同一属性给出互斥陈述（典型为同键不同数值）。
- **方向性**：对称；宜双向连边。
- **示例**："页 1 记载产率 87.5% conflicts_with 页 3 记载产率 79.2%"。
- **证据模式**：两条可定位的互斥陈述；conflict_scan.py 的候选可辅助发现。
- **何时不画**：数值差异可由单位、温度等语境条件调和（应先核查语境，再决定画边或记 uncertainty）。

## 6. cites（引用）

- **定义**：`from`（文本/工作）明确引用 `to`（文献、数据来源、前人工作）。
- **方向性**：有向；引用方 → 被引方。
- **示例**："第 2 节综述 cites 文献 [12] 的基准结果"。
- **证据模式**：参考文献编号、明确"参见/引自/据……报道"措辞。
- **何时不画**：仅为术语巧合相同而无引用标记；材料自身即原始出处（无引用行为）。

## 7. precedes（先于）

- **定义**：`from` 在时间或工序顺序上先于 `to`。
- **方向性**：有向；先行 → 后行。全部 `precedes` 边构成的子图必须无环（DAG），闸门对环报错。
- **示例**："焙烧 precedes 还原活化"。
- **证据模式**：明确的步骤编号、时间戳、"随后/之后/先……再……"措辞。
- **何时不画**：仅推断可能的顺序而材料未述；会形成时间环的边（说明至少一条边的方向或依据有误）。

## 8. addresses（针对/回应）

- **定义**：`from`（方法、工作、设计）旨在解决或回应 `to`（问题、挑战、局限）。
- **方向性**：有向；方案 → 问题。
- **示例**："核壳结构设计 addresses 活性组分烧结问题"。
- **证据模式**："为解决/针对/克服……提出……""to address……"。
- **何时不画**：仅为一般性研究背景陈述，材料未建立方案与问题的对应。

## 9. measures（度量）

- **定义**：`from`（指标、表征手段、测试）度量或表征 `to`（对象、性质）。
- **方向性**：有向；度量手段/指标 → 被测对象。
- **示例**："TOF 值 measures 本征活性"。
- **证据模式**："以……表征……""通过……测定……"。
- **何时不画**：指标与对象仅同段出现而材料未述其度量关系。

## 10. mitigates（缓解）

- **定义**：`from`（措施）降低（但未消除）`to`（风险、误差、副效应）的影响。
- **方向性**：有向；措施 → 风险。
- **示例**："加入助剂 mitigates 积炭失活"。
- **证据模式**："缓解/抑制/降低……程度""alleviate/mitigate"。
- **何时不画**：材料声称问题被彻底解决（更接近 `addresses`）；效果未被材料陈述。

---

## 通用不画边原则

1. 材料无陈述且无合理推断路径——不画；
2. 关系可由主题树父子层级表达——不画横向边（闸门按"层级冗余"拒绝）；
3. 仅为填充导图美观——不画；
4. 引句无法逐字定位——不以 fact 依据画边。
