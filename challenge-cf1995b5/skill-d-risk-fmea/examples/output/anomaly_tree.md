# 异常处置决策树（anomaly_tree.md）

由 `risk_fmea.py decision_tree` 机械生成；入选规则：RPN ≥ 24 或 severity ≥ 5（安全类无论 RPN 一律入选）。

## 通用处置流程（每个异常都按此顺序走）

```
异常信号出现
  → 1. 判据确认：对照 detection_criterion 核实，用 confirm_method 排除误报
  → 2. 止损动作：先执行 stop_loss（先于原因分析），保护样品/人员/设备
  → 3. 替代路径：执行 fallback，方案不中断
  → 4. 升级判断：满足 escalation 条件时停止自主处置，
       升级人工/专家确认，并把确认结论写入 confirmation_items 与 change_log
```

## 高优先级失效模式决策树（共 5 项）

### 1. FM-DRIFT 参数漂移 — RPN 48（S3×O4×D4）— 关联步骤：ST-02, ST-03, ST-04, ST-05

- 评分依据：EQ-HP spec 允差 ±2°C 且为文本内嵌新装设备、漂移史未知（case:equipment_domain_note），按谨慎原则上调

- **异常触发判据**：设备读数与校准标准偏差超出设备手册允差（如温度 ±2°C、转速 ±50rpm）
- **判据确认方法**：用校准标准件/标准样复测读数，与设备手册 spec 字段对账
- **止损动作（立即执行）**：暂停依赖该参数的所有批次，隔离漂移期间产出的样品并单独标记
- **替代路径**：校准后复跑标准样确认恢复；或用第二台同类设备交叉验证后继续
- **设计预防（已反向写入方案）**：温控/转速敏感步骤前置校准确认点；漂移敏感批次保留同期标准样作为事后对账依据
- **责任人**：设备管理员
- **何时升级人工/专家确认**：校准失败 → 升级设备管理员维修；停机排期影响按 FM-EQBUSY 流程处理

### 2. FM-CONTAM 污染 — RPN 36（S4×O3×D3）— 关联步骤：ST-01, ST-02

- **异常触发判据**：溶液浑浊/沉淀/变色、薄膜出现针孔或异常颗粒、空白对照信号异常，任一出现即判污染
- **判据确认方法**：同批空白对照与未开封试剂对照并行观察，排除仪器背景误判
- **止损动作（立即执行）**：立即隔离受污染批次并贴标，停止一切共用耗材/共用腔体操作
- **替代路径**：重开新批次试剂、更换全部耗材、清洁腔体后重做该步骤
- **设计预防（已反向写入方案）**：关键配制步骤加空白对照与洁净度预检；污染敏感步骤预留 1 次重做的试剂与时间余量
- **责任人**：操作者
- **何时升级人工/专家确认**：连续 2 批污染 → 停止自主处置，升级专家确认环境洁净度（写入 confirmation_items）

### 3. FM-REPRO 重复性差 — RPN 36（S3×O4×D3）— 关联步骤：ST-02, ST-03, ST-06, ST-07

- **异常触发判据**：同条件 3 次重复的关键指标 RSD>15%，或批次间趋势方向不一致
- **判据确认方法**：复核原始记录确认操作一致（环境温湿度、陈化时间、操作者），排除记录错误
- **止损动作（立即执行）**：暂停批量制备与结论外推，回到单变量排查
- **替代路径**：固定环境条件，追加对照组，按预实验矩阵在参数域内小步扫描定位敏感变量
- **设计预防（已反向写入方案）**：关键步骤加预实验（小规模单变量矩阵）并预设可接受 RSD 阈值；方案必须含 ≥3 次独立重复
- **责任人**：操作者
- **何时升级人工/专家确认**：两轮单变量排查后 RSD 仍>15% → 专家复核方案与参数域（写入 confirmation_items）

### 4. FM-NOSIGNAL 无信号/无响应 — RPN 24（S4×O3×D2）— 关联步骤：ST-04, ST-05

- **异常触发判据**：目标信号低于基线噪声 3σ，或目标特征峰/条带/读数完全缺失
- **判据确认方法**：用标准样（或已知阳性样）同机复测，区分样品问题与仪器问题
- **止损动作（立即执行）**：暂停同参数批次制备，保留全部样品与原始数据，不得丢弃
- **替代路径**：标准样校验仪器→重制样品→在有限参数域内换参数点重新制备
- **设计预防（已反向写入方案）**：表征/测量步骤前置标准样校验环节；每个表征步骤指定一个可判读的成功判据
- **责任人**：操作者
- **何时升级人工/专家确认**：标准样复测仍异常 → 升级设备管理员检修；样品两次重制无信号 → 专家确认方案可行性

### 5. FM-SAFETY 安全事故 — RPN 10（S5×O2×D1）— 关联步骤：ST-01, ST-03

- **异常触发判据**：烟雾、异味、泄漏、报警触发、人员不适任一发生
- **判据确认方法**：无需排除误报：任何安全信号一律按真实事故先行处置
- **止损动作（立即执行）**：立即停止实验、切断相关电源/气源、按实验室应急预案撤离并报告
- **替代路径**：无替代路径：事故处置完毕且安全员书面确认前，方案全面暂停
- **设计预防（已反向写入方案）**：涉危险化学品/高温/高压步骤强制写 PPE 与应急处置卡；安全确认项永远是 confirmation_items 第一类
- **责任人**：安全员
- **何时升级人工/专家确认**：立即升级安全员与 PI；恢复条件写入 confirmation_items（安全类）
