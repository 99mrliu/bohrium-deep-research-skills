# 设计方法学：全因子 / 单因素扫描 / 正交（部分因子）缩减

本文件说明三类设计策略的适用判据与统计依据，供 Agent 在生成新设计策略
（strategies.json）与撰写 plan.md 的"假设与变量"一节时引用。
脚本 `design_space.py` 负责枚举与核算；本文件负责"何时用哪类设计"的判断。

## 1. 全因子（full factorial）

- 定义：k 个因子各取若干水平，所有组合都做。条件数 = Π levels_i。
- 适用判据：
  - 因子数 ≤ 3 且每因子水平 ≤ 3，或脚本核算出的样本数 × 单样本机时
    落在预约吞吐内（`score` 输出 `est_days ≤ deadline_days`）；
  - 研究目标明确要求估计**交互作用**（如温度×转速）；
  - 预算充足：`score` 的 `within_budget=True`。
- 统计依据：可无混杂地估计全部主效应与交互；每单元 r 次重复给出
  误差均方（df = N − 单元数），支撑 ANOVA / 多重比较。
- 风险：条件数随因子数爆炸（本例 15×4×6 = 360 条件），多数情况下
  被 `score` 以超预算/超工期否决——这是算术结论，不是口味问题。

## 2. 单因素扫描（OFAT / ofat_scan）

- 定义：固定基线，每次只动一个因子；链式扫描共享基线条件。
- 适用判据：
  - 预算/工期极紧，或处于探索期、只想要各因子的主效应方向；
  - 有先验证据（文献/预实验）表明因子间交互可忽略。
- 统计依据：每因子主效应在"其余因子固定"条件下可估；**不能估交互**，
  且若交互真实存在，主效应估计有偏。最优性结论只在被扫描的网格点上成立。
- 脚本行为：`type: ofat_scan` 自动共享基线并去重；信息度中
  `covarying_pairs = 0`，排序时会输给同规模的全因子/部分因子设计。

## 3. 正交 / 部分因子缩减（orthogonal / fractional）

- 定义：只跑全因子的一个平衡子集。脚本实现两种：
  - `orthogonal`：循环拉丁方主效应计划，L 个条件使每因子每水平出现
    次数相等，只能估主效应；
  - 指定 `factors` 子集的 `full_factorial`：对其余因子取固定水平，
    保留子集内的全部交互（本例 S3：温度×转速 3×3，时间固定）。
- 适用判据：
  - 全因子被 `score` 否决（超预算/超工期/replicates 不达标）时的首选替代；
  - 有文献或组织方 key_claim 指出哪些交互重要（只保留这些因子进子集）。
- 统计依据：平衡子集保证主效应正交可估；被固定因子的效应与
  截距混杂，必须在 plan.md 的"假设"中显式声明"固定水平外推有风险"。
- 重复次数：默认 `min_replicates = 2`。无重复设计（如 S1）无法估计
  纯误差，脚本按不可行拦截；如需放宽用 `--min-replicates 1` 并在
  uncertainty 中说明。

## 4. 统计依据说明模板（写进 plan.md）

> 本设计为【类型】，共 C 个条件 × r 次重复 = N 个样品。
> 可估计：【主效应清单 / 交互清单】；不可估计/被混杂：【清单】。
> 误差自由度 = N − C = 【数值】；随机化：样品按【随机顺序】上机；
> 区组：以【天/批次】为区组因子，避免与处理混杂。
> 判读标准见 plan.json 的 readout_criteria（如主效应 p<0.05 且
> 效应量超过重复性标准差 2 倍判为显著）。
