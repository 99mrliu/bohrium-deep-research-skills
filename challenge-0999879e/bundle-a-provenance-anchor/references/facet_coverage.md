# 六分面最低检查点（facet coverage）

本技能深查面是 **事实核验的证据保真**；其余五面按本表最低检查点轮查，
并在 answers.json 的 `facet_status` 中逐面登记状态。

## 状态值（只取其一）

- `checked_clean`：检查点全部执行，未发现问题。
- `issues_found`：检查点全部执行，发现问题（已写入 findings）。
- `partially_checked`：检查点只执行了一部分（须在 notes 说明缺了哪部分、为何）。
- `unable_to_check`：无法执行（须在 notes 说明原因，如抽取失败、材料缺失）。

## 最低检查点

### 1. 事实核验（本技能深查面）

- 摘要/结论中的关键数值与正文结果节逐一比对（产率、温度、样本量、百分比等）。
- 图/表标题中的数值与正文叙述一致性。
- 单位、量级、有效数字是否前后一致。
- **每条 finding 的 original_text 必须通过 anchor_verify 锚定复验**。

### 2. 引用支持

- 参考文献列表中每条是否至少在正文被引用一次；正文每个 [n] 是否在文献表有对应条目。
- 关键事实性断言是否附有引用支撑（无引用的断言登记为 minor finding 或 uncertainty）。
- 不臆造文献内容：无法获取全文的引用，只查"是否存在对应关系"，不评内容真伪。

### 3. 方法设计

- 方法节是否给出可复现的关键参数（设备型号、条件范围、样本来源）。
- 实验组/对照组设置是否交代。
- 只基于稿件文本判断"是否写明"，不推测未写的内容。

### 4. 统计报告

- 是否报告样本量 n、误差棒/标准差/置信区间、显著性检验方法。
- 百分比/均值能否与给出的 n 自洽（如 3/7=42.9% 这类可对账的算式抽查）。
- 稿件无统计数据时登记 `unable_to_check` 并说明，不得编造"统计合格"。

### 5. 论证链

- 摘要/结论的每个强结论能否在结果节找到对应证据句。
- 是否存在"结果只支持弱结论、结论却写成强结论"的跳跃。
- 每条论证链 finding 同样需要原文锚定。

### 6. 学术规范

- 图表是否都有编号与标题；章节结构是否完整（摘要/引言/方法/结果/结论/参考文献）。
- 是否有明显的自我抄袭信号（大段重复文本，可用抽取文本自查）。
- 查重、AI 生成检测不在本技能范围，登记 `unable_to_check` 并注明边界。

## 登记格式（answers.json → facet_status）

```json
"facet_status": {
  "事实核验": {"status": "issues_found", "notes": "摘要 92% vs 结果节 89%（f-001）"},
  "引用支持": {"status": "issues_found", "notes": "文献[3]正文未引用（f-002）"},
  "方法设计": {"status": "checked_clean", "notes": "关键参数齐全"},
  "统计报告": {"status": "unable_to_check", "notes": "稿件无统计数据"},
  "论证链":   {"status": "checked_clean", "notes": "结论均有结果句支撑"},
  "学术规范": {"status": "checked_clean", "notes": "结构完整"}
}
```
