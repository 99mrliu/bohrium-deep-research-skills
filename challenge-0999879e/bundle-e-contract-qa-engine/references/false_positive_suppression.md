# 误报抑制规则（Pass 2 机械复核的判定依据）

误报比漏报更伤可信度。每条 finding 在写入 findings_candidate.json **之前**，
Agent 必须能回答一个删除测试问题：

> **"删掉原文中的哪一句话，这条 finding 就不成立？"**

答不出具体那句话 → 这条 finding 没有锚点，不许写入候选清单。
写进去也会被 adjudicate check 的锚点复验拦下（original_text 空白归一化后
必须出现在 /input 抽取文本中，否则降级 pending_review）。

## 1. 三类"不判缺陷"的情形

### 1.1 学科写作惯例
本领域的标准表述方式不构成缺陷，即使换一种写法"更清楚"。例：
- 医学论文按 CONSORT/PRISMA 惯例的固定句式；
- 化学论文将实验细节统一放入 Supporting Information；
- 数学/物理论文中"显然""不失一般性"等惯用省略（前提：上下文确实可推）。

### 1.2 期刊格式差异
目标期刊的格式要求与通用规范不同，不判"规范问题"。例：
- 期刊要求摘要不分段 / 不设小标题；
- 期刊采用数字引用 [1] 而另一刊用作者-年份；
- 期刊规定图表标题置于图下方/表上方的差异。

### 1.3 作者有意取舍
有证据表明是作者权衡后的选择，不判缺陷（至多 info 级"建议性意见"）。例：
- 篇幅限制下将次要实验移至附录；
- 为聚焦主线而不展开某对照，且文中明示原因。

## 2. 豁免词表（adjudicate.py 机械命中即提示 recheck）

命中以下词组的 finding **不自动 reject**，但强制打 recheck 提示，要求人工
确认是否属于上述三类情形之一：

```
按目标期刊惯例 / 按期刊惯例 / 按本刊惯例 / 遵循期刊格式 / 按期刊要求
依本领域惯例 / 按领域惯例 / 按学科惯例 / 遵循本领域惯例
按编辑部要求 / 按出版方要求 / 格式从简 / 此处从简
```

典型误报形态：finding 把"本研究按目标期刊惯例报告了主要结局指标"判为
"规范问题/报告不全"。豁免词表命中 → recheck，由人工确认这是惯例声明
而非缺陷。

## 3. 误报抑制的其他机械规则

1. **锚点复验**：original_text 编造、转述、跨句拼接 → 复验不到 →
   降级 pending_review（不 reject，留人工确认是否原文真有此意）。
2. **枚举合法性**：severity/type/facet 非法值 → rejected 并留痕
   （如 severity 写 "high" 而非四级枚举）。
3. **type-facet 一致性**：facet 与 type 组合偏离映射表 → recheck 提示
   （映射见 adjudicate.py 中 TYPE_FACET_MAP；偏离不等于错，但值得再看一眼）。
4. **证据约束**：evidence 字段不得引入原文之外的"事实"（编造的文献、页码、
   DOI、数据）。Agent 填写时自查；check 阶段无法机械验证的部分统一进入
   人工 recheck 视野。

## 4. 反例对照（写 finding 前自测）

| 形态 | 处置 |
| --- | --- |
| "摘要写 312 例、正文写 318 例，同一数值两处不一致" | 合法 finding（删任一处的数字即不成立，锚点明确） |
| "论文缺少数据可用性声明"（全文检索确认无此节） | 合法 finding（锚点 = 文末结构，original_text 引用邻近现存段落） |
| "这段写得不够学术" | 不许写入：删除测试答不出 |
| "按期刊惯例报告是偷懒，应判规范问题" | 误报：命中豁免词表，recheck 后应撤回 |
| "参考文献可能有问题"（无具体条目） | 不许写入：无锚点 |
