# 论证链判据（argument_rubric）

本判据用于 chain_lint.py 机械候选（candidate=true）的人工（Agent）处置：
转正 confirmed 或驳回 rejected。每条候选必须引用两侧原文（设计侧 + 主张侧）。

## 1. 论证链六环与链边

环节：研究问题 → 研究假设 → 关键方法 → 核心结果 → 结论主张 → 外推边界。
链边一致性核对：

- 问题→假设：假设是否逐条覆盖引言问题？漏环即"答非所问"候选。
- 假设→方法：方法能否检验假设（设计类型、对象、指标是否对口）？
- 方法→结果：方法承诺的每个分析，结果节是否有对应产出？
- 结果→结论：每条结论主张能否回溯到结果节的具体数值/发现？
- 结论→外推边界：结论是否声明了适用范围（人群、场景、设计局限）？

## 2. 因果/相关混淆判据

- **规则**：观察性设计（横断面、相关性、回顾性、问卷调查、现况调查）只能支撑
  "相关/关联"表述；结论或结果节出现"导致/致使/引起/造成/证明/决定了/prove/cause/
  result in"等因果措辞即候选 major。
- **转正条件**：方法节原文确为观察性设计 且 主张句无任何缓和措辞。
- **驳回条件（防误报）**：
  - 主张句含"提示/可能/或许/推测/suggest/may/could"等推测措辞 —— 属合理推测，不算；
  - 方法实为随机对照试验或自然实验设计（lint 词表误命中"相关"，如"相关系数"出现
    在 RCT 的次要分析里）；
  - 因果词出现在引述他人文献的句子里（"前人证明……"）而非本文主张。

## 3. 外推 / 无据结论判据

- **新数值（X1）**：结论节出现的数值在结果节全文检索不到 → 候选 major。
  - 驳回条件：该数值是结果节数值的显式换算（如由两组均值直接算出的相对百分比）
    且换算口径在文中可查；此时降级 minor 或驳回，注明换算路径。
  - 转正条件：结果节确无该数值且无从换算 —— 属"无据结论"。
- **新主张**：结论提出结果节完全没有涉及的新实体/新建议（如结果只讲相关性，
  结论直接给出政策优先级建议）→ 人工判定，合理范围内的一句展望可降级 minor。
- **范围外推**：结论把结论对象从研究人群（如某市成人）扩到全称人群（"所有人"
  "普遍适用"）而无边界声明 → major。

## 4. 循环论证与缺环

- 循环论证：结论的主张被当作方法的依据（"因为我们假设 X 导致 Y，所以测量了……，
  因此 X 导致 Y"）。lint 不机械扫描此类，由 Agent 在 chain_register 的链边
  consistent=false 记录，必须同时引用方法侧与结论侧原文。
- 缺环：六环中任何一环在稿件中找不到原文支撑，chain_register 该环置 broken，
  build_result 报 major；不得用摘要里的概括句冒充该环（摘要属概括，不替代正文环节）。

## 5. 处置记录格式

Agent 在 work/lint_dispositions.json 中逐条处置：

```json
{"dispositions": [
  {"candidate_id": "CAND-001", "verdict": "confirmed",
   "note": "方法节原文'横断面观察性调查'，结论原文'导致'无缓和措辞"},
  {"candidate_id": "CAND-002", "verdict": "rejected",
   "note": "44.4% 系 (7.8-5.4)/5.4 的显式换算——本例不应驳回，仅为格式示例"}
]}
```

未处置的候选在 result.json 中保持 pending_review，诚实门：待复核不凭空补结论。
