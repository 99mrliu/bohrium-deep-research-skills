# examples（合成示例，非正式案例结果）

本目录为**合成示例，非正式案例结果**，仅用于端到端验证 bundle-d 的工作流。

- `synthetic-input/`：合成 case.json + task.md + manuscript.md。
  稿件开头已显著标注"本文为合成示例文本"，主题自拟（城市夜间光暴露与睡眠质量），
  植入 4 处已知问题：
  1. 有摘要/引言/方法/结果/结论/参考文献，但**无讨论节**（结构缺位 major）；
  2. 引言提出两个问题，结论只回答第一个，**年龄分层问题未回应**（答非所问 major）；
  3. 方法为**横断面观察性调查**，结论写"夜间光暴露**导致**居民睡眠质量下降"（因果混淆 major）；
  4. 结论出现结果节从未出现的数值 **44.4%**（无据结论 major）。
- `synthetic-output/`：按 SKILL.md 工作流真实跑出的 result.json 与 review_report.md 拷贝。

预期：4 处植入问题全部检出（confirmed），且每条 finding 均附两侧原文引用与定位。
