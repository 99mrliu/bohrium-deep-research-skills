# 同族口径：simple 与 extended

`scripts/family_merge.py` 同时输出两种口径，二者**并排呈现、不可合并为
单一结论**，并附 `scope_note` 说明差异。

## 定义

- **simple（简单同族）**：优先权集合**完全相同**的记录归为一族。
  实现：以排序去重后的优先权元组为键分组。
- **extended（扩展同族）**：**至少共享一件优先权**的记录构成的连通分量。
  实现：以"共享优先权"为边做并查集，每个连通分量为一族。

二者关系：simple 是 extended 的细分。任一 extended 族内若各成员优先权
集合不全相同，则其 simple 族数 > 1。fixture 即按此设计：EX1001/EX1002/
EX1003 通过链式共享优先权构成 1 个 extended 族，但因优先权集合两两不同
而分为 3 个 simple 族。

## 观察到的链接纪律（observed-links-only）

- 族**仅**基于本次输入 records 中观察到的优先权链接构建；
- **绝不声称族已穷尽**——可能存在未纳入材料的成员或未观察到的链接；
- **绝不声称族成员权利要求范围一致**——同族不等于同保护范围；
- 不含任何法律状态判断；族归属变化须以官方登记为准；
- 优先权号无法解析时**原文保留**参与匹配，并在 `warnings` 中说明；
- 无优先权的记录不参与任何族，单列于 `records_without_priorities`，
  附固定警示语："族归属不确定，观察到的链接非完整同族"。

## 输出措辞模板（可直接用于 result.json / 报告）

- 口径说明：
  "simple（简单同族）= 优先权集合完全相同的记录归为一族；extended
  （扩展同族）= 至少共享一件优先权的记录构成的连通分量。两种口径均仅
  基于本次观察到的优先权链接：不保证穷尽（可能存在未观察到的成员或
  链接），不代表族成员权利要求范围一致，亦不包含任何法律状态判断。
  族归属变化须以官方登记为准。"
- 非穷尽声明：
  "以上同族结果仅基于本次检索观察到的优先权链接，未核验官方同族数据库，
  不应视为完整同族。"
- 无优先权记录：
  "记录 X 未观察到优先权信息：族归属不确定，观察到的链接非完整同族。"
