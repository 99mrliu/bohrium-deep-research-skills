# OCR 粘连切分：唯一边界规则

USPTO 传真 PDF 等 OCR 文本常把相邻两个号码粘连成一个 token（尤其 WO 号
与随后的 US 号之间丢失空白），例如 `WO2019/123456US10293847B2`。
`patent_numbers.py split` 的处理规则如下。

## 规则

对粘连串 `s`，枚举全部切分位置 `1..len(s)-1`，对每对 `(s[:i], s[i:])`
分别调用同一确定性解析器：

- **恰好一个**边界使两侧均为合法号码（`ok=true`，允许各自带 warning）→
  执行切分，输出两段各自的规范化结果与 `boundary`；
- **零个**合法边界 → 不拆分，原文保留（`kept`），warning"切分失败"；
- **多于一个**合法边界 → 不拆分，原文保留，warning"歧义切分"并列出全部
  `candidate_boundaries`。

即：**只在唯一解时动手，其余情况一律保守保留**。模型不得凭语境"帮忙选
一个"。

## 示例（合成示例）

| 输入 | 结果 | 说明 |
| --- | --- | --- |
| `WO2019/123456US10293847B2` | 拆分：`WO2019123456` + `US10293847B2`（boundary=13） | 唯一合法边界；WO 段缺种类代码，自带 warning |
| `123456789123456` | 不拆分（歧义） | 15 位裸数字：boundary=7（7+8）与 boundary=8（8+7）均合法 |
| `GARBAGE!!` | 不拆分（失败） | 无任何合法边界 |

## WO 粘连边界保留

WO 公开号（`WO+4 位年+6 位序号`）长度固定，是最常见的粘连左段。拆分后
WO 段若缺种类代码，解析结果会带"缺少种类代码"warning 一并传递——边界
信息（`boundary`）与两段原文均保留在输出中，便于回溯原始 OCR 文本。
若粘连串存在多个合法边界（罕见但可能），按规则整体保留原文，由人工
核对 PDF 原件行定位（`corpus_scan` 的定位符可辅助回查）。
