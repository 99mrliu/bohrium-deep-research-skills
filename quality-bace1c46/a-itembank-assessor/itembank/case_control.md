# 病例对照研究特有检查点

## [K-01] 病例定义与来源
- 维度: 样本与抽样
- 问题: 病例的诊断标准与来源（医院/社区/登记系统）是否明确？
- 所需证据: 病例定义（诊断标准）与来源人群的描述句。
- 不可评价: 仅称"确诊病例"而无标准与来源。
- 核心: 是
- 关键词: case definition, diagnostic criteria, cases were, confirmed cases, 病例定义, 诊断标准, 确诊病例

## [K-02] 对照选择的代表性
- 维度: 样本与抽样
- 问题: 对照是否来自产生病例的同一源人群？
- 所需证据: 对照来源与选择方法的描述（community controls / hospital controls 及其合理性讨论）。
- 不可评价: 对照来源不明。
- 核心: 是
- 关键词: controls were selected, control group, source population, matched, 对照选择, 对照来源, 匹配

## [K-03] 暴露测量的一致性（回忆偏倚控制）
- 维度: 测量与结局
- 问题: 病例与对照的暴露信息是否以相同方式收集？是否采取措施降低回忆偏倚？
- 所需证据: 暴露采集方式（问卷/访谈/记录）对两组一致的描述，或盲法访谈等措施。
- 不可评价: 暴露采集方式未描述。
- 核心: 是
- 关键词: interview, questionnaire, recall, exposure assessment, records, 回忆, 问卷调查, 暴露测量

## [K-04] 混杂调整与匹配策略
- 维度: 统计分析
- 问题: 是否通过设计（匹配）或分析（分层/回归）控制混杂？
- 所需证据: 匹配变量清单或 adjusted OR 的协变量清单。
- 不可评价: 仅报告粗 OR 且未说明。
- 核心: 是
- 关键词: adjusted odds ratio, matched for, conditional logistic, adjusted for, 条件logistic, 校正, 匹配因素

## [K-05] 参与率/应答率报告
- 维度: 样本与抽样
- 问题: 是否报告病例与对照的参与率/拒访率？
- 所需证据: participation / response rate 数值句。
- 不可评价: 无参与率信息。
- 核心: 否
- 关键词: participation rate, response rate, refused, non-response, 参与率, 应答率, 拒访
