# 队列研究特有检查点

## [H-01] 暴露定义与测量
- 维度: 测量与结局
- 问题: 暴露因素是否明确定义，测量方法是否可靠？
- 所需证据: 暴露的定义、测量时点与工具描述句。
- 不可评价: 暴露仅一句话带过，无定义无测量说明。
- 核心: 是
- 关键词: exposure, exposed, unexposed, definition of exposure, 暴露, 暴露组

## [H-02] 随访完整性与失访处理
- 维度: 样本与抽样
- 问题: 是否报告随访率/失访率，并说明失访处理方法？
- 所需证据: follow-up rate / lost to follow-up 的具体数值句及处理方法。
- 不可评价: 无随访完整性信息；仅摘要可得。
- 核心: 是
- 关键词: follow-up rate, lost to follow-up, dropout, attrition, censored, 随访率, 失访, 删失

## [H-03] 混杂因素控制
- 维度: 统计分析
- 问题: 是否识别并调整了关键混杂因素（多变量模型、分层、匹配）？
- 所需证据: adjusted for / multivariable model 中列出的协变量清单。
- 不可评价: 仅报告粗关联（crude），且未说明为何不调整。
- 核心: 是
- 关键词: adjusted for, adjustment, confounding, confounder, multivariable, propensity, 混杂, 校正, 调整

## [H-04] 结局判定的客观性
- 维度: 测量与结局
- 问题: 结局判定是否采用客观标准或对暴露状态盲法判定？
- 所需证据: 结局判定流程、判定者是否知晓暴露状态的说明。
- 不可评价: 无结局判定过程描述。
- 核心: 否
- 关键词: outcome assessment, adjudicated, blinded to exposure, 结局判定, 盲法判定

## [H-05] 时间关系明确性（避免不朽时间偏倚）
- 维度: 研究设计
- 问题: 暴露、随访起点与结局的时间关系是否明确？
- 所需证据: index date / baseline / follow-up start 的明确定义。
- 不可评价: 无法从文中重建时间轴。
- 核心: 否
- 关键词: index date, baseline, start of follow-up, immortal time, 入组时间, 随访起点

## [H-06] 剂量-反应关系
- 维度: 统计分析
- 问题: 若适用，是否考察暴露水平与结局的剂量-反应趋势？
- 所需证据: trend test / dose-response / 分层暴露分析的结果句。
- 不可评价: 暴露为二分类无法分层，或研究问题不涉及剂量关系（理由中说明）。
- 核心: 否
- 关键词: dose-response, trend, p for trend, 剂量反应, 趋势检验
