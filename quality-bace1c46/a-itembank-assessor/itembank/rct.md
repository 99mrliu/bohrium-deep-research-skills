# RCT 特有检查点

## [R-01] 随机序列生成
- 维度: 研究设计
- 问题: 是否描述了随机序列的具体生成方法（随机数字表、计算机随机等）？
- 所需证据: 随机化方法的具体描述句；仅写"随机分为两组"而无方法判 partial。
- 不可评价: 全文无随机化描述；仅摘要可得且摘要未提随机方法。
- 核心: 是
- 关键词: random sequence, random number, computer-generated, randomization, randomly, 随机数字, 随机序列, 随机分为

## [R-02] 分配隐藏
- 维度: 研究设计
- 问题: 是否实施并描述了分配隐藏（中心随机、封闭信封等）？
- 所需证据: allocation concealment / sealed envelope / central randomization 的描述句。
- 不可评价: 无分配隐藏描述（注意：未描述不等于未实施，判 not_assessable 并说明，而非 not_met）。
- 核心: 是
- 关键词: allocation concealment, concealed, sealed envelope, central randomization, 分配隐藏, 密封信封

## [R-03] 盲法实施
- 维度: 测量与结局
- 问题: 是否对受试者/实施者/结局评估者实施盲法并说明对象？
- 所需证据: double-blind / single-blind / assessor-blinded 的具体说明；开放标签研究声明 open-label 并讨论影响可判 partial。
- 不可评价: 无盲法相关描述。
- 核心: 是
- 关键词: double-blind, single-blind, blinded, masked, open-label, 双盲, 单盲, 盲法

## [R-04] 组间基线可比性
- 维度: 样本与抽样
- 问题: 是否报告并比较各组基线特征？
- 所需证据: 基线特征表（Table 1）或基线比较的文字描述。
- 不可评价: 无基线数据；表格不可解析且正文未提及。
- 核心: 否
- 关键词: baseline characteristics, baseline, table 1, 基线, 基线特征

## [R-05] 分析集与意向性分析
- 维度: 统计分析
- 问题: 是否采用意向性治疗（ITT）分析或明确说明分析集？
- 所需证据: intention-to-treat / ITT / full analysis set 声明，或明确的 per-protocol 说明。
- 不可评价: 未说明分析集构成；失访处理完全未提。
- 核心: 是
- 关键词: intention-to-treat, intention to treat, itt, per-protocol, full analysis set, 意向性, 意向治疗

## [R-06] 试验注册与方案可及
- 维度: 报告完整性
- 问题: 是否报告前瞻性试验注册号或研究方案？
- 所需证据: 注册号（NCT/ChiCTR/ISRCTN 等）或 protocol 引用。
- 不可评价: 无注册信息且研究早于注册制度（在理由中说明）。
- 核心: 否
- 关键词: registered, registration, clinicaltrials, nct, chictr, isrctn, protocol, 注册, 方案
