# domains/：偏倚领域集与信号问题树

本目录定义按文献类型选择的偏倚风险领域集。每个领域含 2–4 个信号问题
（signaling questions），每个信号问题明文规定：

- **肯定性证据什么样**（看到什么说明该偏倚被控制 / 或该问题有正面答案）；
- **否定性证据什么样**（看到什么说明偏倚明确存在）；
- **何时判"证据不足"**（弃权条件）。

机器可读版本在 `scripts/domain_specs.py`，二者必须保持一致：改量表时先改
`domain_specs.py` 再同步本目录文档（`apply_overrides.py` 生成的
`scale_revision_suggestions.md` 会指出哪个领域需要修订）。

## 领域集选择

| 文献类型 | 适用领域 |
|---|---|
| 全部类型 | 结果选择性报告（核心）、统计方法适用性、资助与利益冲突 |
| RCT | + 随机化与分配隐藏（核心）、盲法实施（核心）、失访与缺失数据（核心） |
| 观察性 | + 混杂控制（核心）、研究对象选择（核心）、暴露/结局测量（核心）、失访与缺失数据（核心） |
| 诊断 | + 参考标准（核心）、受试者流程与时间间隔、研究对象选择（核心）、失访与缺失数据（核心） |
| 系统综述 | + 检索与纳入过程（核心）、纳入研究质量评价与综合方法（核心） |
| 其他 | 仅公共领域 |

- **核心领域**：任一核心领域判 `present` 即触发整体 `high`（见
  `rules/judgment_levels.md` 映射表）。
- 详细定义见 `common.md`（公共领域）与各类型文件（`rct.md` /
  `observational.md` / `diagnostic.md` / `systematic_review.md`）。

## 判定等级

四级：`present`（明确存在）/ `likely`（可能存在）/ `no_indication`
（未见迹象，要求主动检索过否定性证据并记录检索范围）/ `insufficient`
（证据不足，弃权而非默认安全）。完整定义见 `rules/judgment_levels.md`。
