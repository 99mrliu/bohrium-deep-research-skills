# 关联信号规范（signal specification）

## 1. 信号定义

| 信号 | 定义 | 证据内容 | 权重 |
|-|-|-|-|
| S1 共被引 | 引用种子的文献集合 C 中，同时引用候选 W 的成员数 | 每个施引者的标识、"施引者→种子"定位、"施引者→候选"定位 | Ochiai：n / √(n_C · cited_by(W))；cited_by 未知时退化为 n / √n_C |
| S2 文献耦合 | 候选与种子参考文献集合的交集 | 每条共享参考文献的标识、种子引用处定位、候选引用处定位 | Jaccard：∩ / ∪ |
| S3 作者重叠 | 候选与种子共享的作者姓氏 | 姓氏列表 | 0.15 × 人数（微调） |
| S4 期刊/主题词 | 同刊；标题显著词交集（去停用词，长度>2） | 词表 | 0.05 ×（词数 + 同刊）（微调） |

入选门槛：S1 或 S2 至少一条（`--min-support`，默认 1，可调高到 2 降噪）。S3/S4 永远不单独入选。

## 2. 为什么排除直接邻居

种子的参考文献与施引文献已经由引文追踪（方向 1）覆盖。把它们留在"关联发现"候选里会虚高覆盖率、稀释平行工作的排名。脚本在 `direct_neighbors` 字段中报告排除数量与说明，供合并两类结果时引用。

## 3. 抗噪声原则

- **高被引 ≠ 高相关**：S1 用 Ochiai 归一，候选自身被引越高，单次共被引的权重越低；避免领域综述、工具书式文献霸榜。
- **主题相似 ≠ 方法相关**：S4 主题词仅微调；没有引用结构支撑的主题相似记录不进入候选。
- **单次信号可复核**：每条 S1/S2 证据都是一对具体定位，复核人可直接打开源文件验证"施引者确实同时引用了两者"。
- **确定性**：同语料同参数输出完全一致；排序平局按候选键字典序，保证可重复。

## 4. 参数指引

| 场景 | 建议 |
|-|-|
| 语料引用覆盖好（会议/期刊论文种子） | 默认 top=40, min_support=1 |
| 候选噪声大（大领域、老种子） | min_support=2，top=30 |
| 种子为新预印本（无施引记录） | 依赖 S2 耦合；在报告中说明 S1 缺失 |
| 900 秒预算 | 脚本秒级完成；时间应用于 Agent 对 Top 候选的主题标注，不得改写结构证据 |

## 5. 诚实性

- 空结果照实交付并注明阈值；不得降低门槛后声称"发现"。
- 元数据缺失字段置 null；不从标题猜测年份、作者或期刊。
- 共被引中的施引者身份必须来自语料记录；本地无记录时该信号计 0 并在 uncertainty 说明覆盖局限。
