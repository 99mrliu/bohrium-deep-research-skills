# 对齐方法学：相似度、阈值与候选策略（alignment_method.md）

本文件说明 `claim_align.py` 的对齐方法，便于复核与调参。

## 1. 两级对齐

1. **权利要求级**：按编号配对（A 第 N 项 ↔ B 第 N 项）。版本间重新编号时，编号相同的项主题可能不同——此时要素级相似度会自然降低，低相似度配对只进入候选列表；无法配对的整项记为 `claims_added` / `claims_removed`（带整项逐字 quote 与 span）。本工具**不**做跨编号智能匹配，避免把主题不同的权利要求强行对应。
2. **要素级**：每项权利要求的对齐单元为 `preamble`、`transition` 与全部 `elements`（含 wherein 从句与编号子步骤），均带原文 span 与逐字 quote。

## 2. 相似度度量

- 归一化：`lower()` + 折叠连续空白为单个空格。**不做**词干化、同义替换或翻译——一切判断停留在字面层。
- 度量：`difflib.SequenceMatcher(None, a_norm, b_norm).ratio()` ∈ [0, 1]，即 `2·M / (|a|+|b|)`，M 为匹配字符块总长度。
- 特性：对局部插入/替换（如 `a fastener` → `a titanium alloy fastener`）给出高但小于 1 的比率，正好落入 `modified`；对整体换题给出低比率，落入候选区。

## 3. 配对算法与阈值

- 贪婪最优配对：计算全部 A×B 单元对的比率，按降序遍历，双方均未占用且比率 ≥ 阈值即配对。阈值默认 **0.60**，可用 `--threshold` 显式声明；产出 JSON 中的 `threshold` 字段记录实际使用值。
- 分类规则：
  - 归一化文本完全一致 → `unchanged`；
  - 配对成功但文本不同 → `modified`；
  - 配对成功、文本一致但相对次序变化 → `reordered`（文本不同而次序变化时分类保持 `modified`，另置 `reordered: true`）；
  - A 侧未配对 → `removed`；B 侧未配对 → `added`。
- 重排判定：将配对按 A 侧序号排序后，若 B 侧序号的相对位次与 A 侧不一致，则该对标记 `reordered`。

## 4. 候选策略（不强制配对）

- 对每个未配对的 A 侧单元，计算其与所有未占用 B 侧单元的最佳比率；比率 > 0 者列入该权利要求对的 `candidates`，附 `below_threshold_not_forced` 标注。
- 候选**永不**转为正式配对：低于阈值的相似度不足以支持字面层对应断言。候选仅供人工复核时参考。

## 5. 统计与诚实性

- `statistics` 一律由脚本根据**已生成的对应表**现场重算；调用方提供的任何计数均被忽略。
- 状态规则：
  - 双版本、两侧切分均未降级、无 OCR 边界交叉 → `ok`；
  - 仅单一版本（缺少 `--b`）→ `mode=one_sided_inventory`、`status=partial`，只输出单侧清单；
  - 任一侧切分降级，或任一权利要求跨越已声明的 OCR 合并边界 → `status=partial`，`limits` 逐条写明位置（版本、权利要求编号、span 偏移）。
- 已知局限：
  - 贪婪配对不保证全局最优；要素数少时风险有限，必要时可调高阈值并人工复核候选；
  - `difflib` 比率对长公共前缀敏感，两段都以相同套话开头的要素可能比率虚高——这仍属字面层事实，报告中的逐字 quote 允许复核者自行判断；
  - 跨语言版本（如英文授权文本 vs 中文公开文本）在本工具中只会得到低比率与候选列表；本工具不做翻译对齐。
