# 措辞闸门：违禁与允许措辞（wording_gate.md）

本文件是 `scope_note.py --gate` 的词表依据与理由说明。闸门是**钝器**：逐行子串匹配，不理解语境；宁可误报，不可漏报。修改本词表时必须同步修改 `scope_note.py` 中的 `FORBIDDEN_PHRASES`。

## 1. 为什么需要闸门

本技能的产出是"文本层面差异"的报告。权利要求保护范围的判断是法律问题，受全部元素原则、禁止反悔、等同原则（doctrine of equivalents）等规则约束，远超文本比对能力。任何把文本差异（或无差异）表述为法律结论的措辞，都必须被拦截。

## 2. 违禁结论性措辞（检出即退出码 1，报告行号）

| 违禁短语 | 理由 |
|---|---|
| 保护范围相同 | 把文本比对结果断言为保护范围结论 |
| 保护范围一致 | 同上 |
| 保护范围等同 | 同上，且直接使用"等同"作结论 |
| 范围完全相同 | 同上 |
| 未实质改变 | 对修改的法律意义下结论 |
| 未发生实质改变 | 同上 |
| 实质性变化不存在 | 同上 |
| 实质相同 / 实质上相同 | 同上 |
| 等同 | 任何形式的等同结论（含"构成等同""两版本等同"等复合形式）一律拦截 |
| 等效替换成立 | 对等同替换下结论 |
| 构成侵权 / 不构成侵权 | 侵权判断超出本工具范围 |
| 侵权成立 / 侵权不成立 | 同上 |
| 法律效力相同 | 法律效果结论 |

## 3. 允许与推荐措辞

- 描述文本事实：`文本分类：已修改（相似度 0.9310）`、`版本 A 该要素被删除，版本 B 无对应文本`。
- 声明不确定性：`该差异是否影响保护范围，属于法律判断，本说明不作结论。`
- 免责声明中需要指称等同原则时，使用 `法律等价性判断（doctrine of equivalents）` 或英文 `equivalents` 等不含违禁子串的表达；固定页脚即按此原则撰写，因此本工具自动渲染的说明应当能通过闸门。
- 逐字引用原文是允许的：闸门只针对说明文字；若某份说明必须引用恰好含违禁子串的第三方原文，应改写为转述并标注出处，而不是绕过闸门。

## 4. 闸门的局限

- 子串匹配无法识别变体写法（插空格、同音替换、英文等价结论如 `same scope`）。因此：**通过闸门 ≠ 措辞合规**，只是必要条件；最终说明仍需人工通读。
- 反向风险：合法 Disclaimer 若误用违禁子串（如写出"不假定保护范围相同"——其中包含违禁子串"保护范围相同"）也会被拦截。固定页脚已刻意改写为"不对两版本权利要求保护范围是否一致作出任何假定或断言"，规避该问题；自定义文字请沿用类似写法。
