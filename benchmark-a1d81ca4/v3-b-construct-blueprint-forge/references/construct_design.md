# 构念设计：从任务意图到四题题库

## 1. 先定义测量对象，再写题

把 `/input/task.md` 的交付目标压缩成一句 `task_intent`，再判断实际材料是否能支持四种互补操作。每个 item_id 都要回答五个问题：

1. 它服务原任务的哪个决策或理解目标？
2. 作答者必须进行哪一种认知操作？
3. 作答所需的最小充分材料范围是什么？
4. 哪些答案 claim 在可接受改写下必须保持真？
5. 哪些错误应落在 1 分而不是 2 分？

若四题可以先写好答案再随便找引文，设计顺序就反了。蓝图中的 `required_claims` 是可检查的真值分解，不是暗示答案的题干模板。

## 2. 四种操作及边界

### locate_extract：定位并完整抽取

- **操作**：在指定段落内区分目标字段、限定条件和相邻干扰字段，准确抽取一个结构化记录。
- **适用**：多个容易混淆的时间点、对象、阈值或单位同时出现。
- **不适用**：需要跨段裁决、表计算或新旧规则冲突。
- **区分度**：2 分要求目标值与关键限定都正确；只抽到其中一个才可能是 1 分。不要把逐字匹配长句当作认知挑战。

### table_relation_calculation：表关系与计算

- **操作**：选对行、列、方向、分母和单位，再按声明规则计算；关键是关系而非算术长度。
- **适用**：原表数值足以导出明确答案，且能提供未参与泄题的字段名与表达式。
- **不适用**：从单元格抄原值，或需要材料之外的常数/公式。
- **可复核性**：`expression` 的绑定值必须出现在输入材料/证据；独立 `expected` 与参考答案的重算不一致即失败。注明四舍五入和容差，禁止以 `eval` 执行表达式。

### comparison_boundary：比较与判定边界

- **操作**：对两个对象应用同一明确判据，处理等号、缺失、联合条件或证据强度边界。
- **适用**：材料明示包含/排除阈值、至少/至多、前后关系，且存在接近边界的对象。
- **不适用**：重复百分比计算题，或把描述性差异扩大成统计显著、因果、优越性结论。
- **区分度**：部分正确常见于只判对一个对象、漏掉联合条件、越界推断。答案不变量必须写清等号与“不可推出”。

### synthesis_conflict：综合与冲突裁决

- **操作**：识别两段材料的真实张力，依据版本、时间、适用范围、方法优先级或限定语解决，保留未解决部分。
- **适用**：一段给出一般规则，另一段给出在先批准的例外、修订或限定；两段必须都有必要。
- **不适用**：简单拼接互不冲突的信息，或凭“后出现的总是对”机械覆盖。
- **区分度**：2 分同时给出裁决、控制条件和不过度概括；只引用其中一段不能满分。若材料没有足够依据，应保留未知，而非编一个和解方案。

四题的标签不同并不自动代表构念不同。若题干归一化后近似、答案 claim 相同、认知步骤相同或只是换对象复述，应合并为一题并承认材料不足以支持完整四题。

## 3. 可作答性与区分度检查

对每题依次做“遮答案作答”：

1. **只读 task + input_material**，不读 reference_answer/evidence，能否独立推出唯一目标结构？
2. 输入是否包含全部必要规则、表头、单位与冲突版本？若必须看 evidence 才知道题意，输入不完整。
3. 错误选项或错误推导是否有明确来源依据的判错方式？1 分是否比 0 分体现真实部分理解？
4. 材料不充分时，正确交付是否是 partial，而不是硬写 fourth item？
5. 是否存在多个同等合理答案？若是，增加判据、收窄范围或停止，而非把某个答案强行设为唯一。

“唯一”是指答案不变量可判定，不是只允许一个字符串。数值允许的单位换算、合理舍入、键顺序与同义表述必须由 `value_form`、`acceptance_rule` 和 rubric 明确容纳。

## 4. 泄题与重复防护

- 题干可说明要抽取的字段类型和对象，但不能复述 answer value、答案判断、冲突裁决词或可直接照抄的答案短语。
- 单纯的数字本身不作为泄题证据，因为总归一化数值可能大量误伤；但题干直接写出完整计算结果仍须人工删除。
- 工具的 token 检测只报警常见文字泄题，不能代替人工检查缩写、中文近义词、公式变形、布尔判断暗示或示例中的答案。
- 归一化重复题、近似高相似题、同操作+同意图+同 claim 都是缺陷。四题应要求不同的中间步骤，而非四个不同排版。

## 5. 偏差、歧义与科学边界

- 同一任务中的对象使用一致名称，不让无关背景知识、语言晦涩或表格式猜测成为主要难度来源。
- 难度应来自目标/干扰选择、关系建模、边界共同满足或来源冲突，而非缺字、模糊定位、冷僻常识和主观“最佳答案”。
- 避免因对象名称、地区、性别、机构等与测量构念无关的刻板线索影响推断；材料中的敏感属性只有在任务确有必要且许可允许时才使用。
- 不把相关写成因果、把未做检验写成显著、把低于检出限写成零、把未报告写成不存在。
- 对每条 uncertainty 标记其未决状态。只有材料明确解决后才能在参考答案中改成确定命题，并在 change_records 记录实际修订。
- 许可依据按 source_id 绑定实际来源；没有使用许可就缩小范围或交付 partial，不伪造 `data_license`。

## 6. 快照和可比性

`snapshot.py` 对整个实际题库做规范 JSON 的 SHA-256 内容寻址，并保存各题的完整、答案和 rubric 摘要。只有提供旧题库或含完整 bank 的快照时才生成 diff。

- 题项增删、题干、作答输入、任务意图、操作或材料范围改变：构念不可直接比较。
- 参考答案、rubric 或算术声明改变：需要重新评分旧作答。
- 仅改展示元数据：内容变化仍被记录，但不自动认定构念或评分不可比。
- 没有旧状态时状态为 `not_requested_no_previous_state_assumed`；绝不根据 change_records 想象旧答案。
