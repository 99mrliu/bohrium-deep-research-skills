# 失败模式分类表（Failure Taxonomy）

本表定义 `scripts/probe_failures.py` 探测的 12 类失败模式。每条含探测规则、示例、修法与对应评分风险。探针命中即写结构化失败样例 `{probe_id, 题目/字段, 原始输出摘录, 原因, 建议修法, 可否机修}`。

| 编号 | 失败模式 | 探测规则（机器可判定） | 示例 | 修法 | 可否机修 | 对应评分风险 |
|---|---|---|---|---|---|---|
| P01 | 空答案 | `items[].answer` 为空或 null | `"answer": ""` | 补答；无法回答时填诚实标记（如"未报告"）并写 uncertainty | 否 | 高：直接判未作答，该题零分 |
| P02 | 超长输出 | 单字段 >4000 字符，或文件 >500KB | 整段照抄材料充答案 | 压缩为结论+锚点；长摘录移入 sources | 部分（文件可机拆） | 中：截断、跑题扣过程分 |
| P03 | JSON 畸形 | `answers.json`/`items.json`/`result.json` 解析失败 | 尾随逗号、未闭合引号 | json.tool 定位修复；或由 checkpoint 恢复 | 是 | 高：交付物不可解析，整案失败 |
| P04 | 缺证据锚点 | `items[].evidence` 为空 | 有答案无出处 | 补锚点（第N段/表N/p.N）；全文未见填"全文检索未见" | 否 | 中：证据链缺失，诚信项扣分 |
| P05 | 诚实标记与数值混存 | 同一 answer 同时含"未报告/无法判断"等标记与带单位数值 | `"未报告，含量 0.05%"` | 数值结论与诚实说明分字段或分句 | 否 | 低：语义矛盾被判不诚实 |
| P06 | 子问漏答 | task.md 编号子问数 > items 条数 | 两问只答一问 | 逐问核对编号，补齐条目 | 否 | 中：漏答子问零分 |
| P07 | 契约缺字段 | result.json 缺 `output_contract` 字段或为 null（骨架阶段豁免） | 少填 `confidence` | 补答；无法作答保留 null 并写 uncertainty | 否 | 高：违反 output_contract，判不合格 |
| P08 | status 与内容矛盾 | status=成功 但有空契约字段；status=无法判断/拒答 但已填答案 | `"status":"成功"` 且字段为 null | 降级 status 或补齐字段；保持诚实一致 | 是（可机降级） | 高：诚实性造假，一票否决风险 |
| P09 | 定位格式非法 | evidence 非空但不匹配 第N段/表N/p.N/行N/para N/全文 | `"在中间那段"` | 改写标准定位格式 | 否 | 低：锚点不可核验，证据分打折 |
| P10 | 引文为空 | status=成功 但 sources 为空 | `"sources": []` | 回填 sources（文件名+定位） | 否 | 低：溯源链断裂 |
| P11 | 疑似抄题漏改占位符 | answer 含 TODO/FIXME/XXX/占位/待填/placeholder/示例答案 | `"answer": "TODO 待补"` | 替换为真实作答；T2 题卡清空模板占位 | 否 | 中：判抄袭或未完成 |
| P12 | 检查点 STALE 未处理 | checkpoint 记录的依赖 sha256 与当前文件不符或缺失 | 源材料更新后未重跑起草 | 重跑该阶段并 save 刷新，再交付 | 否 | 中：产物基于过期输入，复跑不复现 |

## 高危（high）处理纪律

- P01/P03/P07/P08 为高危：交付前必须清零；无法清零时 status 必须降级为"部分完成"并在 status_reason 指明局限。
- 探针退出码 = min(命中总数, 100)，命中本身不导致崩溃；判定依据以 `probes_report.json` 的 `summary.high` 为准。
