# 词项归一与术语漂移口径（term_cohorts.py 的完整规格）

目标：让"词项队列矩阵"成为**可复算**的证据——任何人拿到同一份 canon.jsonl
与同义词表，重跑脚本必须得到逐位相同的结果（stdlib only、无随机、无网络、
无时钟、排序键确定性输出）。

## 1. 分词

- 文本 = `title + " . " + abstract + " ; " + keywords`，全部小写。
- 英文 token 正则：`[a-z0-9]+`；CJK run 正则：`[\u4e00-\u9fff]+`。
- **bigram 只在标点分隔的片段内构造**：先按
  `. ! ? ; : 换行 ( ) [ ] " ' 、 ， 。 ； ： … — | / \ < > * _ ` ~ @ # $ % ^ & = + { }`
  切段，再在每段内取相邻 token 对。连字符与空格视为段内分隔符，因此
  "self-attention" 产生 bigram "self attention"；句号两侧的词不会拼成 bigram。

## 2. 停用词与保留规则

- 停用词表内嵌在 `term_cohorts.py` 的 `STOPWORDS`（英文功能词 + 学术八股词
  如 propose/approach/results/performance/baseline 等，约 180 个）。
  有意**不**把 model/method/network 列为停用词——它们是 "kernel method"、
  "foundation model"、"neural network" 等关键 bigram 的组成部分。
- 英文 unigram：长度 ≥3 且非停用词（"svm"/"cnn"/"lstm"/"bert" 可保留，
  "ai"/"ml" 被长度规则丢弃——如领域依赖此类双字母缩写，改用关键词字段或
  同义词表的字面匹配通道补回，见 §4）。
- 英文 bigram：两端都非停用词且各长度 ≥2。
- 中文（如出现）：含 CJK 的**关键词整词**保留为一个词项，另加其 CJK run 的
  **字符 bigram**。摘要自由文本不做中文分词——这是有意的简化：中文信号以
  作者标注的关键词为准，避免引入分词器依赖。两语词项应分开报告。

## 3. 文档频率过滤

- 词项的 df = 包含该词项的**文献条数**（不是出现次数）。
- 默认 `min_df = 2`：只出现一次的词项是噪声（拼写变体、一次性造词）。
- 极小语料兜底：若没有任何词项通过 min_df，降级为 df≥1 并打印 WARN；
  此时所有词项层面的结论都必须标注为 exploratory。
- 矩阵计数口径：`term_year_matrix.json` 中 term→year 的值是该年**包含该词项
  的文献数**（年度文档频率），不是原始词频——一篇文献刷十次同一术语不会
  放大其队列信号。

## 4. 同义词 / 术语漂移策略

- `synonyms.json` 为 JSON 对象 `{变体: 规范形}`；下划线开头的键（如
  `_comment`）被忽略，用于留档合并理由。
- 合并发生在**计数之前**：每条记录的词项集合先做 `syn.get(t, t)` 映射，
  再算 df 与逐年计数。因此改名不会制造新队列。
- **字面短语通道**：同义词表中出现过的任何短语（变体或规范形，长度不限，
  可以是 trigram 如 "pretrained language model"）会对每条记录的原始小写
  文本做子串匹配，命中即注入规范形。这弥补了分词器只产 unigram+bigram
  的缺口——规范形不必是分词器能产出的 n-gram。
- 起草流程（代理职责）：先无表跑一遍 → 读 top_terms.csv 高 df 词项的原文
  上下文 → 只对上下文确证同义者合并 → 同义词表作为**版本化工件**留档
  （写入 /app/work 并在报告证据节引用）。

## 5. 同名异义（同形异义）处理

一个词面在语料中承载两个概念时（如电力文献里的 "transformer"）：

1. **不要**把它并入任何规范形；
2. 抽取该词面的 3–5 条原文上下文人工判读；
3. 按多数语义决定保留/排除/拆分（拆分时用词项对如 "transformer 电力语境"
   在报告中说明，脚本层面只能整体保留或排除该词面）；
4. 把决定与支撑上下文记录的 canon id 写进 synonyms.json 的 `_comment`
   和报告的不确定性节。

## 6. 漂移检测报告（phase_segment.py 的 drift_report.json）

对同义词表中的每个规范形，报告**合并前**各变体的逐年字面文献计数 +
合并后队列的逐年计数。判读范式：

- 变体 A 计数集中在早期、变体 B 集中在后期、合并队列连续 ⇒ **术语漂移
  （改名），不是新兴主题**；
- 某变体出现而合并队列并不延续任何既有队列 ⇒ 才允许讨论"新主题"，
  且仍需阶段词项证据佐证。
