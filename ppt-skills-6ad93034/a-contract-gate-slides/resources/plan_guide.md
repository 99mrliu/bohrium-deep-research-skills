# plan.json 撰写细则

plan.json 是本 Skill 中唯一的模型创作面。骨架已由 plan_scaffold.py 按工单分好页序与角色，你只填四个字段：`title`、`bullets`、`figure`、`notes`。

## title
- ≤20 字，写本页的**主张**而不是栏目名。坏例：`实验结果`；好例：`注意力机制使翻译 BLUE 提升 2.0`。
- title 页写论文标题 + 一句话定位。

## bullets
- 每页 3–6 条；每条 ≤60 个中文字符（英文 ≤90 字符）；一条一个要点。
- 每条必须有 `anchor`：`p3`（论文第 3 页）/`fig2` /`tab1`。anchor 即门禁核验范围。
- **数字纪律**：bullet 里的每个数字必须逐字出现在锚定页文本里（digest 抄过来的就是安全的）。想要 `2.0 BLEU` 就先去 digest 确认原文写法；原文是 `2.8` 就不许写 `约 3`。
- 术语与符号与论文一致（模型名、数据集名大小写照抄）。

## figure
- 只能取 plan_scaffold 打印的 `figures_available`（已真实裁剪）。
- 一张图只配一页；结果页优先配图；图的出场顺序与论文一致。
- 没有合适的图就 `null`，绝不放占位图。

## notes（演讲备注，正式交付物）
- 1–3 句，写给本案例受众听的话：评审受众强调创新点与证据强度；导师受众强调进展与下一步；同行受众强调方法细节与可复现性。
- 备注可以展开 bullet 背后的逻辑，但数字同样不得超出论文。

## 好/坏对照

```json
{"text": "Transformer 在 WMT 2014 英德翻译达 28.4 BLEU，超既有最好结果 2.0", "anchor": "p1"}
```
好：数字 28.4/2.0 必须命中 p1 文本。

```json
{"text": "本文提出了一种全新的架构，效果非常显著，远超所有基线方法", "anchor": ""}
```
坏：无锚点、无数字、空话——门禁直接判 hard。
