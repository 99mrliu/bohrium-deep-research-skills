# 任务说明（合成示例 / synthetic, illustrative）

围绕研究问题「益生菌对抗生素相关性腹泻的预防效果」，对 `records.json` 中的 8 条合成题录
完成一次迷你系统综述流程：

1. 去重（标题规范化 + 年份为键）；
2. 题录级筛选（仅纳入随机对照试验、人群须为抗生素治疗患者）；
3. 全文级筛选（全文不可得者排除）并冻结纳入清单；
4. 生成 flow.json 并逐账轧平 PRISMA 计数；
5. 全流程 runlog 登记 + replay 确定性自证。

本任务仅用于演示 slr-replay-pipeline 的过程工程能力，不构成任何真实医学结论。
