# 重复判定政策（duplicate_policy）

> 系统综述的多库检索必然引入重复题录。本政策规定 verify_corpus.py 中
> V4（精确重复）与 V5（近似重复）的判定哲学、阈值依据与误杀处置。
> 重复计数直接喂给 PRISMA 流程图的 duplicates_removed 一栏，必须机器可复核。

## 1. 判定哲学

- **宁留档、不销毁**：重复记录不删除，而是标状态、记 duplicate_of、留理由。
  被标记录仍可在 corpus_report.json 中完整追溯。
- **首条优先**：同一重复簇中保留最早出现的记录（通常为首个数据库的导出版本），
  其余标 duplicate。保留哪条不影响后续筛选结论，但必须确定且可复现。
- **精确优先于近似**：V4 命中的记录不再参与 V5 判定（互斥）。V4 的确定性
  高于 V5，避免一条记录背负两种重复理由造成 PRISMA 计数歧义。

## 2. V4 精确重复

满足任一即判 duplicate：
1. 规范化 DOI 相同（去解析器前缀、小写后逐字符相等）；
2. `NFKC题名比较键 + 第一作者姓 + 出版年` 三元组相同——覆盖无 DOI 或
   DOI 著录不一致的重复（预印本与正式版、不同数据库著录差异）。

## 3. V5 近似重复与阈值 0.92

对未被 V4 命中的记录，两两计算规范化题名比较键的
`difflib.SequenceMatcher.ratio()`，≥ **0.92** 判 probable_duplicate。

**阈值依据**：0.92 对应"题名仅存在标点/大小写/个别词级差异"的情形
（同一研究的会议版与期刊版、数据库著录差异）。示例语料中仅标点差异的标题
比较键完全一致（ratio=1.0）；词序微调或个别词增删通常落在 0.92–0.98 区间。

**已知局限（必须写入 uncertainty）**：
- 同系列研究（如 "Trial-X 1-year results" 与 "Trial-X 2-year results"）题名
  高度相似但**不是**重复，可能被误标 → 故 V5 用 probable_duplicate 而非
  duplicate，强制人工复核；
- 短题名相似度天然偏高，假阳性率上升；
- 中文与英文题录分别比较，跨语言重复（同一研究的中英文著录）无法识别；
- O(n²) 两两比较，万条级语料耗时显著，大语料应分批或先按年份分桶。

## 4. 误杀处置（人工复核入口）

1. probable_duplicate 一律视为**候选**而非定论：Agent 必须逐对复核
   （对照作者、年份、venue、DOI），确认后在 result.json.change_records 留痕
   （"确认重复"或"撤销误标，恢复 verified"）。
2. duplicate（V4）置信度高，但若 DOI 著录错误也可能误链；复核成本最低的方式
   是人工比对 duplicate_of 指向的首条记录。
3. 复核结论必须回写 evidence_matrix（记录 id、判定、依据），不得只在叙述中提及。
4. 拿不准的对子按**不重复**处理（两条都进入筛选，在纳排阶段自然收敛），
   并把该对子列入 uncertainty——误杀真实文献的代价高于多筛一条。
