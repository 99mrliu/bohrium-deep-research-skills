# 任务说明（合成示例 / synthetic, illustrative）

围绕研究问题「远程康复对脑卒中后上肢功能的效果」，使用 slr-dual-screen 技能完成：

1. 按 criteria.json 的条款化纳排标准，对 records.json 中 12 条合成题录进行
   题录级（round 1）与全文级（round 2）双人独立筛选；
2. 用 screen_check.py 校验决策完整性，用 kappa.py 量化两轮一致性，
   对全部分歧用 adjudicate.py 仲裁并冻结纳入集；
3. 形成有来源定位的综合结论，区分事实、推断与无法确定的部分。

本目录所有数据均为虚构合成，仅演示流程，不代表真实文献。
