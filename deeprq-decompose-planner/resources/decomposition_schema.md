# 六要素拆解模式（decomposition schema）

研究问题必须拆成以下六要素后才能派活检索。每个要素在 decomposition_tree.json 的 facets 中留痕；缺失的要素显式标 null，不许省略。

1. 研究对象（population / 材料体系 / 任务类型）——决定检索式的主词。
2. 机制或干预（mechanism / intervention / 方法）——决定"原理/路径"类子问题。
3. 对照（comparator / baseline）——决定比较类子问题的可比字段。
4. 结局指标（outcome / metric）——决定提取哪些数值与效应方向。
5. 时间范围（time window）——决定检索式的时间限定与趋势分析口径。
6. 证据要求（evidence level）——决定纳入的设计层级（RCT/荟萃/队列/综述/观点）。

## 子问题（SQ）质量线

- 可独立检索：每个 SQ 自带中英文检索式，单独提交也能返回相关文献。
- 有验收标准：acceptance 字段写明"几条什么类型的文献算达标"。
- 有依赖标注：depends_on 为空 = 前置可先行；非空 = 依赖结果（如术语口径）才能检索。
- 拒绝关键词式拆解：把原句改写成几个词不算 SQ；SQ 必须含"检索什么、比较什么、纳排什么"。

## 依赖成环处理

plan.py 检测到环时把环内 SQ 摊平到同一层并给出警告；Agent 必须回到拆解步合并或删除造成环的 SQ，不允许带病派发 W2。
