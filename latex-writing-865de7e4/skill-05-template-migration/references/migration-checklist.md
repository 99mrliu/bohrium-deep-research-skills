# 模板迁入通用检查清单

把已有稿件迁入期刊/会议/学位论文模板时的核对清单。按"先证据、后改动"
的顺序使用：`clsinspect.py` 与 `pkgconflict.py` 出报告，Agent 对照本清单
逐项落实，`finalize.py` 收口验证。

## 1. 模板必填项

- [ ] 逐项落实 `template_interface.md` 中列出的必填字段（标题、作者及
      单位、摘要、关键词、期刊名、基金号、学位论文的扉页字段等）。
- [ ] 每个字段**非空且非占位**：不得出现 TODO、TBD、XXX、"待填"、
      空 `{}` 或仅含标点的值。
- [ ] 字段值必须来自原稿或 task.md 给出的事实；原稿没有的字段（如
      期刊名）按 task.md 指示填写，既无来源又无指示时在 uncertainty
      中说明，禁止编造。

## 2. 版式约束

- [ ] 不手改页边距、栏数、行距、页眉页脚：这些由模板类控制，稿件侧的
      `geometry`/`setspace`/`fancyhdr` 调用原则上删除。
- [ ] 不保留原稿对章节标题样式的重定义（`\titleformat`、`\@startsection`
      补丁等），交给模板。
- [ ] 字号、字体命令（`\fontfamily`、`\fontsize` 直调）出现在正文局部
      强调之外的地方时，删除或改成语义命令（`\emph` 等）。

## 3. 宏包与加载顺序

- [ ] 对照 `conflicts.md` 逐条处置：顺序问题调整先后，冲突对按模板
      指定二选一，与类重复的删除稿件侧，模板禁用的移除并改用模板机制。
- [ ] 删除某个宏包后，全文搜索其提供的命令是否仍在使用；在用则改写
      或换模板认可的等价方案（脚本不自动删，由 Agent 判断）。

## 4. 字体与编码

- [ ] pdfLaTeX 模板：原稿的 `inputenc`/`fontenc` 与模板要求不一致时以
      模板为准；XeLaTeX/LuaLaTeX 模板不应再加载 `inputenc`。
- [ ] 原稿使用而模板未覆盖的字体宏包（如 `newtxtext`）确认模板无字体
      规定后方可保留。

## 5. 图表与路径

- [ ] 图片引用改为相对路径并与交付目录结构一致；必要时设置
      `\graphicspath`，不使用绝对路径。
- [ ] 浮动体参数（`[htbp]`）按模板习惯调整；模板定义了专用浮动环境
      （如 `scheme`、`algorithm`）时迁移过去并保留 `\label`/`\caption`。
- [ ] 图表文件本身不丢失：交付时与迁移稿一并放置。

## 6. 文献样式

- [ ] `\bibliographystyle` 以模板指定为准；模板用 biblatex 时把
      natbib 式命令替换为 biblatex 等价命令。
- [ ] `thebibliography` 手排文献迁移时条目文字逐条保留；`\cite` 键
      不变，迁移前后引用键集合一致（`clsinspect.py` 报告里有清单）。

## 7. 收口验证

- [ ] `finalize.py` 的 compliance 总结论为"合规"才允许交付；任一必填
      字段缺失/占位、章节未映射、编译失败都属于不放行。
- [ ] `intent_diff.md` 显示正文零文字改动；有改动时逐条确认是迁移
      需要（如命令替换）还是误改，误改必须回滚。
- [ ] result.json 的契约字段逐字段镜像，缺材料的字段给 null + 说明。
