# 任务（合成示例，非正式案例）

`broken/` 是一个故意损坏的 LaTeX 工程（主文件 `main.tex`，以 `\include`
引入 `chapters/methods.tex`，文献库 `refs.bib`），已知含 4 处故障：

1. 引用了未安装的宏包；
2. 一个未定义命令；
3. 一处 `$...$` 内花括号不配平；
4. 一个未知 `\cite` 文献键。

要求：

1. 用脚本完成有界多轮编译与日志诊断（定位到文件 + 行号 + 根因，
   级联错误折叠标注）；
2. 由 Agent 依据诊断建议修复工程（脚本不改稿）；
3. 修复后真实重编译验证：0 错误、产出新鲜 PDF，记录页数与首页文本抽查，
   并渲染首页预览供目检；
4. 装配 `result.json`，逐字段镜像 output_contract。
