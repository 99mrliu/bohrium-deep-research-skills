# 任务说明（合成示例（synthetic example），非正式案例结果）

你拿到一个小型 LaTeX 工程（`project/`，主文件 `main.tex`）。请：

1. 固化该工程的一次完整构建为构建谱系 manifest：环境（引擎/发行版/工具版本）、
   文档类与宏包逐版本清单、使用字体、精确编译命令序列与轮次、全部输入文件
   SHA256、PDF 页数与全文文本哈希。
2. 模拟他人环境：把源码打包成 zip 解压到干净目录，按 manifest 重建，并逐判据
   比对一致性（源码哈希、版本清单、引擎、轮次、aux 收敛、页数、全文文本），
   对 PDF 字节级差异如实说明。
3. 交付 manifest、重建比对报告与 result.json；任何工具缺失或版本漂移必须诚实
   列出，不得含糊带过。
