# 事实抽取与比对规则

本文件说明 matscan.py / texaudit.py 使用的确定性规则，供 Agent 阅读报告时
理解每条判定的依据。规则只做机械匹配；语义裁定永远由 Agent 完成。

## 1. 事实类型与锚点

| 类型 | 抽取规则 | 锚点形式 |
| --- | --- | --- |
| `num_unit` | 数字 + 紧邻单位（m/s、kg、mM、nm、ms、h、°C、eV、Hz、V、W、J 等，见脚本内单位表） | `文件:行号`；PDF 为 `文件:p页码` |
| `percent` | 数字 + `%`（兼容 LaTeX 转义 `\%`） | 同上 |
| `sample_size` | `n = 数字` / `N = 数字` | 同上 |
| `data_value` | CSV 中纯数值单元格（含科学计数法） | `文件:行号`（行内完整内容记入 line_text） |
| `cite_key` | `\cite{...}` 及其变体（`\citep`/`\citet` 等），多键拆分 | 同上 |
| `bib_key` | .bib 的 `@类型{键,` | 键所在行号 |
| `term` | `\newglossaryentry` / `\newacronym` / `\newcommand` 定义名 | 同上 |
| `caption` | `\caption{...}` 全文 | 同上 |

材料侧的锚点一律指向**材料文件**；稿件侧条目（texaudit）锚点为
`稿件名:行号`。PDF 无行号概念，页码代行锚点并在 materials_index.md 中注明。

## 2. 比对判定

**自我排除**：被审计稿件若同时作为材料被 matscan 扫描（常见于改稿任务），
texaudit 会把锚点位于该稿件文件的事实条目从比对库中剔除——稿件是审计
对象，不是它自己的来源。

对稿件中每条事实，按以下优先级判定（数值类按"数值组"
`{num_unit, percent, sample_size, data_value}` 跨类型比较）：

1. **matched**：材料中存在数值相等（浮点容差 1e-9 相对误差）且单位相容
   （单位相同或一方为空）的条目；cite_key 要求键逐字符等于某个 `bib_key`；
   ref 要求 `\label` 在稿件内已定义。报告给出材料锚点。
2. **conflict**：无精确匹配，但存在**单位相容、数值不同、上下文强重合**
   的材料条目。强重合 = 共享 ≥1 个拉丁词（≥3 字母）或 ≥2 个中文二元组。
   仅数值类可判 conflict；cite_key 键不同不构成 conflict。
3. **unmatched**：以上皆不满足。脚本给出按数值接近度排序的至多 3 条候选，
   全部显式标注 `weak`（弱匹配）。弱匹配只是复核线索，不是证据。

另设**材料间口径冲突**预警：两个不同材料文件中数值不同、上下文强重合的
条目对，无论稿件是否引用都会列出。

## 3. 单位相容与换算

- 脚本只做字符串级单位比较 + 空单位通配，**不做自动单位换算**。
- 形如 `500 ms` 与 `0.5 s` 的等价关系由 Agent 语义判断：若确认等价，可在
  change_log 记为"单位换算后 matched（材料 file:line）"，不得让脚本强行
  判 matched。
- 数值写法差异（`92.4%` 与 `0.924`、科学计数法）同理，由 Agent 裁定。

## 4. LaTeX 注释的处理

texaudit 抽取稿件前先剥离未转义 `%` 起的注释——注释是 Agent 的留痕空间，
不是稿件内容；把处置说明写在注释里（如"已删除材料外数值 9 h"）不会
触发误报。转义的 `\%` 不受影响，百分比照常抽取。matscan 扫描材料时
不剥离注释（材料以召回为先）。

## 5. 已知局限（Agent 读报告时需留意）

- 无单位的裸数字（页码、年份、编号）不抽取；task.md 若含此类关键数字，
  请 Agent 人工补查。
- 表格、数学环境内的数字按普通文本行抽取，可能遗漏被命令拆开的数值。
- 上下文强重合是启发式：同一段反复出现的指标（如多处"准确率"）可能产生
  多条 conflict 候选，Agent 应按 task.md 口径与材料优先级裁定。
- PDF 经 pdftotext 转换后行列可能错位，页码锚点仅供回查定位。
