# 充分性五级判据（sufficiency rubric）

裁决等级由脚本机械推导，本表是等级语义与作答义务的唯一权威解释。

| 等级 | 名称 | 机器判据 | 作答义务 |
|-|-|-|-|
| L5 | 充分可答 | 全部证据面命中且无相关冲突 | 正面作答，每个关键论断带来源坐标 |
| L4 | 基本可答 | 覆盖率 ≥0.75，或冲突可按版本规则消解 | 作答 + 显式限定语（"据当前版本""仅 X 报告提及"）；冲突须在答案中说明采用哪一侧、为什么 |
| L3 | 部分可答 | 0.4 ≤ 覆盖率 < 0.75 | 只答已命中证据面支持的部分；逐面列出未命中部分；禁止把未知部分写成"一般认为" |
| L2 | 证据不足拒答 | 覆盖率 < 0.4 | 拒答。标准句式："库中无充分依据回答该问题。已检索证据面：…；未命中：…；需要补充：…（哪类文件/哪个版本/哪个字段）" |
| L1 | 无法判读 | 0 个可索引文件或问题不可解析 | 说明阻塞原因（权限、格式、工具缺失），给出解除阻塞所需动作 |

## 证据面（facet）类型

- entity：命名实体/专名（样品编号、材料名、方法名）。未命中 → 该实体
  库内无记录，通常直接 L2。
- numeric：问题中的数值+单位。命中说明库内有该数值的候选语境。
- keyword：实义词。命中为弱证据。

## 冲突的处理

conflict_registry.json 中与本题命中术语相关的冲突必须在答案或
uncertainty 中交代：版本差异 → 以当前版本为准并注明历史版本数值；
同源不同表 → 并列双方坐标，标明不一致，不得任取其一静默处理。

## 回降规则（demotion）

模型可在 work/model_verdicts.json 申报裁决（带理由），但申报等级高于
机器等级 ≥2 级时，suff_verdict.py 强制回降到机器等级 +1 并留痕。
设计意图：防止"措辞自信"替代证据；模型正确的争胜路径是补充检索提高
覆盖率，而不是提高申报等级。
