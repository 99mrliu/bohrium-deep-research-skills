# 合成示例任务（虚构数据，非真实案例）

研究问题：对三个来源（Crossref 查询响应、EuropePMC 查询响应、出版商落盘 JSON）
返回的文献记录进行身份去重与确定性合并，产出 canonical 记录清单。

要求：
1. 同一作品在不同来源重复出现时归并为一条 canonical 记录，保留全部来源留痕。
2. 一条记录只有 PMID、另一条只有 DOI 时，只能依据引用图中显式给出的
   对应关系互链，不得臆造映射。
3. 题名相同但年份不同的记录不得合并，判定须留痕。
4. 模糊相似的记录不得自动合并，进入仲裁队列由模型裁决。
5. 每条 canonical 记录携带逐字段来源溯源；字段冲突写入冲突日志。
