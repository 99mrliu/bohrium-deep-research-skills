# 任务说明（合成示例，全部数据为虚构）

（本案例全部文献、DOI、PMID、期刊与查询参数均为合成示例，非真实案例。）

研究问题：梳理自适应光子路由及相关器件方向在 Crossref、EuropePMC 与出版商
接口三个来源中的题录记录。

要求：

1. 建立查询台账：以材料记录为准，提取每个来源库实际执行的查询、参数、命中
   总数与分页游标；某库查询未记录时如实标注 query_unrecorded。
2. 编排审计：检查各库查询是否为机械复制的同一条字符串；检查分页完整性
   （Crossref 声明命中 5 条但仅返回两页共 4 条，应识别 suspected_truncation）。
3. 为每条记录建立全链溯源账本，每个字段必须能回链到原始响应的 JSON 路径。
4. 两级精确去重：标识符相同或归一题名相同者并入同一 canonical；模糊对进
   unresolved 交人工仲裁。
5. 链完整性核验：任何断链显式报告，不得静默修补；同输入重放输出必须一致。
6. 与组织方本地增量导入状态对账：输出 new / already_imported / updated /
   conflicting 四类 diff。
