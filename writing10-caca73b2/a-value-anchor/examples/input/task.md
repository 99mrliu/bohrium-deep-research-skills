# 任务（合成示例 SYNTH-EXAMPLE-001）

根据 `materials/` 下的虚构合成材料，撰写一段"结果"与一段"讨论"（中文，学术书面语）。

要求：

1. 结果段只陈述观察事实，按图序组织；每个进入正文的数字必须携带台账锚点 `[Vnn]`。
2. 讨论段做概括与解释，机制性解释标注"推测"；仅可使用材料中给定的信息，不得引入外部文献。
3. 误差以 SD 表示，不得与 SEM/CI95 互换；无检验支持的表述不得使用"显著"。
4. 交付：`result.json` 满足 `case.json` 的 `output_contract` 全部键。

> 注意：本任务的全部数据为虚构合成数据，仅演示接口与流程。
