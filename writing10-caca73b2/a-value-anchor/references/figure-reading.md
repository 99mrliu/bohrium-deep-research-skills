# 读图与读表规则（value-anchor-rd 参考）

本文件规定从研究材料读取数值并转写进正文时的统一规则。核心原则：文字值优先于图上估读；任何读数必须保留其来源、单位与误差类型。

## 1. 单位与换算

- 进入正文前统一为该领域惯例单位，并在首次出现时注明。常见换算：
  - `mg/mL = g/L`（数值不变）；`µg/mL = mg/L`（数值不变）。
  - `mM = mmol/L`（数值不变）；`µM = µmol/L`。
  - 百分比与分数：`0.32 = 32%`，正文按材料原样使用一种形式，不来回切换。
- 换算必须在台账 note 中记录"原值、原单位、换算关系"，换算后的值与原始值视作同一条目，不得当作两个独立证据。
- 材料单位本身可疑（如量级明显不符）时，按材料原样引用并在 uncertainty 声明，不擅自"纠正"。

## 2. 有效数字与修约

- 正文保留的有效数字不超过材料原始精度；材料给出 1.85 即写 1.85，不写成 1.850 也不四舍五入为 1.9。
- 派生量（如变化百分比）确需计算时，修约到与原始精度相称的位数，并在 change_log 记录计算式；能避免计算就避免，优先引用材料已给出的差值/比值。
- 审计容差默认 tol=0.02（相对误差 2%），仅用于吸收末位修约差异；p 值与 n 强制精确相等，不接受任何容差。

## 3. 误差棒含义（SD / SEM / CI95）

- 三者统计含义不同：**SD** 描述数据离散程度；**SEM** 描述均值估计精度；**CI95** 描述参数估计区间。正文中不得互换、不得混写，不得由 SEM 反推 SD 冒充材料原值（确需换算时写明换算式并记入 change_log）。
- 图注或方法学未注明误差棒含义时，正文写"误差棒含义未注明"，台账 error.kind 记 `unknown`，语气按中等置信处理。
- 材料以 `mean ± x` 给出且同行出现 SD/SEM 字样时，按字样归类；无任何字样时 kind=unknown。

## 4. 多面板图与补充材料

- 引用多面板图必须带面板字母：图 1a、图 1b；正文论断与面板一一对应，evidence_map 定位到面板级。
- 补充材料编号（图 S1、表 S2）与主文编号不得混淆；引用时保留"S"前缀。
- 图内标注值（柱顶数字）优先级高于按坐标刻度估读；坐标为对数刻度时禁止线性估读。

## 5. 估读值写法

- 仅当表格、统计输出、图内标注三类来源全部缺失时才允许估读。
- 估读值正文必须写"约"（约 3.5 mmol/L），台账 confidence=low，note 记录"依据图 X 纵轴刻度估读"。
- 估读值只支撑方向性、量级性论断，不得用于精确比较，不得参与派生计算。

## 6. 统计量转写模板

- t 检验：`t(df) = 7.95，p < 0.001`（df 保留在括号内；p 的比较符按材料原样，"<"不得写成"="）。
- 方差分析：`F(2, 33) = 4.56，p = 0.018`。
- 置信区间：`均值差 0.65 mmol/L，95% CI [0.48, 0.82]`。
- 样本量：`n = 10/组`；组间 n 不同时分别列出。
- 相关系数：`r = 0.42，p = 0.032`。
- 检验条件随统计量一并转写：双侧/单侧、alpha 水平、校正方法（材料给出时）。
- 无对应检验输出的比较，正文只写观察到的方向与幅度，不出现"显著""极显著"。
