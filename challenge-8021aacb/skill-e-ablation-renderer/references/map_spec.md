# 结构图与可视化规范

## 图元素

| 元素 | 视觉 | 语义 |
|---|---|---|
| 节节点（蓝框） | `节 SEC01` + 标题 | 一级/二级标题 |
| 论断节点（红框） | `论断 N005` + 句首 | 含论断线索词的句子 |
| 证据节点（绿框） | `证据 N007` + 句首 | 含数据/图表/引用线索的句子 |
| 虚线箭头 | 证据 → 论断 | `supports?` 可视化近似：同节内证据指向其后最近论断 |
| 虚线边框论断 | — | 可视化判定的孤立论断（无就近证据），提示人工复核论证链 |

## 解读纪律

1. `supports?` 边是**就近匹配的可视化近似**，不是人工判定的论证关系；孤立论断只是「值得人工复核的位点」，不是自动立案的缺陷。
2. 渲染产物（SVG/HTML）是诊断的**附件**，主结果仍是 diagnosis JSON 与编辑计划；图帮助作者定位，不替代文本证据。
3. SVG 与 HTML 均为 UTF-8 文本，符合 Skill 资源「无二进制」约束；运行时若环境提供渲染工具（office-renderer / latex），可另转 PDF/PNG 预览，属运行时产物。
4. 图中句子截断到 52 字符仅为排版；正式引用必须回到 diagnosis 的完整逐字 quote。

## 文件

- `structure_map.svg`：结构图（文本 SVG，浏览器/编辑器可直接查看）。
- `report.html`：自包含报告，内嵌 SVG + 诊断表；单文件可分发。
