# 输入失败分类与处置（异常处理评分项的对应表）

| 失败模式 | 识别信号 | 处置 | result 标注 |
|---|---|---|---|
| 缺章节 | 无方法/结果/结论中任一整节 | 不视为材料失败：作为「章节结构」类 finding 记录 | 正常诊断，finding 指向现存文本 |
| 无参考文献 | 全文无引用列表且无文内引注 | 论证链维度中「文献类论据」检查标「无法执行」 | uncertainty 记「引用证据范围缺失」 |
| 图表缺失 | 正文引用「图 2」但材料无图 | 不猜图内容；相关论断的证据强度按「无图」评估 | uncertainty 记缺失图表编号 |
| 公式缺失/乱码 | 公式区为乱码或图片占位 | 跳过公式内容判断，不臆造公式含义 | uncertainty 记受影响段落 |
| 格式混乱 | 标题层级矛盾、编号跳跃 | 先按文本语义重建大纲，重建规则记 change_record | change_record 记重建动作 |
| 稿件截断 | 末段不成句或无结尾章 | 结论边界维度降 partial；不外推未见内容 | uncertainty 记「疑似截断」+ 位置 |
| 整份不可读 | 解码/解包全失败 | 不产出任何诊断 | status=failed + 逐文件失败原因 |
| 多稿件混合 | 输入含多个独立稿件 | 以 task.md 指定者为准；未指定时在 uncertainty 请求澄清并选字节最大者 | uncertainty 记选择依据 |
| 材料与任务错配 | 材料是数据表而任务要求结构诊断 | 按材料实际形态降级为可读性/结构化检查 | status=partial + 错配说明 |

## 通用原则

1. 材料缺失、无法判断、运行失败三者分别说明，不混写。
2. 所有「跳过」都必须可在 result.json 中找到对应条目；评审应能重建每一次放弃的决策。
3. 异常处置本身消耗预算——识别信号出现即处置，不反复重试同一失败操作（同一策略失败两次即换路）。
