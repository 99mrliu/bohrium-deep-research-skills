# 误报控制手册：结构缺陷 vs 风格偏好（防止把风格当结构错误）

评分明确惩罚「虚构不存在的缺陷」与「把风格偏好当成结构错误」。本手册给出三条纪律与对照例。

## 纪律

1. **无文本证据不立案**：每条 finding 的 `quote` 必须逐字摘自稿件；`location` 必须可指回（章节+段落序号或锚点）。无法同时给出的候选，写入 `dimension_clearance` 的「已排查未立案」而非 findings。
2. **纳入条件全满足才立案**：taxonomy_six.md 每个子类的纳入条件是合取式，缺一条即排除；排除理由可留痕在 clearance。
3. **可证伪表述**：defect_class 写成可被作者复核推翻的形式（「该论断在全文无支撑」而非「论证不充分」）。

## 对照例（同一句子，立案与排除）

| 文本 | 判定 | 理由 |
|---|---|---|
| 「我们的方法最优。」结果章无任何对照实验 | 立案：结论边界-绝对化 | 最高级断言 + 全文无对照，两条件均满足 |
| 「我们的方法最优。」结果章有与三个基线的完整对照表且全胜 | 排除 | 断言有全覆盖对照支撑，属证据问题而非结构问题 |
| 「因此，该材料具有工业应用前景。」无工况/稳定性数据 | 立案：结论超界 | 结论外推超出实验条件 |
| 段落之间无「然而」「此外」等过渡词，但话题衔接可由文本推出 | 排除 | 过渡词缺失是风格；过渡缺失须满足「无法推出为何相邻」 |
| 摘要复述了引言的研究动机 | 排除 | 摘要—正文呼应是体裁要求，见 taxonomy 维度 5 排除条款 |
| 引言贡献清单第 3 条在正文无对应工作节 | 立案：贡献超界 | 逐条核对贡献清单与正文节后成立 |

## 空话黑名单（coverage_gate.py 机器拦截）

「建议作者注意」「建议加强」「建议完善」「逻辑可以更严密」「建议润色」「增强可读性」等不含操作对象的表述一律改写为：操作（移动/合并/拆分/收窄/删重/补过渡/补限制）+ 对象位置 + 目标位置。

## 严重度标尺

- **high**：使「问题—方法—结果—结论」闭环断裂（RQ 悬空、关键论断断裂、结论整体超界）。
- **medium**：局部断裂或成段重复，修复限于少数段落。
- **low**：衔接、铺垫位置、单句尺度问题。
判 high 需在 rationale 写明闭环上被切断的是哪一环。
