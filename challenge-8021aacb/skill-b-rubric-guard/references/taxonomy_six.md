# 六维结构缺陷分类法与纳入/排除判据（Skill B 核心资源）

每条 finding 必须落入某一维的**具体子类**，并同时满足该子类的「纳入条件」全部条款；不满足任一条款即排除（宁缺勿滥）。风格偏好见 false_positive_playbook.md。

## 维度 1：研究问题（RQ 与贡献主张对齐）

| 子类 | 纳入条件（须全部满足） |
|---|---|
| RQ 缺失 | 引言全文无一个可回答的问题句或目标句；且后文无回收句 |
| RQ 悬空 | 引言提出的问题句在结果/结论中无任何对应陈述（逐句核对后确认） |
| 中途换题 | 方法/结果实际回答的问题与引言陈述的问题对象不同（对象、指标或场景至少一项变更） |
| 贡献超界 | 贡献清单中的某项在正文无任何对应工作节；或正文完成的工作未进贡献清单 |

排除：引言写得「不够吸引人」、问题句位置不符合个人偏好——风格问题。

## 维度 2：章节结构（顺序与篇幅服务于论证）

| 子类 | 纳入条件 |
|---|---|
| 顺序倒置 | 后文依赖的定义/方法首次出现于其使用之后（给出两处位置证据） |
| 铺垫缺失 | 某结论依赖的概念全文未引入（指出结论位置与缺失概念） |
| 细节前置 | 大段实现细节出现在方法主线之前并打断论证（引用起止位置） |
| 该合未合 | 两节内容高度重叠且各自不达独立成节信息量（给出重叠证据） |
| 篇幅失衡 | 某节占比与论证地位明显不符且影响信息获取（给出占比数据） |

排除：章节标题命名风格、是否使用编号小节。

## 维度 3：论证链（论断—论据闭环）

| 子类 | 纳入条件 |
|---|---|
| 断裂 | 存在论断句，其支撑材料在全文中找不到（说明检索范围） |
| 跳跃 | 论据到论断之间缺中间推理步骤，且该步骤非领域常识 |
| 循环 | A 句以 B 为据、B 句又以 A 为据（给出两句位置） |
| 强度不足 | 论据类型撑不起论断强度：单次观察撑全称、相关撑因果、n 极小撑普遍结论 |
| 论据闲置 | 大段数据/实验结果未被任何论断引用 |

排除：论证「可以更有说服力」但现有链条完整——不属于结构缺陷。

## 维度 4：段落关系（衔接与信息流）

| 子类 | 纳入条件 |
|---|---|
| 过渡缺失 | 相邻段落话题切换且无承接句，读者无法从文本推出为何相邻 |
| 顺序颠倒 | 段落间存在明确依赖（如先给结论性陈述再给其数据）且影响理解 |
| 段落杂糅 | 单段含两个以上互不隶属的论点，拆分对象明确 |
| 指代断裂 | 「上述/该方法/图 X」类指代在其前文找不到所指 |

排除：过渡词使用频率、段落长度偏好。

## 维度 5：重复内容（冗余而非强调）

| 子类 | 纳入条件 |
|---|---|
| 逐字重复 | 两句/两段文字完全相同或仅差标点 |
| 同义复述 | 两句表达同一命题且后句无新增信息（给出两处的命题对齐） |
| 跨章重复 | 同一内容在引言/方法/结果多处完整展开而非呼应式回指 |

排除：摘要与正文的概括性呼应、结论对结果的合法回指。

## 维度 6：结论边界（论断尺度不超证据）

| 子类 | 纳入条件 |
|---|---|
| 结论超界 | 结论断言行外推超出实验条件（对象、工况、规模任一项超出） |
| 因果冒充 | 数据仅支持相关/伴随，行文使用因果动词（导致、证明、决定） |
| 限制缺失 | 存在明显适用限制（样本、环境、假设）且全文无限制说明段 |
| 绝对化 | 全称/最高级断言无全覆盖对照（「最优」「所有」「完全」） |

排除：谨慎措辞风格偏好；结论语气强弱但范围未越界。
