# 图表工程参考规范

## 图表—数据绑定规范

1. 每张图必须先在 figure plan JSON 中声明：`id`、`type`、列绑定（`x`／`y`／`group`）、`title`。渲染器只校验计划，绝不擅自改列、改图型、改标题。
2. 轴标签一律由数据字典生成：`显示名 (单位)`。被绘制的列没有字典条目、或条目没有单位时，不猜测、不沿用旧图、不编造：记录 `unit_unknown` 异常，轴使用裸名，图标记 `needs_review`，并在 `result.json` 的 `anomalies` 中说明。
3. 图例（或分组轴刻度）的文字必须等于数据中分组水平的精确值（字符串化、排序后枚举），禁止手工重命名后再与按原名统计的表混用。
4. 标题只来自计划；渲染器不自动拼接标题，避免“标题宣称的指标”与“实际绘制的列”不一致。
5. 每张图附带 `<id>.figure_data.csv`：被绘制的精确数值（全精度）与首行注释中的剔除空值行数 `dropped_null_rows`，使任何人可脱离原图复算。
6. manifest 记录 `source_csv_sha256` 与 `rendered_with`（matplotlib 版本），保证图与某一确定输入字节流绑定。

## 高频静默错目录

1. **轴单位与字典不符**：轴写“MPa”而字典单位是“kPa”，或轴无单位而字典有单位。防御：轴标签只由字典生成；QC 校验轴标签包含字典单位字符串。
2. **图例顺序与分组统计错位**：分组按一种顺序绘图、按另一种顺序填统计表。防御：分组水平统一排序枚举，计数与水平名绑定存储（`groups.counts`），QC 从原始数据重算比对。
3. **截断坐标轴未声明**：条形图纵轴不从零开始却不声明，夸大组间差异。防御：默认不截断；若确需截断，必须在计划与标题/注记中显式声明。
4. **聚合图不标 n**：均值±标准差条形图不标样本量，掩盖小组别。防御：条形图必须在每根条上标注 `n=`，manifest 记录各组 `counts`。
5. **双轴图误导**：左右纵轴量纲不同、比例各自缩放，制造虚假相关。防御：本工具不支持双轴图；确需对比时画两张单轴图或先标准化再同轴。

## 确定性渲染清单

1. 后端固定为 `Agg`；显式设置全部关键 rcParams：`figure.dpi=150`、`savefig.dpi=150`、`figure.figsize`、`font.family` 与字体回退链、`axes.grid`、`grid.alpha`、`axes.unicode_minus=False` 等，不依赖用户环境里的 `matplotlibrc`。
2. 全流程禁止随机数；不使用随机 jitter。若未来确需 jitter 以缓解散点重叠，必须固定种子并把种子值记入 manifest。
3. 分箱数、点大小、柱位置等一律由数据确定性推导（如 `bins` 由 n 的平方根规则确定），不使用交互式默认值。
4. 建议位图与矢量双输出（`--formats png,svg`）：PNG 供报告嵌入与 QC 魔数核验，SVG 供出版排版；二者由同一次渲染产生，杜绝“两版图不一致”。
5. 同一 CSV + 同一计划 + 同一 matplotlib 版本 ⇒ 同一 manifest 数值与同一布局；复跑差异即视为事故排查信号。

## 可发表检查表

- 分辨率：位图 dpi ≥ 150（本工具固定 150）；投稿要求 300 时以 `--formats` 加出高分辨率版本或改用矢量。
- 字体：无衬线字体、字号 ≥ 8pt；中文标签确认运行环境有中文字体（回退链：DejaVu Sans → PingFang SC → Noto Sans CJK SC → Microsoft YaHei → SimHei）。
- 色盲友好：默认单色系图（直方图、散点、箱线、条形）天然安全；多系列着色时建议采用色盲安全调色板并辅以线型/标记区分。
- 单位：每个数值轴均有单位且与字典一致；无单位者已标记 `needs_review` 并在交付说明中解释。
- 样本量：聚合图标注每组 `n`；所有图在 manifest 中给出 `n_plotted` 与 `dropped_null_rows`。
- QC：`figforge qc` 全 PASS（PNG 魔数、n/min/max、分组计数、单位字符串、图下数据行数）后方可交付。
