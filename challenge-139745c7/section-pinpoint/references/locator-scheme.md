# 锚点定位规则（section-pinpoint references）

## locator 语法

```
<相对路径> [› p<物理页号>] [› §<章节路径>] › ¶<段序号>
```

- 物理页号只对多页文件（PDF）出现，从 1 起；与阅读器页码一致。
- 章节路径取当前最近 ≤3 级标题，用 `/` 连接。
- 段序号为该页/该节内自然段序号，从 1 起。
- 每条锚点同时携带：`anchor_sentence`（段落首句 ≤120 字）、`char_start`/
  `char_end`（抽取文本内字符区间）、`page_printed`（见下）。复核方式：
  重新抽取同一文件 → 按 locator 找到同一段 → 比对 anchor_sentence 是否逐字一致。

## 标题识别

1. Markdown 标题：`#`–`######`，级别即 `#` 数。
2. 编号标题：`2.`、`2.1`、`3.2.4` 开头且行长 <70，级别为点号数+1。
3. 全大写短行（3–60 字符，如 `EXPERIMENTAL SECTION`）记 2 级。
4. 都不满足的行并入正文段落。

## 印刷页码与物理页错位

PDF 物理页 = `pdftotext` 输出中 `\f` 分隔的页序。印刷页码从每页末三行
匹配 `第N页` / `- N -` / `Page N` 得到；匹配不到则 `page_printed=null`
并在引用时只用物理页。**绝不用物理页冒充印刷页**；两者都给时，答案中
写作“物理页 7（印刷页 5）”。

## 双栏与版式

PDF 统一用 `pdftotext -layout` 保留栏位；复杂跨栏表格可能错序，命中此类
段落时在答案 note 中声明“版式抽取，顺序以原文为准”。跨页段落按页切开，
各自成锚点，不复原——避免虚构跨页连续性。

## 无文本层扫描件

抽取结果全空 → 文件状态 `needs_ocr`，不进锚点库；内容类提问的 uncertainty
必须列出这些文件，不允许假装检索过它们。
