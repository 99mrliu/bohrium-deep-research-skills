# 第1章 绪论（合成示例文本）

## 1.1 研究背景

锌空气电池理论能量密度高、原料成本低，被视为有前景的储能与动力电源体系。
隔膜是锌空气电池的关键组件之一，其作用是物理隔离正负极，同时允许氢氧根离子自由迁移。
早期研究多采用聚烯烃类隔膜，但其电解液保持能力有限，且在锌枝晶穿刺下容易失效。

如图1-2所示，隔膜的孔结构直接影响电解液分布与枝晶抑制效果。孔径过大时枝晶易穿透，
孔径过小时离子电导率下降，二者之间存在权衡。

## 1.2 本文工作

本文以复合隔膜为对象，系统比较三种涂覆工艺对电池循环寿命的影响，主要性能指标汇总于表1-1。

**表1-1 三种涂覆工艺下隔膜的面电阻与循环寿命（合成数据）**

| 工艺 | 面电阻 (Ω·cm²) | 循环寿命 (次) |
|------|----------------|----------------|
| 浸涂 | 0.42 | 210 |
| 刮涂 | 0.35 | 260 |
| 喷涂 | 0.31 | 305 |

综上，隔膜的工艺优化是提升锌空气电池寿命的可行路径，本文后续章节给出实验细节。
