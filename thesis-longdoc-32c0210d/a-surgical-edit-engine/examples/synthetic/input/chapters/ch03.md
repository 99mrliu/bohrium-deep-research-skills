# 第3章 结果与结论（合成示例文本）

## 3.1 结果讨论

三种工艺中，喷涂法制备的隔膜面电阻最低，与表1-1的汇总一致。分析认为喷涂工艺形成的
涂层更均匀，隔膜内部孔隙连通性更好，离子迁移阻力更小。循环测试表明，采用喷涂隔膜
的电池在 300 次循环后容量保持率仍高于 85%（合成数据）。

## 3.2 结论

隔膜的涂覆工艺显著影响锌空气电池的循环寿命，喷涂工艺在本文条件下表现最优。
后续工作将考察隔膜在长期浮充条件下的尺寸稳定性。
