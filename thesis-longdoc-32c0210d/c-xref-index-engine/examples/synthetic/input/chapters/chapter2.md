# 2 封装材料与工艺

## 2.1 封装材料

## 2.2 固化工艺

UV固化胶 的固化需要控制辐照度与时间，固化不足会导致边缘密封提前失效。EVA 胶膜的层压温度控制在 150 ℃ 左右。
