# Minimal invocation example — SYNTHETIC, not a formal case result

The outputs below were produced by **actually running this exact skill version** on
the synthetic fixture in `examples/synthetic-case/` (all records fictional, DOIs
under the reserved `10.0000` prefix). They demonstrate the interface end-to-end;
they are **not** results of any organizer test case. The real artifacts are kept
under `examples/synthetic-output/` so a reviewer can diff them against a fresh run.

## Input

`examples/synthetic-case/case.json` (excerpt):

```json
{"case_id": "SYNTH-A-001",
 "research_question": "Find literature on moisture-induced degradation and defect passivation of halide perovskite solar cells.",
 "year_from": 2019,
 "output_contract": {"candidate_literature": "...", "screening_evidence": "...", "status_report": "..."}}
```

`examples/synthetic-case/snapshots/` ships five files on purpose:

| file | role |
|-|-|
| `crossref_page1.json` | valid Crossref-shaped page, 3 records (one with deliberately broken metadata) |
| `europepmc_page1.json` | valid EuropePMC-shaped page, 2 records (one duplicates a Crossref DOI) |
| `crossref_page1_duplicate.json` | byte-identical copy → must be quarantined |
| `truncated_response.json` | unterminated JSON → must be quarantined |
| `mystery.json` | valid JSON, unknown shape → must be quarantined |

## Invocation (exactly what was run)

```
python3 scripts/make_result.py --case examples/synthetic-case/case.json \
    --out examples/synthetic-output/result.json --status partial
python3 scripts/trust_gate.py --case examples/synthetic-case/case.json \
    --input examples/synthetic-case --work /tmp/a-work --out examples/synthetic-output
python3 scripts/make_result.py --case examples/synthetic-case/case.json \
    --out examples/synthetic-output/result.json --status partial --uncertainty "..."
python3 scripts/make_result.py --case examples/synthetic-case/case.json \
    --out examples/synthetic-output/result.json --validate
```

## What the run demonstrates

- **3 of 5 snapshots quarantined** before touching the corpus:
  `DUPLICATE_PAYLOAD`, `PARSE_ERROR` (unterminated string), `SCHEMA_UNRECOGNIZED`
  — see `synthetic-output/quarantine_report.md`.
- **Cross-source dedup**: the EuropePMC copy of `10.0000/synth.a.002` merged into
  the Crossref record; 5 verified records → 4 unique.
- **Record flags**: the broken record (empty title, year 20999) stays visible with
  `TITLE_MISSING` + `YEAR_IMPLAUSIBLE`; its snapshot is tier `T2-flagged-records`.
- **Contract**: `result.json` validates (`VALIDATE OK: 3 contract fields,
  case_id=SYNTH-A-001, status=partial`); status stays `partial` because the
  quarantines are ledgered in `uncertainty` — exactly the behavior expected on a
  real case with defective inputs.
