# 估计量公式与适用条件（权威参考）

本文档是 `scripts/recall_estimator.py` 所实现公式的权威说明。方法按
名称/年份归属：Lincoln–Petersen 估计、Chapman (1951) 偏差校正与方差、
Chao (1987) Chao1 与其对数变换置信区间。不附文献细节，以免编造。

记号：来源（数据库）集合 S，|S| = k；去重后的文献簇为「个体」；
簇 c 的捕获历史为长度 k 的 0/1 向量（1 = 被该库检出）。

- n_i：库 i 检出的簇数（边际计数）；
- m_ij：库 i 与库 j 共同检出的簇数；
- S_obs：被至少一个库检出的簇总数（观测到的去重文献数）；
- f1：恰被 1 个库检出的簇数（单例）；f2：恰被 2 个库检出的簇数。

## 1. 两库：Lincoln–Petersen 与 Chapman (1951) 偏差校正

Lincoln–Petersen 原始估计：N̂_LP = n_i · n_j / m_ij。
小样本下偏差大，本技能使用 Chapman (1951) 偏差校正形式：

    N̂ = ((n_i + 1)(n_j + 1) / (m_ij + 1)) − 1

Chapman (1951) 方差：

    Var(N̂) = ((n_i + 1)(n_j + 1)(n_i − m_ij)(n_j − m_ij))
             / ((m_ij + 1)² (m_ij + 2))

95% 置信区间（正态近似）：

    SE = √Var；CI = [max(max(n_i, n_j), N̂ − 1.96·SE), N̂ + 1.96·SE]

下界钳制在 max(n_i, n_j)：总数不可能小于任一库的检出数。

**无定义情形**：m_ij = 0 时点估计与方差均无定义（除以 1 得 N̂ 仍可算但
方差分母意义上的重叠证据为零，估计不可辩护），本技能如实标注
`undefined_zero_overlap`，不给数字。

适用条件：仅两库、样本量不至于触发小样本降级（见 §4）。

## 2. 多库（k ≥ 2）：Chao1 下界估计（Chao 1987）

f2 > 0（经典形式）：

    N̂_Chao1 = S_obs + f1² / (2·f2)
    Var = f2 · ( (1/4)(f1/f2)⁴ + (f1/f2)³ + (1/2)(f1/f2)² )

f2 = 0（偏差校正形式，variant = `bias_corrected_f2_zero`）：

    N̂_Chao1 = S_obs + f1(f1 − 1) / 2
    Var = f1(f1−1)/2 + f1(2f1−1)²/4 − f1⁴/(4·N̂_Chao1)

对数变换 95% 置信区间（Chao 1987 的构造，改善小样本下正态近似的
下界越界问题）：令 t = N̂ − S_obs，

    t ≤ 0：CI = [S_obs, S_obs]
    t > 0：C = exp(1.96 · √(ln(1 + Var / t²)))
            CI = [S_obs + t/C, S_obs + t·C]

未检出（unseen）估计：

    unseen = max(0, N̂ − S_obs)
    unseen 的 95% CI = [max(0, CI_lo − S_obs), max(0, CI_hi − S_obs)]

**性质**：Chao1 利用单例/双例频数估计未检出类数，是总数的**下界**
估计——真实总数倾向于 ≥ N̂，检出概率越异质低估越多。本技能据此把
unseen 陈述为「至少约 k 条」而非「恰好 k 条」。

## 3. 条件覆盖与独有贡献（纯观测量，非估计）

    条件覆盖 P(簇在库 j | 簇在库 i) = m_ij / n_i    (n_i > 0)
    库 i 的独有贡献 = 捕获历史仅在第 i 位为 1 的簇数（单例分解）

这些是捕获历史矩阵的直接计数，无统计假设，任何情况下都可报告。

## 4. 假设与适用性

1. **封闭总体**：材料快照期间相关文献总数不变（无新增/撤稿进入样本）。
   离线案例的材料是固定快照，该假设通常可辩护，但仍列入 uncertainty。
2. **重叠结构含信息**：各库检出概率允许不同（异质），但簇间重叠模式
   与未检出簇数量相关。两个极端使假设失效：
   - 捕获历史高度集中（某单一模式 ≥70% 簇）→ 重叠信息稀薄 → 警示；
   - Chao1 与最大成对 Chapman 相对差 >50% → 估计量分歧 → 警示；
   警示触发时输出仍给数字，但报告与 uncertainty 强调「以观测事实为准」。
3. **无行为响应**：被某库检出不改变被其他库检出的概率（对文献检索
   即：各库收录决策近似独立）。若两库共享同一上游索引（强相关收录），
   该假设受威胁——此时 m_ij 偏大、unseen 被低估，只能以观测事实为准。
4. **身份归并正确**：DOI/PMID 精确键 + 标题+年份+第一作者姓复合键的
   归并错误可忽略。错误合并（异文并为一簇）→ 重叠高估、unseen 低估；
   错误拆分（同文不并）→ 单例虚增、unseen 高估。仅由模糊键跨源连接的
   簇被显式披露（`fuzzy_only_cross_source_clusters`）。

## 5. 小样本降级规则（硬性）

满足任一条件即触发 descriptive-only，全部点估计置 null 并标注
`suppressed_descriptive_only`：

- 任一来源检出簇数 n_i < 5；
- 总簇数 S_obs < 10。

理由：Chapman/Chao1 的方差行为在极小样本下不可辩护；此时输出只含
§3 的纯观测量（捕获历史普查、条件覆盖、独有贡献）与「样本量不足以
支持统计估计」的明示说明。退出码仍为 0，status=partial。

## 6. 追加来源的预期产出（停止规则的数值部分）

    单例率 r = f1 / S_obs
    各库平均检出 n̄ = (Σ n_i) / k
    预期独有产出 ≈ r · n̄
    参考上限 = unseen 的 95% CI 上界

解释：新增一个检出强度与现有库相近的来源，其独有新贡献预期约 r·n̄ 条；
在封闭总体与 Chao1 下界假设下，任何新来源的独有新增以 unseen CI 上界
为参考上限。该数由 recall_estimate.json 的 `stopping_rule_numbers`
给出，供遗漏陈述引用。
