# 任务说明（虚构教学案例 synthetic-recall-cc-001）

研究问题：围绕「固态锂电池界面稳定化」这一虚构主题，组织者已从
crossref / europepmc / publisher 三个数据库完成联合检索，`materials/`
下的文件即为各库的**离线响应**（不得联网重查）。

请完成：

1. 解析三份检索响应，做最小身份归并（DOI / PMID / 标题+年份+第一作者姓），
   得到去重后的候选簇集合及各簇的来源归属；
2. 把多源检索视为捕获-再捕获问题：统计捕获历史（哪些簇被哪些库检出），
   用成对 Chapman 与多源 Chao1 估计**未被任何来源检出的相关文献数**，
   给出 95% 置信区间；
3. 量化各来源的独有贡献与条件覆盖；
4. 给出可辩护的停止/遗漏陈述：估计还有多少条未检出、置信区间多宽、
   追加一个类似来源预期还能贡献多少条独有记录，并明示假设与小样本限制。

输出契约见 `case.json` 的 `output_contract`。所有数字必须可追溯至
`capture_histories.json` 或声明的公式。`materials/truth.json` 为合成
示例专用真值（真实案例不存在真值文件），仅用于验证估计误差。
