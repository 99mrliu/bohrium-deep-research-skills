# 任务说明(合成示例)

> 合成示例:所有文献与响应均为虚构,仅演示接口与流程,非正式案例结果。

## 研究问题

合成生长素类似物 ZK-7 的剂量-效应关系如何影响水稻(Oryza sativa)根系的
向地性反应?

## 要求

1. 读取本目录 `case.json` 与 `materials/` 下的离线材料(视作各数据库的响应,
   **评测环境无网络,绝不调用实时 API**)。
2. 将研究问题抽取为中性 facet 概念块(PICO 式),交由脚本编译逐库查询计划,
   计划中须尊重各库语法、字段能力、分页方式与配额。
3. 将计划与实际在场的材料响应对账:核对查询回响(query echo),识别单页截断;
   **publisher 库材料缺席,必须显式声明覆盖缺口,不得静默跳过或臆造结果**。
4. 按 `output_contract` 交付 `result.json`;无法确定性填充的字段置 `null`
   并登记 unresolved。

## 交付目录约定

输入只读 `/input`;中间产物 `/app/work`;交付物 `/app/output`。
