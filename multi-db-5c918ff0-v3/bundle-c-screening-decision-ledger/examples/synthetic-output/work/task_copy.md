# 任务：多数据库联合检索的筛选判定（合成示例）

研究问题：合成肽 **NX-3** 对比**安慰剂**治疗**成人慢性失眠**的**入睡潜伏期
（sleep latency）**疗效。

## 资格标准（请逐条遵守）

纳入标准：

1. 研究设计必须为**随机对照试验（RCT）**；综述、观察性研究、动物或体外实验
   一律排除。
2. 研究对象必须为 **≥18 岁成人**且诊断为**慢性失眠**；儿童/青少年人群排除。
3. 干预对比必须为 **NX-3 对比安慰剂**；以活性药物（如唑吡坦）为对照而无
   安慰剂组的研究排除。
4. 结局指标必须包含**入睡潜伏期（sleep latency / sleep onset latency）**。

排除标准（机器可判部分）：

5. 发表年份须在 **2015–2025** 之间，超出者排除。
6. 文献类型为综述（review）、社论（editorial）或会议摘要者排除。

## 交付要求

- 给出每条记录的纳入/排除判定，**必须引用资格标准编号与记录内的证据原文**；
  拿不准的进入边界队列集中裁定，不要硬判。
- 产出 PRISMA 风格流量计数：识别 → 去重 → 初筛 → 排除（分原因）→ 纳入，
  计数须与实际判定记录一致。
- 对拿不准或证据不足的记录给出遗漏/待决说明。
