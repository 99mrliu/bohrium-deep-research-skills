# 引用图模型与重编号规则（renumber-sync-engine 内部模型）

本文件是 SKILL.md 的配套细则：引用图模型、稳定 id 方案、阅读序定义、编辑操作语义、
著者-年 a/b 赋号规则、区间折叠规则。所有规则由 `scripts/` 下三个脚本确定性实现，
本文不引入脚本之外的任何行为。

## 1. 引用图模型

```
稿件文本 ──扫描──> 标记出现 (occurrence) ──引用──> 文献条目 (entry)
                     │                                │
                     │  original_label（旧编号）        │  sid（稳定 id）
                     └──────── label_map ─────────────┘
                                   │
                                   ▼
                            new_label（新编号）
```

- **文献条目 (entry)**：文末列表的每一行。数字制条目有原始标签（旧编号，字符串形式，
  如 "12"）；著者-年制条目的键为 `第一作者姓 年[后缀]`（如 `Smith 2020a`）。
- **稳定 id (sid)**：与位置、编号无关的身份标识，形如 sid-001。**旧编号 12 不等于数组
  第 12 条**：编号只是标签，sid 才是身份。三层映射 `original-label → sid → new-label`
  全程记录在 label_map.json 中。
- **标记出现 (occurrence)**：稿件中一次引用标记的出现。它有真实阅读序坐标
  （reading_order、行、列）、区域（body / figure_caption / table_caption / footnote /
  appendix）、原始文本（raw）与展开后的条目引用集（refs）。
- **编辑操作 (op)**：对稿件与列表的事务性修改。编号从来不是被「改」出来的，而是操作
  施加后由阅读序**重算**出来的；正文标记与文末列表在同一次重算中同步。

## 2. 稳定 id 方案

1. 扫描原始稿件，得到全部 occurrence 的阅读序。
2. 按「全局首现顺序」为被引条目赋 sid：第一个首现的原标签 → sid-001，依此类推。
3. 从未被引用的列表条目按**列表顺序**续赋 sid。
4. 同一原标签的任何重复出现共享同一 sid（重复出现共享编号的前提）。
5. sid 只对「同一份输入的同一次扫描」负责；输入变了就重新扫描、重新建图，
   不得把旧 sid 套到新文本上（apply 的复算校验强制了这一点）。

## 3. 真实阅读序定义

- 文本按行自上而下；行内按字符列（0 基）从左到右。
- 区域识别：
  - `figure_caption` / `table_caption`：行首匹配 `图|表|Figure|Table` + 数字；
  - `footnote`：`[^x]:` 定义行，或以「注：/注:」起首的行；
  - `appendix`：`附录`/`Appendix` 标题行起，直到下一个非附录的 Markdown 标题；
  - 其余非空行：`body`；空行不产生 occurrence。
- **所有区域在同一个编号序列中**（图注、脚注、附录里的引用与正文连续编号），
  这正是 V7 的判定对象。
- 编辑操作之后，以**编辑后文本**重新扫描得到的阅读序为准；合并章节导致的
  「重复首现」冲突按此消解，判定依据写入 label_map.notes。

## 4. 编辑操作语义（ops.json）

所有操作的坐标一律指向**原始稿件**。plan 分两相施加：

- **相一（标记级）**：delete_marker / insert_marker。同一行内有多个编辑时，按起点
  **从右到左**施加，左侧编辑不影响右侧坐标。删除后对该行做空白规整（压缩连续空白、
  去掉标点前多余空格）。插入的引用先以占位符 `⟦标签,…⟧` 落位，重算后统一渲染。
- **相二（结构级）**：merge_paragraphs / move_section，按 ops.json 中给定顺序施加。
  之后合并多余空行（连续空行折叠为一个，去首尾空行），再整篇重扫。

| 操作 | 参数 | 语义 |
| --- | --- | --- |
| delete_marker | reading_order | 删除该出现（典型用途：删悬空标记）。不删列表条目 |
| insert_marker | line + col 或 line + after_text；labels | 在该处插入引用给定原标签的新标记 |
| merge_paragraphs | para_a, para_b（0 基段落索引） | 两段并为一段（单空格连接），段落内标记相对顺序不变 |
| move_section | heading, after_heading（正则，须唯一匹配） | 把源章节（标题行至下个同级或更高级标题前）整体移到目标章节之后 |
| merge_entries | keep, drop（原标签） | 列表条目 drop 并入 keep；所有引用 drop 的标记改指 keep；keep 条目追加「（合并原条目 [drop]）」注记 |

冲突与报错：

- 坐标越界、reading_order 不存在、标题正则不匹配或多匹配、merge_entries 的条目
  不在列表中 → plan 报错（退出码 2），不产生任何输出。
- 施加完 ops 仍有标记引用不存在的标签（悬空未删）→ plan 报错并列出清单，
  要求显式 delete_marker。**绝不**为悬空标记编造条目或编号。

## 5. 首现赋号与区间折叠（顺序编码制）

1. 按编辑后阅读序扫描；某 sid 第一次出现时取下一个可用编号（默认自 1 起；
   任务可指定其他起始值，此时全部编号偏移，V3 按「自起始值连续」判定）。
2. 多编号标记：展开后的 refs 按标记内顺序逐个结算首现。
3. 渲染：编号排序去重；连续长度 ≥3 折叠为 `a-b`；长度 2 不折叠（`a,b`）；
   其余逗号相连。形态：`[…]`（numeric-bracket）或 `^[…]^`（numeric-superscript，
   本 bundle 的上标约定写法；Unicode 上标字符不在渲染端使用，以避免字体歧义）。
4. 未引用条目：按任务要求处理。默认保留——追加标注 `【未引用·保留】`，以 `[*]`
   前缀列于文末列表末尾（保持原列表相对顺序），不占编号序列，V2/V3 对其特判。

## 6. 著者-出版年制规则

- 列表排序键：`(作者串小写规范化, 年, 题名小写规范化)`；稳定排序。
- a/b 后缀：同一（作者串, 年）组内有多条时，按**题名**排序依次赋 a, b, c…；
  单条无后缀。正文标记中的年份后缀同步改写（半角/全角括号都处理）。
- 正文标记键 = `第一作者姓 年[后缀]`；第一作者姓取作者串首个 `,`/`and`/`&` 之前的
  最后一个词；中文作者整名作为「姓」。
- 同姓同年不同人：排序键中的作者串已包含 initials/全名时可区分；无法区分时按题名
  排序赋后缀并在 notes 记录（见 SKILL.md 异常表）。
- 未引用条目：保留在排序后列表中并追加 `【未引用·保留】`。

## 7. 幂等与原子性

- **幂等（V8）**：对已同步文本以空 ops 重跑 compute_plan，要求映射恒等且重渲染文本
  与输入逐字节一致。这是「编号已同步」的操作定义，也是交付前最后一道闸。
- **原子施加（apply）**：先用相同输入 + label_map 内嵌的 ops 完整复算并逐字段比对
  label_map；全部通过才把三个产物（edited_manuscript.txt、edited_references.txt、
  label_map.json）经临时文件 + os.replace 落盘；任何一步失败则不写任何文件。
- **确定性**：同输入必同输出；无网络、无时间戳、无随机数、仅标准库。
