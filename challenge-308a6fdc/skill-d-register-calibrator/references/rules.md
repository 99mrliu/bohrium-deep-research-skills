# rules.md — R1–R8 判定逻辑、词表与豁免条件

机器可读规则表为同目录 `rules.json`（register_lint.py 启动时加载，可用 `--rules` 覆盖）。
本文档是同一套规则的人类可读说明。通用豁免：围栏代码块（```）内不检查任何规则；标题行不触发 R1/R3/R4（但参与 R7 缩写检查）。

## R1 人称（高）
- **判定**：正文匹配 `我们|笔者|您|你|我(?!国|们)`。
- **豁免**：「我国」（引述国家层面表述）通过负向断言排除；代码块、标题。
- **自动修复**：仅 `笔者→本文`、`我们→本研究` 两条无歧义映射；「我/你/您」语义不定，只报告。
- **建议**：改为「本文/本研究」或无主语句式。

## R2 标点（中，可自动修复）
- **判定**：句读类 `, . : ;` 前一中文字符 → 命中；括号类 `(` 前为中文或后直接跟中文 → 命中，`)` 前为中文或后直接跟中文 → 命中。
- **豁免（天然）**：小数点（`3.5`，前一字符为数字）、英文句子、URL、代码块、`(1)` 这类数字编号。
- **自动修复**：映射 `,→， .→。 (→（ )→） :→： ;→；`，逐条写入 fix_log.json（行/列/原文/替换/规则号）。

## R3 口语化（高）
- **词表**：搞、弄、东西、挺、差不多、一大堆、啥、靠谱、给力、干货。
- **程度副词「很」**：命中 unless 紧跟白名单语境 `很可能|很多|很少|较大|较小`。
- **豁免**：代码块、标题。
- **不自动修复**（需语义判断），建议替换：搞→开展/进行；东西→具体名词；差不多→大致/约；挺→较/较为。

## R4 夸大词（高）
- **词表**：革命性、颠覆性、首次提出、完美、彻底解决、填补空白、国际领先、划时代。
- **豁免条件**：同一行内出现「材料依据」标注（如 `（材料依据：材料A 第3节）`），视为作者已自证，跳过。
- **不自动修复**：删除或降级为客观陈述；确需保留必须补材料依据标注。

## R5 强度分级校准（高/低）
- **稿件断言分级**（词表见 rules.json）：
  - L3 定论：证实、证明、确证、定论；
  - L2 较强：表明、显示、揭示；
  - L1 初步：初步表明、提示、有望、可能。
- **材料证据信号扫描**：
  - L1 信号：初步、preliminary、pilot、小样本、探索性、试点，及小样本标记 `n=\d+` 且 n<30；
  - 强证据信号：随机对照、randomized、多中心、大样本、荟萃、meta-analysis、RCT。
- **判定矩阵**（仅对含 L3 措辞的断言句触发）：
  | 材料信号 | 稿件用 L3 | 结果 |
  |----------|-----------|------|
  | 仅 L1 信号 | 是 | **CALIBRATION-MISMATCH，高** |
  | 无任何信号 | 是 | 低，提示人工确认证据等级 |
  | 强证据信号 | 是 | 不报 |
  | 未提供材料 | 是 | 低，提示人工确认 |
- L2 措辞默认不触发（边界情形交模型判断，见 strength-calibration.md）。

## R6 因果越界（中）
- **因果动词表**：导致、使得、促进了、降低了、提升了、引起了、改善了。
- **章节限定**：仅当前 markdown 标题含「摘要/结果/结论」的正文行参与检查。
- **材料设计信号**：随机对照、干预实验、randomized、对照实验、RCT、准实验、双盲。**任一出现则整条规则不启用**（视为有因果推断资格）。
- **建议**：改为「相关」「伴随」「与……有关」。

## R7 缩写规范（中/低）
- **缩写识别**：`(?<![A-Za-z0-9])[A-Z]{2,}(?![A-Za-z0-9])`，忽略表（AI/ID/URL/PDF/LED/APP）在 rules.json 可调。
- **判定**：
  - 首次出现行不含 `中文全称（ABBR）`（全/半角括号均可）→ 「未定义缩写」，中；
  - 已定义后再次出现定义模式 → 「重复定义」，低；
  - 先裸用、后补定义：裸用已在首现时报过，补定义处仅登记不再报。
- **不自动修复**（全称需领域知识）。

## R8 术语一致（低）
- **(a) glossary.lock 检索**：工作目录下存在 glossary.lock 时（格式见 glossary-format.md），稿件出现变体且同行未出现标准形式 → 低，建议改标准形式。
- **(b) 候选术语自动抽取**：提取 2–6 字中文 n-gram，保留全文频次 ≥3 且不被等频更长形式吸收的最大项；两候选共享 ≥2 字公共子串且互不为子串 → 组成「候选术语组」，报 1 条低级别 finding（行号 0，全文级），列出让模型裁决。
- **上限**：最多报 30 组，防爆版。
- **典型误报**：共享词根的不同概念（如「配伍规律/方剂配伍」）——模型应驳回并写理由。
