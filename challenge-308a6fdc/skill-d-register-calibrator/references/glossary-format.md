# glossary-format.md — glossary.lock 术语锁定表格式

`glossary.lock` 放在工作目录（运行时 `/app/work`），供 R8 检索。纯文本、UTF-8。

## 语法

```
# 井号开头为注释，空行忽略
标准形式 <= 变体1 | 变体2 | 变体3
大语言模型 <= 大模型 | 大型语言模型
配伍规律挖掘 <= 配伍规律的挖掘
```

- 每行一条：左为标准形式（译名锁定目标），右为禁用变体列表。
- 变体之间可用 `|`、`,` 或 `，` 分隔。
- 不含 `<=` 的非注释行被忽略（容错）。

## 语义

- 稿件某行出现任一变体、且同行未出现标准形式 → R8 低级别 finding，建议改为标准形式。
- 同行同时出现标准形式与变体不报（视为对照说明）。
- 无 glossary.lock 时 R8 退化为仅自动候选术语组抽取（报给模型裁决），模型裁决后可把结论**写回** glossary.lock，供后续复检一致执行。

## 建议工作流

1. 首轮 lint 后，把模型裁决过的术语组整理为 glossary.lock；
2. 后续章节/版本复检时，R8 直接按锁定表执行，避免同一术语反复裁决。
