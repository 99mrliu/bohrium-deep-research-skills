# strength-calibration.md — L1–L3 措辞强度分级体系与证据对齐原则

## 分级体系

| 级别 | 含义 | 典型措辞 | 所需证据 |
|------|------|----------|----------|
| L3 定论 | 因果/确证性断言 | 证实、证明、确证、定论、X 导致 Y | 强设计：随机对照、多中心、大样本、荟萃分析 |
| L2 较强 | 较稳健的经验结论 | 表明、显示、揭示 | 可复现的定量结果，样本与设计无重大局限 |
| L1 初步 | 探索性/或然表述 | 初步表明、提示、有望、可能、或 | 初步、pilot、小样本、探索性研究 |

## 证据对齐原则

1. **措辞强度 ≤ 证据强度**：材料里出现的最高证据等级，是稿件允许使用的最高断言等级。材料只含 L1 信号（初步/preliminary/pilot/小样本/n<30）时，稿件任何章节不得出现 L3 措辞。
2. **降级而非删除**：CALIBRATION-MISMATCH 的标准处理是把 L3 降为 L1/L2 并保留事实内核，例如「实验证实 X 有效」→「实验初步表明 X 在小样本语料上可行」。
3. **因果与强度分开看**：R5 管断言强度，R6 管因果方向。一句「证实 A 导致 B」通常同时越两级：强度降到 L1，因果动词改为「相关/伴随」。
4. **无信号不臆断**：材料中没有任何强度信号时，脚本只发低级别提示；模型应回到材料原文人工确认，不得默认升格。
5. **限定语即降级**：为断言附加适用范围（「在 n=12 语料上」「在本数据集内」）等价于向 L1 靠拢，是合法的校准手段。

## 常见误判提醒

- 「表明/显示」（L2）在材料仅 L1 时不自动报警，但若句子同时含全称量词（「所有」「完全」）应按越级处理，由模型判断。
- 材料中「初步表明……有望……」支持稿件写 L1，不支持写 L2/L3；材料局限章节（小样本、单中心）是降级的强信号。
- 标题与摘要是强度越级高发区，校准后与正文结论保持一致。
