# 合成材料：方剂配伍规律探索性研究记录（非真实研究数据）

本材料为 skill 示例的合成输入，非正式案例结果。

## 研究性质
- 本研究为**初步**（preliminary）探索性工作，属 pilot 阶段。
- 样本规模：纳入方剂 n=12，属小样本。
- 未采用随机分组或干预设计，仅为观察性文本挖掘。

## 观察记录
- 在 n=12 的语料上，模型对高频药对的召回率约为 0.71。
- 初步表明大语言模型可辅助发现部分配伍模式。
- 研究者备注：结果提示该方法有望扩展到更大语料，但目前不能下因果结论。

## 局限性
- 小样本、单中心语料，结论外推需谨慎。
- 未做人工标注一致性检验。
