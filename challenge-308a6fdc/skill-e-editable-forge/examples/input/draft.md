# 合成实验记录成稿（示例，非正式案例）

本成稿为**合成示例**，用于演示 MD→DOCX 编译与修订留痕流程，所有数据均为虚构。

## 方法

示例反应在 50 摄氏度下进行 2 小时，搅拌速度为 300 转每分钟。粗产物经*柱层析*纯化。

## 结果

三组平行样本的合成结果如下：

| 组别 | 均值 | 备注 |
|---|---|---|
| A 组 | 12.4 | 合成数据 |
| B 组 | 15.1 | 合成数据 |
| C 组 | 13.8 | 合成数据 |

## 讨论

- 示例要点一：B 组均值最高，但差异未做统计检验。
- 示例要点二：当前温度设定**可能**不是最优条件。
- 示例要点三：需要人工复核所有数值后再进入正式写作。
