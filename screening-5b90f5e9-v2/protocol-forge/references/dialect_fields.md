# 方言字段白名单（lint_query.py 的实现依据）

门禁只放行下列字段标签；其余一律 L5 ERROR。白名单刻意从严——
宁可误报让操作者确认，也不放行会在目标库静默失败的标签。

## pubmed（方括号后缀式）

| 标签 | 含义 | 备注 |
|---|---|---|
| `[tiab]` | 题名/摘要 | 默认主字段 |
| `[ti]` | 题名 | 精确缩窄时用 |
| `[tw]` | 文本词 | 含 MeSH 之外的文本词 |
| `[mh]` / `[mesh]` | MeSH 主题词 | 与自由词块 OR 联用 |
| `[dp]` / `[Date - Publication]` | 出版日期 | 范围写法 `"2020/01/01"[dp] : "2026/12/31"[dp]` |
| `[la]` | 语种 | 限定在执行侧落实时也要登记 |
| `[pt]` | 出版物类型 | 如 `randomized controlled trial[pt]` |
| `[au]` `[ta]` `[all]` | 作者/刊名/全字段 | 辅助 |

## scopus（函数前缀式）

`TITLE-ABS-KEY(...)`、`TITLE(...)`、`ABS(...)`、`KEY(...)`、`ALL(...)`、
`AU(...)`、`DOI(...)`；限定词 `PUBYEAR`、`LANGUAGE(...)`、`SRCTYPE(...)`。
注意 Scopus 的通配符是 `*`（词尾）与 `?`（单字符），本门禁只放行词尾 `*`。

## wos（等号前缀式）

`TS=(...)` 主题、`TI=(...)` 题名、`AB=(...)` 摘要、`AK=(...)` 作者关键词、
`AU=(...)`、`DO=(...)` DOI、`LA=(...)` 语种、`DT=(...)` 文献类型、
`DOP=(...)` 出版日期。

## 执行侧提醒

- 日期与语种限定即使写进检索式，也必须在协议的 `date_limit` /
  `language_limit` 字段单独登记，保证审计时可对照；
- 某些库界面不接受的合法语法（如 PubMed 超长 OR 块）属运行风险，
  应在协议 notes 中说明降级方案（分批执行），而不是悄悄改短检索式；
- 检索式一旦执行，把**实际执行的字符串**与命中数回写到执行记录，
  与协议文本并列保存，禁止只留协议不留执行串。
