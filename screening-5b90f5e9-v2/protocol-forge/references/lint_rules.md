# 语法门禁规则（L1–L9）

每条规则给出：级别、触发条件、处置。ERROR 使整条检索式 FAIL 且
lint_query.py exit 3，阻断协议定稿；WARN 记录在案不阻断。

| 规则 | 级别 | 触发 | 处置 |
|---|---|---|---|
| L1 | ERROR | 括号深度不归零或出现负深度 | 定位到首个失衡位置修复 |
| L2 | ERROR | 双引号数为奇数 | 闭合引号；短语内含引号须改写 |
| L3 | ERROR | 布尔运算符位于串首/串尾 | 删除或补操作数 |
| L4 | ERROR | 运算符相邻（`AND AND`、`OR OR`、`NOT NOT`；`AND NOT` 合法） | 删除多余运算符 |
| L5 | ERROR | 字段标签不在方言白名单（见 dialect_fields.md） | 换白名单标签或改方言 |
| L6 | ERROR | `*` 不在词尾（词首/词中/孤立） | 改写截词；中间截词换受控词表 |
| L7 | ERROR | 空括号 `()` | 删除或填子句 |
| L8 | WARN | 单条检索式字段标签超过 3 种 | 复核可移植性，必要时拆分 |
| L9 | ERROR | 运算符紧贴括号（`OR )`、`( AND`） | 补操作数或删运算符 |

## 门禁的工作方式

- 门禁是**静态检查**，不执行检索、不验证命中数；命中数合理性属执行记录；
- 生成式检索式（build_protocol.py 产物）也必须过门禁——生成器可能有 bug，
  门禁不因为它"是自己人"就放行；
- 历史遗留检索式（前人手工写的）逐条过门禁并留 lint_report，是协议评审的
  标准动作；
- FAIL 的检索式禁止进入执行记录；修复后重跑到 PASS 为止。

## 与标准映射的关系（map_criteria.py）

语法合法只说明检索式"能跑"，不说明它"问对了问题"。M1–M4 检查标准与
概念块的引用完整性：标准引用悬空块（M1）、标准无块对应（M2）、块无标准
引用（M3）、块子句未进入检索式（M4）。I4/E1 这类不对应概念块的标准
（如"随机对照试验"）依赖筛选阶段兜底，M2 会 WARN 提醒——这是正常且
必要的提示，不是缺陷。
