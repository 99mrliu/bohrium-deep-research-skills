# challenge-a0e888fa 科研数据清洗与处理 · 第二轮五份独立 Skill 作品

五个重心截然不同的方向，五份相互独立、零共享文件的 bundle；每份含完整
SKILL.md、scripts/、references/ 与已真实运行的合成示例（examples/ 内数据
均为人工编造的合成数据，不对应正式案例）。本轮与同仓库 challenge-a0e888fa/
目录下的第一轮作品无任何共享文件，方向亦不重复。

| 目录 | 方向 | 重心 |
|---|---|---|
| `origin-anchor` | 发表汇总表算术取证 | 上游数据真实性：恒等式建网、最小命中集故障定位、仅唯一可解时反解恢复 |
| `sql-cleanroom` | 声明式清洗范式 | 执行范式：SQLite 集合操作，规则即数据、清洗即查询、报告即聚合、全量可重放 |
| `twin-pass` | 双实现冗余对账 | 过程质量控制：一份规约两个独立引擎、逐格 diff、幂等核验，零分歧才交付 |
| `report-forge` | 报告与图表交付工程 | 下游渲染工程：报告数字只由产物重算注入、手写 SVG 图表、三方一致性门 |
| `dict-compiler` | 数据字典编译器 | 规则知识工程：字典/工单文本机械编译为规则，无出处不执行，覆盖矩阵三视图 |

每份 bundle 根部的 `GITHUB_URL.txt` 第一行即本作品链接。
