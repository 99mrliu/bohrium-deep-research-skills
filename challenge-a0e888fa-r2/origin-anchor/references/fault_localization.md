# 故障定位与有限恢复方法论

## 1. 最小命中集定位

每条被违反的恒等式至少含一个坏单元格（故障注入点）。因此“能解释全部违反等式的
最小单元格集合”是一个**最小命中集**（minimum hitting set）问题：

- 宇宙：所有 VIOLATED 等式的单元格并集。
- 目标：选出最小的单元格子集 S，使每条 VIOLATED 等式都至少含 S 中一个单元格。

脚本使用确定性贪心：每轮选择“覆盖未覆盖违反等式最多”的单元格；平局时依次按
“参与已通过等式更少”（一个单元格被越多独立等式 corroborate，它越不像坏点）、
“(行, 列) 字典序”决胜。贪心不保证数学最小，但保证确定性与可复现性；因此报告
必须同时给出：

- **primary**：命中集成员（主要可疑单元格）；
- **alternative**：位于违反等式中但未被选中的单元格（替代解释，同样可疑但优先级低）。

切勿把 alternative 当作干净单元格写入结论；它们只是“用别的解释也能说通”。

## 2. 置信分级

| 级别 | 定义 |
|---|---|
| high | primary 单元格，**同时**违反算术恒等式与字典物理界（两类独立证据交叉） |
| medium | primary 且参与 ≥2 条违反等式；或仅违反字典界（bound_only） |
| low | primary 但只参与 1 条违反等式（孤立违反）；或 alternative |
| clean | 未参与任何违反项 |

依据：多条独立等式指向同一单元格时，“等式全对、单元格坏”的假设远优于
“多条等式各自的另一单元格同时坏”；算术与字典两类来源独立的证据交叉时最强。

## 3. 可恢复性的充要条件

仅当以下**全部**满足时，restore_unique.py 才允许反解恢复 primary 单元格 c：

1. **唯一可归因**：c 参与的每条 VIOLATED 等式中，c 都是唯一的 primary 可疑单元格。
   反例：合计行被改坏、或两个分项同时被改时，求和等式含 ≥2 个可疑格，反解会把
   误差随意分摊到某一个格子上——禁止。
2. **候选一致**：由这些等式分别反解得到的候选值互相一致——
   点候选两两之差 ≤ 双方等式容差之和；点候选落在全部区间候选之内
   （区间来自对方报告值的舍入半宽，如 pct=53.3% ⇒ 真值 ∈ [53.25, 53.75)）；
   只有区间候选时，区间交集非空。
3. **不越字典界**：反解值满足该列全部 bounds（含半个舍入单位的宽限）。
4. **有据可依**：至少一条等式支持反解该位置。

恢复值选取顺序（确定性）：col_sum/subtotal_sum 的点候选优先，其次 unit_pair、
mean_of_sum、percent、weighted_mean 的点候选，最后才是区间交集中点。
整数列（原单元格 decimals=0）贴靠最近整数并回验仍落在全部区间内。

每次恢复必须在 restoration_ledger.csv 留痕：等式编号、定位依据（方法）、旧值、
新值。digest.md 对恢复后的表**复评全部等式**，列出仍违反者。

## 4. 禁止事项（铁律）

- **绝不插补**：缺值、非法值不可用均值/中位数/众数/回归等任何方式填补。
- **绝不推断总体统计量**：不得由样本统计量反推总体参数，不得假设分布。
- **绝不依据标签补造数据**：不得因为“这一格应该是合计”就凭空写一个数——
  只有第 3 节的等式反解（且满足全部条件）是合法来源。
- **原值必留痕**：任何改动保留旧值；未恢复的可疑格原样保留并写入不确定性。
- **alternative 不可恢复**：只处理 primary；扩大恢复面会把定位不确定性转化为
  数据污染。
- **UNDEFINED 等式不参与定位与恢复**：缺值导致的无法评估如实报告，不得猜测。

## 5. 降级与失败模式

| 情形 | 行为 |
|---|---|
| 无合计/小计行 | 列合计等式缺失，仅用行内等式（percent、mean_of_sum、unit_pair）与字典界；在报告中声明降级 |
| 无百分比列或未配置角色 | 对应等式类缺失；声明降级 |
| 等式大面积违反（命中集 > 违反等式数的 1/2） | 表格可能整体错位（如转列、行错位），停止恢复，全部标记，status 写 partial/failed 并说明 |
| 字典缺物理界 | bounds 为空即可，置信不会出现 high；声明此局限 |
| constraints.json 缺 source / 索引越界 | 退出码 4，拒绝运行（约束无出处即不可用） |
