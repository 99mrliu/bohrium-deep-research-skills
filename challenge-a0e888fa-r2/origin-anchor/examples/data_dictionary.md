# 合成数据字典（人工编造，仅用于示例）

本字典对应 `trial_table.csv`（合成临床试验风格汇总表，全部为人工编造数据）。

| 字段 | 含义 | 单位 | 物理界 / QC 规则 |
|---|---|---|---|
| 组别 | 分组标签 | — | A组 / B组 / 小计(治疗) / 安慰剂组 / 合计 |
| n | 各组例数 | 例 | 整数，1–200；合计 = 各组之和 |
| male_n | 男性例数 | 例 | 整数，0–200；合计 = 各组之和 |
| male_pct | 男性构成比 | % | 0–100；male_pct = male_n / n × 100 |
| responders | 应答例数 | 例 | 整数，0–200；合计 = 各组之和 |
| response_pct | 应答率 | % | 0–100；response_pct = responders / n × 100 |
| age_mean | 组内平均年龄 | 岁 | 18–75（入选标准）；合计行为按 n 加权的均值 |
| dose_mg_sum | 组内累计给药量 | mg | 0–48000；合计 = 各组之和 |
| dose_mg_mean | 人均给药量 | mg | 60–240；dose_mg_mean = dose_mg_sum / n |

单位说明：本表全部指标只有一种单位，无单位对偶列（unit_pairs 为空）。
