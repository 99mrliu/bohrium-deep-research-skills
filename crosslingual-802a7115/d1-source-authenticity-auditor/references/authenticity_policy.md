# 上游数据真实性核验策略（authenticity policy）

## 原则

1. **实际文件是事实依据**。文件名、目录名、记录的 `language`/`type` 字段都只是声明；
   判定以抽取出的真实正文为准。PDF 一律用 `pdftotext` 真实抽取，不依据标签臆断内容。
2. **缺口不补造**。缺 DOI、缺语种、缺版本、缺摘要/全文的记录，缺口本身就是结论的一部分，
   逐条写入 findings 与 result.json 的 `uncertainty`。推断出来的元数据比缺失更有害。
3. **重复只计一次**。同文多副本（含跨文件复制）在去重后计数，但每个副本的来源路径与
   归因字段都保留，供复核者回指。
4. **失败显式化**。解析失败、抽取失败、语种不定全部入 `parse_notes`/findings；
   台账的 `status` 反映真实严重度。

## 语种检测方法（启发式，供核验而非翻译）

- 假名（ひらがな/カタカナ）≥5 → `ja`；汉字 ≥10 且无假名 → `zh`。
- 拉丁语系：对 NFKD 折叠后的 token 统计各语种高频停用词命中数，最高分为候选语种；
  另按变音字符画像加分（ã/õ/ç→pt，ñ/¿/¡→es，ä/ö/ü/ß→de，à/â/è/ê→fr），上限 15 分防爆。
- 置信度 = 0.4 + 0.6 × (top − second)/(top + 1)，封顶 0.99；top 与 second 接近时置信度自然降低。
- 证据（各语种得分、margin、kana/han 计数）完整保留在台账里，人工可复核。

## 重复判定

- 规范化：NFKD 去变音 → 小写 → 空白压缩。
- 完全重复：规范化全文 SHA-256 相同。
- 近重复：5-gram shingle Jaccard ≥ 0.9（容忍尾部参考文献/页眉差异）。
- 阈值 0.9 是保守线：0.7–0.9 的相似对可能是"同工作不同版本"（原文 vs 译文摘要），
  本脚本不报为重复，交由下游版本归并环节处理。

## 与下游的接口

- `duplicate_pairs` → 版本归并/计数步骤：去重后计数。
- `language_label_mismatch` → 语种路由步骤：以 `detected_language` 为准，原标签保留在对照字段。
- `missing_doi`、`language_undetermined` → result.json `uncertainty`：显式列出，不静默丢弃。
- `content_sha256` 可作为结果记录的证据定位锚点（locator 的一部分）。
