# 证据强度分级口径与对齐判定（Strength Rubric & Alignment Policy）

## 1. 证据等级（A 最强，D 最弱）

| 等级 | 定级条件 | 允许措辞（示例） |
|---|---|---|
| A | meta 分析 / 指南共识；或 ≥2 项一致的高等级证据上调 | "证据一致表明""指南推荐" |
| B | 单项随机对照试验（RCT） | "研究显示""随机对照试验提示" |
| C | 单项观察性研究（队列、病例对照、横断面） | "一项观察性研究提示""初步显示" |
| D | 预印本、体外/动物实验、病例系列、专家意见、n<30 | "临床前证据提示""尚待研究验证" |

调整规则（`strength_map.py` 的 level_of 实现）：≥2 项互相一致的
研究上调一级（最高 A）；任一研究 n<30 下调一级（最低 D）；未登记
研究信息的论断按 D 处理。模型登记 `consistent` 时必须依据原文结论
方向判断，不得臆断。

## 2. 对齐判定口径（align_check.py）

| 判定 | 含义 | 成稿处置 |
|---|---|---|
| anchored | quote 逐字命中、数字保真、方向一致、无否定歧义 | 可支撑事实句 |
| review | 仅 NEGATION-REVIEW（否定词奇偶不一致） | 人工核对语义后方可使用；核对结论写入证据表 |
| failed | QUOTE-NOT-ANCHORED / NUMERIC-MISMATCH / DIRECTION-CONFLICT / SOURCE-MISSING | 不得支撑事实句；修复证据或删除论断 |

论断级汇总：全部证据 anchored = supported；部分 anchored =
partial（成稿只能写被覆盖的部分）；无 anchored = unsupported
（论断删除或转〔未锚定〕并记入 change_log）。

## 3. 四层检查的设计意图

1. **逐字锚定**拦截"凭印象转述"：quote 必须是来源文本的连续子串
   （规范化后），页码由命中位置回填而非估计；
2. **数字保真**拦截数字错位：论断中每个数字必须逐字出现在 quote
   中（`1.8` 与 `1.80` 不等价——设计如此，等价写法须改回原文数字）；
3. **方向一致**拦截方向反转：论断说"升高"而 quote 只有"降低"时
   报 DIRECTION-CONFLICT；
4. **否定审视**拦截极性反转：否定词计数奇偶不一致时强制人工复核，
   不自动判死（双重否定等合法情形存在）。

## 4. 已知边界

- 对齐检查是字符串级：同义改写（"空腹血糖下降 1.8" vs "FPG 降低
  1.8"）无法通过数字保真——这是有意的严格口径，代价是部分合法
  转述需要改写为贴近原文的表述；
- 方向词表与否定词表集中在 `align_check.py` 顶部常量，学科特异的
  反义词（如 上调/下调、激活/抑制）可按需扩展并同步本文件；
- 强度词表覆盖中文常用表述，英文成稿需在 FORBIDDEN/ALLOWED 中
  补充对应英文措辞。
