# 互补性度量定义

## 渠道三分

设图谱渠道窗口内（role = new）候选集合为 G，关键词快照候选集合为 K，对齐只使用最低限度精确匹配（DOI 小写去前缀；失败退回标题 casefold + 空白压缩）：

- `both` = G ∩ K（两渠道都找到）
- `graph_only` = G \ K（只有图谱找到 —— 图谱渠道的独有贡献）
- `keyword_only` = K \ G（只有关键词找到）

窗口外的图谱扩展条目（`context`）与 dangling reference **不计入** G，单独成列；这是为了防止背景文献与坏边污染增益数字。

## 互补增益

```
graph_unique_gain = |graph_only| / (|both| + |graph_only| + |keyword_only|)
```

- 分母是去重后、窗口内的新候选总数；`graph_unique_gain` 表示"若只做关键词检索，将损失的新候选比例"。
- 分母为 0 时输出 `null`，并在 gaps 说明，绝不输出 0 或编造的百分比。
- 辅助量 `graph_channel_yield.graph_new_candidates = |both| + |graph_only|`：图谱渠道的窗口内产出量。

## graph_only 漏检原因诊断

对每条 graph_only 候选，在其材料原文（图谱节点记录的 `title` / `abstract`）上做 casefold 子串检查：

| 检查结果 | 诊断 |
| --- | --- |
| 标题不含任何查询词 | "标题不含任何查询词: ..." |
| 摘要不含任何查询词 | "摘要不含任何查询词: ..." |
| 摘要字段缺失 | "摘要字段缺失（材料未提供）" |
| 节点记录无标题/摘要文本 | "材料本身无文本可检" |
| 部分命中但仍未被收录 | "原因超出材料可解释范围"（诚实声明，不编造） |

每条诊断带 `evidence.graph_node_locator`，可回指图谱文件中的原始记录。诊断只陈述材料中可验证的事实；若材料无法解释（例如关键词渠道其实是收录策略问题而非用词问题），必须明说"超出材料可解释范围"，禁止臆断。

## 解读注意

- `graph_unique_gain` 高不代表关键词渠道差：graph_only 条目可能是关键词检索式本就无意覆盖的背景文献。诊断列用于区分"用词不同导致的漏检"与"非目标主题"。
- 增益是**本轮、本快照、本图谱**下的快照值；外推到其他语料需要在 gaps/notes 中声明。
