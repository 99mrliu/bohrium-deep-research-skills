# 滚雪球方法学与一轮/多轮权衡

## 定义

引文滚雪球（citation snowballing）以一组种子文献为起点，沿引文边扩展候选集：

- **backward（后向）**：种子的参考文献，即图谱中 `种子 -> X` 边的 target。用于发现种子赖以立论的基础工作与同主题早期工作。
- **forward（前向）**：引用了种子的文献，即图谱中 `X -> 种子` 边的 source。用于发现追随种子的最新工作。仅当图谱提供该方向的边时可用；图谱只含 backward 边时必须如实声明 forward 不可得，禁止伪造。

本 Skill 中所有边**只能**取自案例材料中的保留参考图谱文件，绝不外查 OpenCitations、Crossref references 或任何在线源。

## 为什么是一轮

本 Skill 固定做**一轮**扩展，理由：

1. **可追溯性**：一轮扩展的每个候选距离恒为 1，每条边都能用 locator 精确回指图谱文件；多轮扩展的候选距离增大后，"为什么这篇被纳入"的解释链变长，离线评测中无法向外部数据库求证中间节点的归属。
2. **精度衰减**：每多一轮，候选数大致按分支因子放大，与科研问题的相关性迅速稀释；一轮的精度/召回权衡在种子质量高时通常最优。
3. **与关键词渠道的互补性度量保持干净**：一轮 graph_only 的漏检原因（标题/摘要不含查询词）可以直接在材料原文上验证；多轮候选的漏检原因常混杂"本身就不相关"，度量被污染。

## 何时可以考虑多轮（本 Skill 默认不做）

- 种子极少（1~2 篇）且图谱稀疏，一轮扩展候选为 0 时，可在**人工声明**后做第二轮，并且：
  - 逐轮保留每条的完整路径 locator（边 id 序列）；
  - 在 `ranking.criteria` 中显式把距离作为首要排序键；
  - 在 `gaps` 中说明多轮带来的精度风险。
- 禁止把多轮扩展作为默认行为，也禁止为了凑候选数而扩轮。

## 距离与共被引作为先验

- **图谱距离**：离种子越近越可能与研究问题同主题；一轮场景下全部为 1，多轮时是首要排序键。
- **种子共被引次数**：被越多颗种子共同引用（backward 方向），越可能是该问题的核心背景或方法来源；作为新颖性/相关性的次级先验参与排序。
- 两者都只是**先验**，排序依据必须逐条写出（本 Skill 在 `ranking.ranked[].reason` 中体现），不做黑箱打分。
