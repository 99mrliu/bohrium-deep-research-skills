# 五路证伪：判定逻辑与修订范式

审核器的姿态是"假定每条论断都是错的，尽力找到证据"。以下按规则给出
判定逻辑、典型误报与规范修订方式。

## F1 引文逐字（UNSUPPORTED）

判定：空白归一化后，引文必须是所引段落的子串。
修订：回到原文重新复制；找不到能支撑论断的引文时，删除论断或改写为
"本工作未能从材料中证实"，并写入 NOTE。

## F2 论断数值必在引文中（REVISE）

判定：论断 text 中每个数值（排除 P3 之类的段落编号）都必须出现在该论断的引文集合中。
典型误报：无（段落编号已排除）。
修订范式：差值/比值类数值是自己算的，必须（a）把 kind 改为 inferred，
（b）在 text 中写明"由 P…计算可知"，（c）引文挂原始数值。
捏造数值（原文根本没有的 95%）必然命中 F2。

## F3 否定/转折语境（REVISE）

判定：引文含 `not/no/never/failed to/however/but/cannot` 等词，而论断 text
不含任何否定/转折字样（未/不/无/否定/转折）。
典型误报：引文末尾恰好带 however 但前半句完整支撑论断。
规范修订：把语境并入论断——「X 成立；原文同时指出 however 之后的限制」，
而不是为绕开检查删掉 however。机器的意图是**语境不得丢失**。

## F4 比较论断需双取值（REVISE）

判定：论断含"更高/优于/低于/倍/more than/outperform"等措辞时，
引文集合中不同的数值必须 ≥2。
修订范式：补挂比较对象的数值引文（可跨段落）；
或者删掉比较措辞，把论断改回单点陈述。

## F5 单位风险（WARN，不阻断）

判定：论断含数值而引文中未见单位词表中的单位。
处置：人工确认单位在上下文中有定义（如全文统一 MPa）；
确认不了就把单位写进论断与 conditions，或改写论断。

## 渲染降级语义

- pass 论断：进 `claims[]`，claim_id 机械分配为 `Q<n>-C<i>`。
- revise/unsupported 论断：进 `unanswered_parts[]`，reason 附审核规则与消息——
  审阅者可以直接看到"哪条论断为什么没交"。
- NOTE 行（缺口）：必须带"已核对"段落列表才计 pass；通过的 NOTE 使全题
  在无论断时判定为 insufficient_evidence（有效回答）。
