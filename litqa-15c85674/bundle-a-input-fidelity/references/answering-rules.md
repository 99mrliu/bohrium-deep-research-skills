# 作答与证据规则

1. **只依据给定材料**。材料与常识冲突时以材料为准并注明；材料未报告时明确写
   "材料未报告"，不得用先验知识补全。
2. **保留条件**：数值、单位、比较对象、实验条件（光源、浓度、时间、温度等）与原文一致地保留；
   给数值必须连同条件。
3. **来源三分**：原文明确报告的用 `kind=reported`；由多段对比、组合或简单换算得出
   的用 `kind=inferred`（text 中写明"由 P3 与 P7 对比可知"）；作者归因（如
   "authors attribute … to"）要说明这是作者解释而非实测事实。
4. **引文逐字**：每条证据的 `quote` 必须能在所引段落中逐字找到
   （空白差异可容忍，措辞差异不可）。一条论断可挂多条不同段落的证据。
5. **引文截短**：≤60 词，保留数值、单位与比较对象所在的完整从句。
6. **冲突处理**：两处说法不一致时，并列给出两种说法及各自段落出处，不二选一后沉默。
7. **中文作答**：`answer`、`conditions`、`claims.text` 用中文；`quote` 保留英文原文。
8. **覆盖全部问题**：`answers[]` 与输入的 `question_id` 一一对应；无法回答的用
   `insufficient_evidence` 并说明核对了哪些段落。
9. **每题 2–5 条论断**，每条 1–3 条证据；不做逐段摘要、不复述全文。
10. **结合完整性标记**：引用带 `possible_truncation` 的段落时，涉及其段尾数值的
    结论必须降为 `partial` 并注明。
