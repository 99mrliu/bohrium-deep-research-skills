# 检验选择决策树与口径（premise_stats.py 实现的确切规则）

## 决策树（每个 特征×分组 组合独立走一遍）

```
各组 n ≥ 3？
 ├─ 否 → 记录 error，不检验（不猜）
 └─ 是 → 前提检验（α=0.05）
     1. 每组 Shapiro-Wilk（n>500 时固定 seed=0 抽 500；p>α 视为满足）
     2. Levene 方差齐性（p>α 视为满足）
     全部满足？
     ├─ 是，2 组 → 方差齐:Student t；不齐:Welch t；效应量 Cohen's d
     ├─ 是，≥3 组 → 单因素 ANOVA（η²）；显著时两两 t + Bonferroni
     └─ 否 → 2 组: Mann-Whitney U（rank-biserial r = 1−2U/(n1n2)）
             ≥3 组: Kruskal-Wallis（ε²=(H−k+1)/(n−k)）+ Dunn 两两（Bonferroni，结校正）
```

## 多重比较口径（必须在报告中声明）

- 族 1：特征族。案例要求检验 m 个指标（Iris m=4，Wine m=13）时，特征级显著性
  以 Bonferroni α/m 判定；原始 p 一并报告，不得只报校正后口径。
- 族 2：两两比较族。k 组产生 k(k−1)/2 对，p 乘以对数（Bonferroni）后截断到 1。

## 区分度排序口径

按效应量降序：参数路径用 η²，非参路径用 ε²，两组路径用 |Cohen's d| 或 |rank-biserial|。
排序是描述性的筛查结果，不替代推断结论；p 不显著但效应量大的指标应在报告中
单独点名（样本量或检验力问题的信号）。

## 回归口径（regress 子命令）

- Spearman 相关：单调关联，抗异常值；与 Pearson 结论冲突时以 Spearman 为准并说明。
- 标准化 OLS：X 与 y 均 z 化，β 可比；报告 R²、调整 R²、VIF（>10 提示共线性，
  此时 β 解释降级为"相关结构"，不得解释为独立贡献）、残差 Shapiro。
- 强制声明：相关与标准化系数是筛查证据，不构成因果。

## 前提检验的已知边界

- Shapiro-Wilk 在大样本对微小偏离过敏：n>200 且 p 略低于 α 时，应结合偏度/QQ 图
  人工复核再决定是否降级非参（脚本严格按 p>α 判定，人工复核意见写入报告）。
- Levene 对非正态敏感；正态性已失败时方差齐性结论仅供参考。
- ε² 的保守下界截断为 0（H<k−1 时）。
