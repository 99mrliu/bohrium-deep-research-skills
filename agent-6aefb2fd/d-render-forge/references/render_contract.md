# 渲染契约（figure_forge.py / report_forge.py 实现的确切规则）

## 1. 意图→图型映射（不可随意替换）

| 分析意图 | 唯一允许图型 | 禁止 |
|-|-|-|
| 看单变量分布 | 直方图+箱线双联 | 只用箱线（掩盖多峰） |
| 看组间分布差异 | 分组箱线+抖动散点叠加 | 只画均值条形图（掩盖分布与样本量） |
| 看多变量关联 | Spearman 热图（色标 [-1,1]，标注数值） | Pearson 冒充单调关联、无标注色块 |
| 看指标排序 | 横向条形图，值轴从 0 起 | 截断值轴放大差异 |
| 看回归拟合质量 | 残差-拟合散点 + 残差直方图（零参考线） | 只报 R² 不看残差 |

任务要求其他图型时：可以补充，但上述意图对应的图型必须至少各有一张。

## 2. 坐标轴与聚合诚实

- 计数轴、条形值轴一律从 0 起；散点/箱线轴按数据范围。
- 图上呈现的一切统计量（箱线五数、散点、热图值）直接来自 cleaned 表或统计 JSON，
  与正文口径同源；manifest 中记录每张图的 source_table、columns、aggregation、n_rows。
- 聚合层级必须与底层数据一致：按 class 分组画图就不得以全样本统计量替代。

## 3. 确定性渲染

- Agg 后端、150 dpi、固定 seed=0 的散点抖动；同一输入逐字节可复现布局（PNG 元数据
  除外）。禁止在绘图脚本里引入时间戳标题等不确定元素。

## 4. 报告数字溯源（verify 规则）

- 核验范围：report.md 中全部 ≥3 位有效数字的数值字面量（小数或整数）。
- 豁免：1–2 位有效数字（小节号、个数计数）；行首编号样式（`2.3 …` 小节号）。
- 匹配规则：报告数字 x 与任一源值 y 满足 |x−y| ≤ 0.5×10^(⌊log10|x|⌋−d+1)，
  d 为 x 的有效位数（即允许四舍五入到报告精度的同值）；x=0 时要求 |y|<1e-12。
- 无源数字是非零退出（6）的交付阻断项：要么改回源值，要么把产生该数字的证据
  JSON 加入 --sources。**禁止删除数字来通过核验**——数字必须存在且有源。
- 百分数写法（如 62.5%）与源值小数（0.625）不同值；报告统一用小数，或把百分数
  也写进证据 JSON（推荐前者）。

## 5. 已知边界

- verify 不理解语义（它不知道 0.9414 是 η² 还是 p），只保证"有源"；语义正确性由
  scaffold 的机器渲染与撰写者负责。
- 图注/坐标轴标签中的数字也在核验范围内；刻度由 matplotlib 自动生成不受影响。
