# 证据定位符（locator）格式

## 标准形式

```
[来源:<文件名> 第<N>页]
[来源:<文件名> 第<N>页, 偏移<M>]
[来源:<文件名>(记录)]        ← 记录型材料（JSON/CSV）专用
```

- 页码以提取文本层中 `\f` 拆页结果为准，从 1 起；与 PDF 物理页码一致
  （pdftotext 逐页输出）。
- `偏移` 是归一化（NFKC + 空白折叠）后引文在该页文本中的字符偏移，
  由 `extraction_qc.py locate` 输出，可选登记。
- 记录型材料无页概念，必须写明是记录而非引文。

## 引文规则

1. 引文 = 从文本层**复制**的连续字符序列；转述必须明确写成转述，
   不得混入引号。
2. 跨页引文拆成两条，各自 locate 命中后分别登记页码。
3. 归一化后少于 8 字符的引文不足以定位（脚本拒绝），换更长的片段。
4. 证据表中每条证据必须同时有：引文、locator、以及它在综述中支撑的
   那句话——三者缺一，该证据不得进入结论。

## 失败处置速查

| locate 结果 | 含义 | 动作 |
|-|-|-|
| 命中 1 处 | 正常 | 登记 locator |
| 命中多处 | 引文不唯一 | 换更长片段或在证据表注明多处出现 |
| 未命中 | 转述冒充引文 / 跨页拼接 / 记错出处 | 回文本层重新复制；两次失败弃用 |
