# 合成示例语料说明（非正式测试案例）

三篇虚构文献支撑本示例（全部为演示而编造，不对应真实论文）：

- **paper_a.txt（虚构，2024）**：直接实验证据。在数据集 D 上，方法 M 把指标 X
  从 0.71 提升到 0.79，双盲对照、3 次重复、报告置信区间。→ G1 支持证据，高严谨。
- **paper_b.txt（虚构，2025）**：直接实验证据。在数据集 D 上，方法 M 仅把 X
  从 0.71 提升到 0.72，单臂小样本。→ G1 反证，中严谨。
- **paper_c.txt（虚构，2023）**：间接证据。综述转述"M 类方法在类似数据集上
  普遍有效"。→ G2 支持证据（间接），无反证。

G1 构成真实冲突：两篇直接实验结论相反；按准则优先级，直接性（平）→
证据类型（平）→ **方法严谨度决定胜负**（high 胜 medium）——注意 2025 年的
反证更新，但时效排在最后，不能抵消严谨度差距。
