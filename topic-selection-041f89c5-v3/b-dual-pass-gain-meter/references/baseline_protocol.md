# 基线通道协议（pass0 公平性规则）

基线稿的目的是复现"未加载技能的基础 Agent 在相同输入下的典型产出"，
作为对照组。对照组一旦被污染，全部增益数字失去意义。

## 允许省略的（协议步骤）

- 逐篇精读与证据表提取（允许只浏览标题/摘要级信息）；
- 覆盖边界声明与纳排留痕；
- 证据锚点（允许凭印象写结论）；
- 冲突证据检索与不确定性登记；
- 任何脚本调用。

## 禁止做的（稻草人化）

- 禁止故意留空契约字段——基础 Agent 通常会尝试填满；
- 禁止故意写错事实或编造文献——基础 Agent 的典型问题是"无锚点"，不是"说假话"；
- 禁止使用比 pass1 更少的输入信息——两稿必须读同一套材料；
- 禁止在写完 pass1 之后回头修改 pass0（逆向工程增益）。

## 资源约束

- pass0 最多 4 次模型请求、建议 2–3 次；超过即偏离"快速通道"定义。
- pass0 一次性成稿，不迭代；发现错误也保留原样（它是测量仪器，不是作品）。

## 偏离登记

任何偏离上述规则的情况（如材料太少导致 pass0 与 pass1 趋同），必须在
result.json 的不确定性字段与 gain_report 的附注中写明。
