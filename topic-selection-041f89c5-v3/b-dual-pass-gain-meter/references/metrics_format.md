# 增益指标定义（gain_meter.py 的计量口径）

所有指标对两稿（baseline/final）分别计算，差值 = final − baseline。
脚本只做确定性文本计算，不做语义判断；指标是代理量，解释如下。

| 指标 | 计算方式 | 期望方向 | 解释 |
|-|-|-|-|
| 契约字段填充数/填充率 | 契约字段中值非空（非 null/""/[]/{}）的比例 | ↑ | 完整性增益 |
| 证据锚点数 | 全文中定位模式（`[来源:…]`、`p. N`、`第N页`、`表N`、`Fig. N` 等）命中总数 | ↑ | 可核验性增益 |
| 无边界越界断言数 | 越界断言模式命中且 ±60 字符窗口内无边界限定词的数量 | ↓ 或不增 | 过度声称的消除 |
| 不确定性条目数 | uncertainties 字段的列表项数（字符串则按非空行计） | ↑ | 诚实边界声明 |
| 冲突登记数 | 冲突/矛盾/不一致/conflict/contradict 等词出现次数 | ↑ 或不减 | 冲突证据是否被登记 |

## 判定规则（五项）

1. 填充率提升（或两稿均已填满）；
2. 证据锚点增加；
3. 无边界越界断言减少或不增；
4. 不确定性登记增加；
5. 冲突登记增加或不减。

任一不满足 → 该维度"增益未证实"，不许宣称有增益；连续两轮修不好则如实登记。

## 已知局限

- 锚点计数是文本模式匹配，不验证锚点真伪（真伪核验属于其他技能的职责，
  本报告只证明"严谨稿更可核"这一相对事实）；
- 冲突登记数是词频代理，可能把"无冲突"误判为冲突——出现时人工核对上下文；
- 指标不测量结论正确性本身，只测量可核验性、完整性与诚实度的相对变化。
