# 合成文献笔记（演示用，非真实文献）

- [S1] 合成来源：LLZO 石榴石型固态电解质与锂金属负极接触时界面阻抗可达数百 Ω·cm²，
  主要源于界面润湿性差与孔洞形成（合成笔记，2024）。
- [S2] 合成来源：在 LLZO 表面磁控溅射 5–20 nm Al 或 ZnO 缓冲层可将界面阻抗降至
  10 Ω·cm² 量级（合成笔记，2024）。
- [S3] 合成来源：锂枝晶沿晶界穿透是固态电池短路的主要失效模式，
  临界电流密度普遍低于 1 mA/cm²（合成笔记，2023）。
- [S4] 合成来源：堆叠压力 2–5 MPa 可显著延缓界面孔洞扩展，
  但过高压力会加速蠕变短路（合成笔记，2023）。
- [S5] 合成来源：硫化物电解质（如 Li6PS5Cl）离子电导率可达 10⁻³ S/cm，
  但对空气与水分敏感，需全程手套箱操作（合成笔记，2024）。
