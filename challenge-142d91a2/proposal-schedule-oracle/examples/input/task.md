# 合成开题任务（非正式案例）

课题：单细胞转录组解析结直肠癌肿瘤微环境的细胞互作网络。

给定条件：研究周期 **24 个月**；人员为 **2 名在读研究生**（无其他编制）；
总经费 **30 万元**。临床样本仅在第 5–10 月可采集，测序平台机时仅在
第 9–13 月可预约。

要求：完成开题报告的阶段计划章节。技术路线为：文献调研与方案设计 →
伦理审批与入组协议 → 临床样本采集与单细胞悬液制备 → 单细胞测序建库
上机 → 数据质控与批次校正 → 细胞类型注释与微环境分群 → 细胞通讯与
轨迹分析 / 关键亚群功能验证 → 公共队列独立验证 → 论文与开题成果汇总。

阶段计划必须落在给定周期、经费与人员条件内，给出关键路径与余量说明；
风险章节须以可计算的排期裁定信号（超期量、超载月份）作为触发信号依据。
