# 合成开题任务：青藏高原草地样带放牧强度调查

（本任务为合成示例输入，非平台正式案例。）

拟在青藏高原某高寒草甸样带开展放牧强度梯度调查。2023 年已沿样带完成 8 个样方的
前期摸底（见 `prior_survey_2023.csv`），覆盖围栏对照与轻、中、重三个放牧强度，
测得地上净初级生产力（ANPP）与群落 Shannon 多样性。前期数据提示：重牧样地 ANPP
较对照下降约三成，多样性下降约两成，但样本量不足以定位退化阈值。

请在此基础上撰写 24 个月期的开题报告，要求：研究问题可证伪且附判断标准；研究目标
含指标、阈值及阈值依据、考核时间点；技术路线每一步明确服务哪个目标；每个目标给出
验证方式（对照与统计判据）与可考核的预期成果；风险须有触发信号、备选方案与决策时点。
交付前须通过对齐裁定。
