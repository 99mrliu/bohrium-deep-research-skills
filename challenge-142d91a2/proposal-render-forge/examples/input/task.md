你是水利工程与气象交叉方向的博士研究生。导师要求你完成开题报告，研究题目为
「城市内涝时空预测模型研究——融合雷达定量降水估计与图神经网络的内涝风险预警方法」。

硬性条件（写入开题并逐条遵守）：

- 研究周期：2027-03 至 2029-02，共 8 个季度，第 4 季度末中期检查；
- 经费预算：28 万元；人员：博士生 1 名，硕士生 2 名协助数据标注；
- 阶段计划须分解为不少于 6 项任务，明确起止季度与交付物。

1. 可继续编辑的 Markdown 开题报告：七要素章节（研究背景与缺口 / 问题定义 /
   研究目标 / 技术路线 / 阶段计划 / 风险与备选 / 预期成果）编号固定 1–7，
   表格用 GFM 格式，引用用行内 [S#] 标注，文末自动生成来源清单；

   渲染横向甘特条；另附自包含 HTML 预览页；
