# 存储/编码故障分类与证据标准

每项故障必须给出**字节级或行级证据**，不接受"看起来乱码"这类主观描述。

## 1. 编码类

| 故障 | 证据标准 | 典型评分 |
|---|---|---|
| 非 UTF-8 编码（gb18030/big5/latin-1） | 候选解码打分表：utf-8 解码失败或含 U+FFFD，而候选编码可解码且可打印比更高 | 0.9 |
| 双重编码 mojibake | 文本含 Latin-1 补充区连续字符（如 `æµ‹è¯`），且 `encode('latin-1').decode('utf-8')` 后 CJK 字符数显著增加、乱码字符数下降；附 before/after 样本行 | 0.5–0.99 按改善率 |
| BOM | 文件头 `EF BB BF`（UTF-8）/`FF FE`/`FE FF`（UTF-16） | 0.99 |
| 编码歧义 | 两个候选编码评分差 < 0.02 | 0.5，标 ambiguous |

## 2. 结构类

| 故障 | 证据标准 | 典型评分 |
|---|---|---|
| 混合行尾 | CRLF/LF/CR 三类计数中两类以上非零 | 0.95 |
| 错误分隔符 | 备选分隔符中某者的"众数列数一致性 × 列数"显著高于逗号 | 0.9（一致性 ≥0.98 时才建议重序列化） |
| 参差行（ragged rows） | 各行字段数一致性 < 0.98 | 0.6，标 ambiguous，不得擅自合并/截断 |

## 3. 字符类

| 故障 | 证据标准 | 典型评分 |
|---|---|---|
| 不可见字符 | NBSP(U+00A0)、ZWSP(U+200B)、ZWNJ(U+200C)、ZWJ(U+200D)、行内 U+FEFF、表意空格(U+3000) 的逐类计数 | 0.9 |
| 全角字符 | 全角数字/字母/句点/百分号（U+FF10–FF19 等）出现单元格数 | 0.9 |

## 4. 数值表示类（只报告、不转换语义）

| 故障 | 证据标准 | 处置 |
|---|---|---|
| 哨兵缺失码（-999/-9999/NA/N/A/null/ND/—/空白/缺失） | 逐 token 计数 | **本层不动**；语义（未检测/低于检出限/录入缺失/真值 0）由数据字典裁决 |
| 低于检出限标记（`<0.01`） | 正则 `^<\s*\d` 计数 | 保留原字面值；是否转 LOD/2 等由工单决定，默认不转 |
| 科学计数法文本 | `1.2e-3` 形计数 | 保留字面值与精度，禁止浮点重写丢位 |
| 千分位 vs 小数逗号 | `1,234` 形与 `1,23` 形并存 | 高严重歧义；无法核定则该列保留字面值并入隔离队列 |
| 数值内嵌单位（`12 mg/L`） | 数字+单位串计数 | 拆分与否由字典/工单决定；拆分时单位字符串入台账 |

## 5. 日期类

混排日期格式（`2024-01-05` / `05/01/2024` / `20240105`）只报告计数与样例；
统一格式时保持 ISO 8601 文本，不得转为 Excel 序列数或丢失时区。
