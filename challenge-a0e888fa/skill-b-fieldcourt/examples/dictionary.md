# 数据字典（合成示例）

| 字段 | 含义 | 约束 |
|---|---|---|
| sample_id | 样品编号，主键的一部分 | 形如 W-NN，大小写不敏感 |
| metric | 指标名，主键的一部分 | 溶解氧/氨氮/总磷/浊度 |
| value | 测量均值 | 数值或缺失码 |
| unit | 单位 | 浓度类规范单位为 mg/L |
| n | 重复测定次数 | 正整数 |

## 缺失码表（本案例约定）

- `ND`：未检出（not_detected）
- `<数值`：低于检出限（below_lod），保留原字面值
- `-999`：录入缺失（entry_missing）
- `0`：真值 0（true_zero），是有效测量值

## QC 规则（合成）

- 溶解氧物理界：0–20 mg/L
- 总磷物理界：0–5 mg/L
