# 单位注册表（仅可乘线性换算）

引擎只执行注册表内、同量纲、纯倍率的换算；每次换算做**逆运算复核**
（换算结果反向算回，与原值相对差 > 1e-12 即判定失败并回退原值）。
带偏移的换算（℃ ↔ K ↔ ℉）一律拒绝：保留原值、写入复核队列。

## concentration（相对因子，基准 mg/L = 1）

| 单位 | 因子 | 备注 |
|---|---|---|
| mg/L | 1 | |
| μg/mL（µg/mL） | 1 | 与 mg/L 数值相等，常见"换算"实为写法统一 |
| g/L | 1000 | |
| μg/L（µg/L） | 0.001 | |
| ng/L | 1e-6 | |
| mg/mL | 1e6 | |
| g/mL | 1e9 | |
| % | 1e4 | 质量体积百分浓度 w/v；v/v、w/w 不在表内，拒绝换算 |

## mass（基准 mg = 1）

mg=1，g=1e3，μg/µg=1e-3，kg=1e6。

## volume（基准 mL = 1）

mL=1，L=1e3，μL/µL=1e-3。

## dimensionless

NTU、pH、空串：仅允许"写法统一"，数值不变。

## 换算公式

`y = x × factor[in] / factor[canonical]`；台账记录 `in->canonical (x倍率)`。

## 判定规则

1. 单元格内嵌单位（`0.45 μg/mL`）优先于字段级声明单位；
2. 字段级 `observed` 有多个不同单位且单元格未内嵌 → 单位不明，保留原值 + 复核；
3. 目标单位与源单位量纲不同 → 拒绝，保留原值 + 复核；
4. 有效位：换算结果用 repr 往返的最短十进制表示，不多不少；
5. 科学计数法文本先按 float 解析换算，结果按同样最短表示写回；
   若字段语义要求保留原写法，置 policy=keep。
