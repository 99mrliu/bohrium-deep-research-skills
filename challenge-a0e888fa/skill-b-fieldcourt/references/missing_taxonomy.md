# 缺失分类学：四类语义与判定树

把"空白"当成 0、把"未检测"当成缺失并按均值填补，是科研数据清洗最典型的两处
事实性错误。本技能只承认四类缺失语义，且**默认动作是标记而非填补**。

## 四类语义

| 类 | 含义 | 典型 token | 下游口径 |
|---|---|---|---|
| `not_detected` | 做了检测但未检出 | ND、n.d.、未检出 | 不是 0，也不是缺失；统计时按规则单列 |
| `below_lod` | 检出但低于检出限/定量限 | `<0.01`、<LOD、<LOQ | 保留原字面值 `<0.01`；是否转 LOD/2 由工单显式下令，默认不转 |
| `entry_missing` | 应记录而未记录 | 空、NA、N/A、null、-999、—、空白 | 真缺失；只在工单显式给规则时才填补 |
| `true_zero` | 真实测得 0 | `0`、`0.0` | 是有效测量值，**不得**与缺失混同 |

## 判定树（对每个哨兵 token 逐字段裁决）

1. 数据字典是否给该字段的缺失码表？→ 以字典为准，source 记字典位置。
2. 字典未载明：token 是否形如 `<数值`？→ `below_lod`。
3. token ∈ {ND, n.d., 未检出} → `not_detected`。
4. token ∈ {-999, -9999, NA, N/A, null, None, —, 空白, 空字符串} → `entry_missing`
   （哨兵码只是录入约定，不携带"未检测"语义）。
5. 值 `0`/`0.0` → `true_zero`，不是缺失。
6. 无法判定 → 不分类、保留原值、写入 review_queue，**不得猜**。

## 处置策略（policy）

- `mark`（默认）：原值保留，台账记录分类；下游可按需过滤。
- `empty`：工单明确要求"缺失置空"时使用；台账记录旧值。
- `keep`：字面值有证据意义（如 `<0.01`）时原样保留。
- 任何 `fill`（均值/中位数/LOD 分数倍）只在本技能之外、工单显式下令时由
  Agent 逐格声明执行；引擎不提供插补功能。

## 单位注意

`μg/mL` 与 `mg/L` 数值相等（都是 10⁻³ g/L 量级）：单位"修正"若改变数值，
必须先在注册表内确认量纲一致并做逆运算复核——参见 unit_registry.md。
