# 去重键裁定手册

只删"整行完全相同"的记录会把大小写、空格、全半角、单位写法不一致的近似重复
留在表里；乱定主键又会把不同样品误并。本手册规定主键的确定与冲突处置。

## 主键确定（按优先级）

1. **工单/数据字典显式指定的键**（样品编号、受试者标识、时间戳组合）→ 采用，
   source 记工单条目。
2. 字典未指定：用 `field_survey.py` 的键候选分析——归一化后 `distinct == rows`
   的列（或列组合）才可作键；单列不唯一时用 2–3 列组合（如 样品编号+指标）。
3. 没有任何列组合唯一 → 不去重，把"疑似重复组"整体写入 review_queue，
   由人复核；**不得**按"看起来一样"删行。

## 归一化规则（仅用于键比较，不改写数据）

`casefold`（大小写）→ `fullwidth`（全角→半角）→ `strip`（首尾空白）→
`collapse_space`（内部连续空白合一）。比较用归一化键，保留行用原始值。

## 保留策略（dedup.keep）

- `most_complete`（默认）：非空单元格最多者；并列取先出现的行。
- `first` / `last`：工单指定时序语义时使用（如"以后一次录入为准"取 last）。
- 每次丢弃都在台账写完整行 JSON + 策略 + 依据，可逐行复核恢复。

## 键冲突（同键不同值）——最高警戒

归一化键相同但其他字段值不一致 ⇒ 这不是重复，是**冲突**（可能是不同样品
误用同号、或录入错误）。处置：**全部保留**，逐行写入 review_queue，写明
冲突键与差异字段；绝不按 keep 策略删。冲突组数计入质量报告。

## 与异常值的关系

去重先于异常标记执行（避免重复行扭曲 IQR 诊断）；但 IQR 只是辅助证据，
最终保留/剔除理由必须落在物理界或工单规则上。
