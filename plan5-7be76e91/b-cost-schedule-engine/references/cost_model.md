# 成本口径模型（cost_model.md）

本文件定义 `cost_ledger.py` 的口径，并把每个口径对应到题目点名的典型失败模式。
所有算术由脚本以 `decimal.Decimal` 完成；模型只负责抽取条目、填字段、挂来源。

## 1. 五类成本口径（category）

| category | 中文 | 定义 | 常见漏算 |
|---|---|---|---|
| equipment_time | 机时费 | 设备小时 × 小时费率 | 只写"用了 X 小时设备"却不乘费率 |
| consumable | 耗材 | 数量 × 单价 | 只写单价不写数量与重复次数 |
| labor | 人力 | 工日（或工时）× 工日费率 | 完全漏掉人力工日 |
| outsourcing | 外送 | 批次/样品数 × 外送单价 | 把外送表征当成"免费" |
| other | 其他 | 不属于上列的条目，必须写清 name | 改装、培训、优先排期费等 |

## 2. 一次性投入 vs 按次消耗（basis）

- `one_time`：`line_total = quantity × unit_price`。不随实验重复次数放大。
  例：设备改装、方法开发、优先排期费。
- `per_run`：`line_total = quantity × unit_price × runs`。随 runs 放大。
  例：每轮实验的机时、试剂、人工。

**失败模式对应**：题目点名"不区分一次性投入与按次消耗"。若把一次性改装费
按 per_run 乘 runs，会虚增成本；把按次耗材当 one_time，会漏算放大效应。
脚本强制每个条目声明 basis，台账中一次性与按次分列小计。

## 3. 缺值即缺陷，绝不静默当 0

- 缺 `quantity` 或 `unit_price` → 进缺陷清单，exit 3，产物仍写出（可复核）。
- 负数、非数字、布尔值、非有限数 → 同样 exit 3。
- `runs` 缺省为 1；非正整数 → exit 3。

## 4. Decimal 算术

- JSON 解析即 `parse_float=Decimal`，从源头杜绝 float。
- 输出全部金额经 `dstr()` 规整为紧凑十进制字符串，无双跑差异、无尾差。
- 演示算例（examples/plan_record_P1.json）：微量滤膜 `0.1 × 7 = 0.7` 精确；
  float 运算会得到 `0.7000000000000001`。selfcheck 对该条目做精确断言。

## 5. 与题目失败模式的对照表

| 题目点名失败 | 本引擎的机检点 |
|---|---|
| 成本只写耗材单价，漏机时费/人力 | category 五口径分列小计，缺一栏在台账里显形 |
| 不区分一次性与按次 | basis 强制二选一，分列合计 |
| 缺数量/单价拍脑袋补 0 | 缺陷清单 + exit 3 |
| 数字转录错误 | pareto.py 直接读 ledger/time 产物，不手抄 |
| 浮点尾差 | 全链路 Decimal，输出十进制字符串 |

## 6. 币种说明

脚本按输入数值原样求和，不做汇率换算。若材料中出现多币种，模型必须在抽取
阶段先统一币种并在 `source`/`locator` 注明换算依据，否则应把该条目标记为
待确认项而非直接入账。
