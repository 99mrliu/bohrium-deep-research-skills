# 模拟吸收光谱数据：清洗、分组统计与发表级可视化

> 本案例为**合成示例**（synthetic demo）：数据由 examples 中的生成脚本
> 用固定随机种子模拟产生，仅用于演示 Skill 的调用方式与输出结构，
> 不构成任何真实实验结论。

## 任务
1. 读取数据字典与字段语义，确认数据口径：报告每列缺失值数量、重复记录
   数量与处理方式，异常值（IQR 准则）只标记不删除，全部口径必须留痕。
2. 对全部数值变量计算描述统计量：n、均值、标准差（SD）、标准误（SEM）、
   中位数、四分位数、最小/最大值；分类变量给出频数表；按 batch 分组
   计算分组统计。
3. 生成图件（300 dpi PNG + 嵌入式字体 PDF + 可编辑 SVG，单栏 89 mm 宽，
   色盲友好配色，坐标轴含单位）：(a) 数值变量分布图；(b) 按 batch 分组
   箱线图（叠加散点）；(c) 关键变量两两散点图（分组着色）；(d) 数值变量
   相关热图（标注相关系数）。
4. 所有图需附中文图注，说明样本量 n、误差线/须线含义与数据来源
   （合成示例数据）。
5. 输出 result.json，字段遵守 case.json 的 output_contract；所有数字
   必须可由源数据复算。
