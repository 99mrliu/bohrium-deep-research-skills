# 视觉编码策略

## 编码通道精度序（定量数据）

位置 > 长度 > 角度/斜率 > 面积 > 颜色饱和度 > 色相。
决策引擎为每个图件显式声明编码映射，并把低精度通道留给低精度任务
（如热图用色相表达符号、格内数字承担精确值）。

## 各图件编码映射（decide.py 输出格式）

- **分布图**：x=变量取值（右偏正值为对数轴），y=频数，曲线=KDE，
  分面=每变量一面板；
- **分组箱线图**：x=组（位置），y=变量取值（位置），色=组（与散点
  图例一致），箱体=Q1–Q3，须线=1.5×IQR，散点=原始观测（固定种子
  抖动）；
- **散点图**：x/y=两变量（位置通道），色=分组，面板标题=Pearson r
  与 n；
- **相关热图**：格色=r（发散色 RdBu_r，固定 [-1,1]），格内文本=r
  精确值（补偿颜色精度损失）。

## 禁止的编码实践

| 实践 | 问题 |
|---|---|
| 面积/角度编码定量差异（气泡、饼图） | 感知非线性，系统性夸大 |
| 双 y 轴 | 相对尺度可任意调，制造虚假相关/脱节 |
| 截断纵轴 | 长度编码失去比例语义 |
| 3D 透视 | 位置判读失真 |
| 彩虹色标（jet/rainbow） | 非感知均匀、色盲不友好、灰度混乱 |
| 未标注的对数轴 | 读者按线性解读，结论被改变 |

## 颜色使用纪律

- 分类色：Okabe-Ito 顺序取用，与图例严格 1:1；
- 发散色：仅用于有天然中点的量（相关系数 0），色标固定 [-1,1]；
- 顺序色：不用于无序类别；
- 灰度打印：前 3 色灰度亮度差需 ≥15；临界时以线型/形状冗余编码，
  审计报告 advisory 说明。

## 坐标轴尺度决策记录

每个对数轴决策写入 `log_scale_decisions`：列名、偏度、判定、理由；
图内轴标注明"（对数尺度）"；图注再次声明。线性/对数的选择必须在
图件与文档中同时可考。
