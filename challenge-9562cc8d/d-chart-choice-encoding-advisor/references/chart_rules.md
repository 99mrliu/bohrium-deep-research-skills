# 图表选型规则库

## 数据类型 × 分析目的 → 图型

| 数据结构 | 目的 | 首选 | 否决（及理由） |
|---|---|---|---|
| 连续单变量 | 分布 | 直方图 + KDE | 饼图（无构成语义）；均值条（掩盖分布） |
| 连续变量 × 无序分类 | 分组比较 | 分组箱线图 + 抖动散点 | dynamite plot（隐藏分布与 n）；并列柱（非有序轴） |
| 连续 × 连续 | 相关 | 散点图（分组着色） | 气泡图（面积感知非线性）；3D 散点（透视失真） |
| 多变量数值 | 相关结构 | 相关热图（色标固定 [-1,1]，格内标注） | 未固定色标热图（跨图不可比）；网络图（布局引入无信息维度） |
| 时间/有序序列 | 趋势 | 折线图 | 并列柱（割裂连续性）；面积图（基线歧义） |
| 无序分类构成 | 构成比较 | 零基线条形图 | 饼图/环图（角度与面积编码不可比）——**强制禁止** |
| 两个量纲不同变量 | 联合展示 | 分面双面板 | 双 y 轴（相对尺度可任意调节，误导） |

## 强制约束（global_constraints，decide.py 输出）

1. `no_pie_for_unordered_categories`：无序类别禁饼图；
2. `zero_baseline_for_bars`：一切长度编码零基线，禁止截断纵轴；
3. `colorblind_safe_palette`：Okabe-Ito；
4. 对数轴规则：偏度 >1 且最小值 >0 → 对数轴并在轴标注明"对数尺度"，
   决策连同偏度数值写入 `log_scale_decisions`；含非正值的右偏变量
   不得强行对数化，改 advisory 说明。

## 面板与类别过载规则

- 分组比较面板按组间 F 统计量降序，至多 8 个；取舍在图注声明；
- 散点对按 |r| 降序取前 3，任务点名的变量对强制纳入（≤4 面板）；
- 分类水平 >12：advisory 建议分面或合并尾部为"其他"；
- n>300 的散点固定种子抽样 300 个并在图注声明。

## 分组列识别

1. 任务文本"按 X 分组"中的 X 精确匹配列名（优先级最高）；
2. 2–12 水平的字符串分类列；
3. 整数编码、2–12 水平、列名含 class/target/label/group/batch/批次
   的数值列 → 改判分类变量（进频数表，不进相关面板）；
4. 皆无：选名含 age/time/day 或正偏最明显的连续列做四分位等频分箱
   （4 箱），作为有序分组展示目标变量条件分布。
