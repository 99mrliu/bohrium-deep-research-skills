# Wholly invented end-to-end example

This example uses no platform case or real publication. Two fictional rooms give
plain `r` two meanings: pore radius and total resistance. Source MathML also
contains `r_{1}` and `r_{2}`, proving that full scripts remain part of identity.
The coating-radius unit `nm` has literal evidence; resistance units are
intentionally unreported and remain null rather than becoming inferred ohms.

Run from this directory:

```bash
bash run.sh
```

The runner rebuilds the ledger twice and compares hashes, validates the authored
`bindings.json`, and generates `out/valid/result.json` and both variable tables.
It also finalizes the untouched template early, requiring retained partial outputs
and a non-silent exit 2, then validates `bindings.invalid.json`. The adversarial file fabricates definition and
unit quotations and omits a formula and `r_{2}` coverage. The test requires exit
2 and checks explicit error messages. Finally it creates a temporary invented
no-formula case with a different dynamic output contract and requires
`insufficient_evidence` plus a null numeric `reported_value` (not zero).

A successful run creates `out/test_summary.json` and
`out/invalid/validation.json`, plus the result and variable tables described
above. These are reproducible generated artifacts, not additional source data;
machine-specific run caches are deliberately not part of the reusable bundle.
