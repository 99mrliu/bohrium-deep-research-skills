# Wilson 得分置信区间（wilson_interval）

覆盖率是比例量（命中数 k／可用参考数 n）。小样本或比例接近 0／1 时，正态近似
（Wald）区间会越界或覆盖概率不足，本技能统一采用 Wilson 得分区间。

## 公式

设 p̂ = k／n，置信水平 95% 取 z = 1.96，记 z² = z·z：

```
中心 = (p̂ + z²/(2n)) / (1 + z²/n)
半径 = z · √( p̂(1−p̂)/n + z²/(4n²) ) / (1 + z²/n)
下界 = max(0, 中心 − 半径)
上界 = min(1, 中心 + 半径)
```

n = 0 时区间无定义，实现返回 `(None, None)`，报告中记「不可估计」，禁止输出 0 或 1。

## 性质

- 区间恒落于 [0, 1]，不会越界；
- k = 0 时下界为 0、上界 > 0，如实反映「未命中但样本有限」的残余不确定性；
- 随 n 增大收敛于 Wald 区间；
- 对同一分母的分来源／分查询召回率同样适用（各切片 n 不变、k 变）。

## 参考实现

`scripts/hit_matrix.py` 中 `wilson_interval(k, n, z=1.96)`，纯标准库（`math.sqrt`）。
可独立复算：

```python
from hit_matrix import wilson_interval
wilson_interval(6, 9)   # → 约 (0.3542, 0.8794)
```

## 报告口径

- 报告中每个召回率必须附 Wilson95 区间与分母 n；
- 补检前后区间重叠不代表「无改进」、不重叠也不作统计显著性宣称——本技能只报告
  点估计、区间与新增命中清单，统计推断结论交由人工判断；
- `ambiguous` 单元不计入命中，其数量在 `uncertainty.ambiguous_cells` 单独披露。
