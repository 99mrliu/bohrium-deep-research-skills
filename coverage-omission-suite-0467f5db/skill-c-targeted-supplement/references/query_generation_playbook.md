# 查询生成手册（漏检驱动的四类原型）

本手册规定定向补检查询的生成规则。核心原则：**每条查询都必须从一条具体
漏检记录的原文词项生成**，并记录假设、目标漏检与生成依据；禁止从同义词表、
主题词表或“感觉”出发。漏检记录的原文词项来自本地材料中该记录的
标题、摘要、关键词字段（题录字段是组织者留存材料的一部分，允许引用）。

## 通用规则

1. 判别词项抽取：对漏检记录的规范化标题分词，去掉停用词与纯数字，
   按在冻结参考集内的文档频率升序取低频词（罕见词判别力更强）。
2. 每条查询必须携带以下字段（写入 supplement_log.csv）：
   `hypothesis`（针对哪类漏检）、`target_miss_ids`、
   `generated_from`（漏检记录 ref_id）、`quoted_terms`（引用的原文词项）、
   `source`（执行说明）、执行序号与时间信息（审计模式以固定顺序代替时间戳）。
3. 四类原型按固定顺序分批执行：a → b → c → d。
   每条漏检记录生成全部可用原型的查询；记录缺标题时 a/c/d 不可用，
   退化到 b 并如实记录。
4. 查询命中候选后，一律用冻结参考集重匹配裁决，不得把“候选存在”
   直接当作“漏检已覆盖”。

## 原型 a：原词补全式

**构造**：取漏检记录标题的规范化全串（或最长连续判别短语）作为查询词。
**假设**：初始检索对该标题的用词覆盖不全（截断、分词、字段遗漏），
以原词整串检索本地题录可命中。
**示例**：漏检记录 R0007 标题
“Coupled eddy-current braking in superconducting maglev bearings”，
查询词 = “coupled eddy current braking in superconducting maglev bearings”，
generated_from = R0007，quoted_terms = “eddy current braking superconducting maglev”。
**何时判零**：标题全串在本地全部留存文件中零命中——此时转入探针归因，
不得继续生成同义改写。

## 原型 b：作者 + 年锚定式

**构造**：第一作者姓氏 + 年份 ±1 的窗口；二者必须同时出现在候选记录中。
**假设**：标题存在变体（缩写、连字符、修订版措辞），但作者与年份稳定。
**示例**：R0007 第一作者 Nakamura、年份 2019 → 查询 =
(“nakamura”, {2018, 2019, 2020}) 共现。
**注意**：仅姓氏常见时（如 Wang）必须结合年份窗口与词项二次过滤；
命中后经冻结参考集重匹配确认身份，防止同姓氏异记录假阳性。

## 原型 c：引文追踪式

**构造**：
- 前向：在本地参考图与留存文件全文（含参考文献串）中查找**引用**漏检记录的
  记录——任何留存文件的正文/参考文献区出现该记录完整标题或标识符，
  即构成引文邻域命中；
- 后向：核对漏检记录自身参考文献列表中的条目是否在本地可解析，
  以判断该记录是否真实存在于来源体系内。

**假设**：漏检记录被来源库收录但未进入初始检索的返回窗口；
其引用者或被引者已在本地材料中，可通过引文串回捞完整题录。
**示例**：本地 corpus 中某综述的参考文献串含
“… Nakamura et al., Coupled eddy-current braking … (2019)”，
即对该标题构成前向命中，可定位题录。

## 原型 d：来源切换式

**构造**：与原型 a 相同的判别词项，但执行范围排除初始检索所用来源文件，
仅检索其余本地索引文件（如初始检索用 Crossref 响应，则切换至
EuropePMC 响应或出版商响应）。
**假设**：单一来源索引缺失，跨源可补。
**记账**：必须注明切换前/后的来源文件，便于审计核对“换源”真实性。

## 反例：同义词空转（禁止，属补检空转）

以下做法均属反模式，记录为反例：

1. **同义词替换循环**：把 “eddy current braking” 改写为
   “electromagnetic damping”“magnetic drag”等近义表达反复查询；
   若原词在本地零命中，近义词通常同样零命中，不产生新增覆盖却虚增查询成本。
2. **无目标漏检的查询**：查询不带 target_miss_ids，检索某个主题词后宣称
   “可能覆盖了部分漏检”——无法核算边际收益，禁止。
3. **用检索结果反推分母**：把补检新命中的记录并入“参考集”以抬高分母
   或抬升覆盖率——覆盖率分母只允许来自冻结参考集。
4. **零命中即宣称归因**：本地文件零命中只支持“来源库未收录”的
   探针证据，不能据此断言该文献不存在或不应计入分母。
5. **时间/来源不变的重跑**：相同查询词、相同来源、相同参数重复执行，
   只改变措辞包装——属于换皮重跑，不产生边际收益。

凡 supplement_log 中出现 verdict=zero 的查询，必须保留记录并计入成本，
禁止删除以美化收益曲线。
