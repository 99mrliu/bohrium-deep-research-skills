# 合成示例说明（非案例答案）

本目录下全部文件均为**合成示例（synthetic examples）**，仅用于演示技能产物的形状与字段语义，与任何真实案例无关，绝不代表任何评测案例的答案。

| 文件 | 用途 |
|---|---|
| `synthetic_case.json` | 演示 case.json 的最小结构（case_id、materials、output_contract）。 |
| `synthetic_bibliography.csv` | 演示可被 `refset_build.py` 解析的题录 CSV 格式。 |
| `synthetic_expected_reference_set.fragment.json` | 演示冻结参考集中两条记录的出处与处置字段形状（片段，非完整文件）。 |

任何人不得将本目录内容作为某真实案例的参考答案使用；示例中的文献信息全部为虚构或公开占位内容。
