# 标识符规范化与冲突处置规则

本文件是 `refset_build.py` 与 `coverage_check.py` 的规范化唯一标准。所有脚本行为以本文件为准；任何例外须写入 change_log。

## 一、DOI 规范化

1. 去除 URL 前缀：`https://doi.org/`、`http://doi.org/`、`https://dx.doi.org/`、`http://dx.doi.org/`（大小写不敏感）。
2. 去除文献前缀：`doi:`、`DOI:`、`doi `（大小写不敏感）。
3. 去除首尾空白字符、句点与结尾斜杠。
4. 全部转为小写。
5. 合法性校验：须匹配 `10.\d{4,9}/\S+`；不匹配则视为无 DOI（记 `doi=null`），不得部分截断使用。
6. 判断两个 DOI 是否相同，只比较规范化后的字符串。

## 二、PMID 规范化

1. 仅接受纯数字串（1 至 9 位），去除空白。
2. 带 `PMID:`、`PMID ` 前缀者先剥除前缀再校验。
3. 非纯数字（例如含连字符、字母）一律视为无 PMID。

## 三、PMCID 规范化

1. 统一大写，形式必须为 `PMC` 加数字（如 `PMC1234567`）。
2. `pmc1234567` 之类小写形式规范化为大写；无 `PMC` 前缀的数字串补上前缀。

## 四、arXiv 规范化

1. 剥除 `arXiv:` 前缀与结尾版本号（`v1`、`v2` 等）。
2. 新样式：`dddd.ddddd` 或 `dddd.ddddd:nnnn`；旧样式：`类别/七位数字`（如 `cs/9901001`）。其余形式视为无 arXiv 标识符。
3. 版本差异不视为不同文献；不同标识符段（如 `math.GT/0309136` 与 `math/0309136`）若无版本关系提示，按不同记录处理并交由标题相似度判重。

## 五、标题弱匹配键

1. 转小写；将标点符号替换为空格。
2. 去除停用词：the、a、an、of、and、in、on、for、to、with、by、is、are、was、were、using、based、study、studies、review、from、at、as、be、its。
3. 去除长度为一的词（中文字符除外）。
4. 剩余词元排序后构成元组；相似度采用排序词组 Jaccard 系数，阈值 0.85。
5. 该键仅用于去重与回退匹配，绝不替代标识符精确匹配。

## 六、标识符冲突判定与处置

1. 同一候选记录携带多个标识符时，逐一在本地响应索引中查找。
2. 若各标识符命中的题名字段两两 Jaccard 相似度均低于 0.6，判为 `identifier_conflict`。
3. 冲突处置：`disposition=needs_manual_review`，`usable` 保留为 true 但标记 `flags=["identifier_conflict"]`，以字段更全、来源更权威的响应记录为准展示，并在 uncertainty 中列出。
4. 冲突不得以"丢弃其中一个标识符"方式静默解决。

## 七、以结果定分母的禁令

规范化后的标识符仅用于核验与匹配；参考集（分母）的来源限定为题录文件、专家清单与参考图谱，与任何检索结果的并集无关。检索结果中出现的、但参考材料中不存在的条目，只进入覆盖统计的分子侧证据，绝不进入分母。
