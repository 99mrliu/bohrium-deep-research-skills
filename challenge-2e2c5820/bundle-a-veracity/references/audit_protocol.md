# 实验方案可行性审查协议（7 约束清单与分级规则）

## 1. 七约束清单 → 证据要求

| # | 约束 | 审查要点 | 所需证据（evidence.jsonl category） |
|---|---|---|---|
| 1 | 假设与变量 | 自变量/因变量/检测限等核心假设是否写明、可检验 | `假设与变量`：变量定义引文；检测限目标引文 |
| 2 | 对照组 | 阳性/阴性/空白对照是否设置，数量是否满足统计 | `对照组`：对照设置引文；孔数/重复数计算 |
| 3 | 设备与材料 | 设备是否在合同/清单内、是否可预约；耗材价格是否与合同一致 | `设备材料`：设备清单引文 + 合同比对；价格引文 + `计算` |
| 4 | 时间与成本 | 周期是否在合同窗口内；总预算是否超硬顶（逐项算术核算） | `时间成本`：进度引文；预算表引文 + `计算`（单价×数量 与合同单价核对） |
| 5 | 参数范围 | 关键参数是否落在 parameter_domain / 设备手册允许区间内；同一参数前后是否一致 | `参数范围`：参数引文 + 参数域比对；矛盾扫描报告回查 |
| 6 | 风险与异常 | 是否有失败预案、异常处理路径 | `风险与异常`：风险章节引文 |
| 7 | 伦理与安全 | 涉及人体样本/动物/病原体的，是否写明伦理审批、知情同意、生物安全等级 | `伦理与安全`：伦理表述引文，或 missing + absence_scope |

## 2. 门槛项（gating items）

以下为**一票否决**性质，判定为 fail 或 missing（按铁律 missing 计未满足）即触发否决：

- **伦理否决项**：涉及人体样本、动物实验、人源数据而无伦理审批/知情同意表述。
- **安全红线**：病原体操作生物安全等级超出合同允许的实验室等级；危险试剂无处置方案。
- **预算硬顶**：按合同单价算术核算的总成本超过合同预算硬顶。

## 3. 结论分级规则（verdict grading）

按以下顺序判定，取最先命中的级别：

1. **不可行**：任何门槛项 fail 或 missing；或同一方案存在无法调和的自相矛盾（如关键参数
   前后两值）且影响结论成立。
2. **无法判定**：必要素材缺失（合同、参数域、清单任一未提供，或 plans 无法索引），
   导致门槛项无从核验。对应 status=partial，并在 uncertainty 中列明缺什么。
3. **有条件可行**：存在非门槛的 missing 或 unknown 判定。必须附**显式条件清单**
   （每条对应一个 item_id），说明补什么证据后可升级为可行。
4. **可行**：全部条目为 pass 或 not_applicable。

## 4. 纪律

- 每个判定必须锚定逐字引文；无引文的判定一律不予采信（verify_anchors 会拒绝）。
- 跨章节、跨版本的数值矛盾**只记录、不调和**：在 contradiction 报告中并列呈现，
  由结论分级处理，禁止擅自择一采信。
- 来源可追溯：materials.json 记录每份素材的 JSON 路径；重跑时应能得到可比结论。
- 诚实状态：任何环节未能完成即报 partial，并在 change_record 与 uncertainty 中说明边界。
