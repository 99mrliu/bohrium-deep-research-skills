# 任务书（合成示例，非正式案例数据）

对 case.json 中 qPCR 病原体快速检测方案的 2 个候选版本（v1、v2）进行可行性评估。

要求：

1. 依据组织方合同（预算硬顶 5000 元、设备预约窗口、价格表、BSL-2 等级）与参数域，
   按七约束清单（假设与变量 / 对照组 / 设备材料 / 时间成本 / 参数范围 / 风险与异常 /
   伦理与安全）逐项判定。
2. 每条判定必须携带方案文本的逐字引文；方案未写明的门槛要素按未满足计入。
3. 核查同方案内与跨版本的数值口径矛盾。
4. 输出符合 output_contract 的 result.json，含 verdict、证据台账、矛盾报告、
   risk_items、summary，并诚实标注 status / sources / uncertainty / change_record。
