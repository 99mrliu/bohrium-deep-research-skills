# 实验方案可行性评分量规（7 维度 · 0–4 分）

本量规用于对 case 中**每一个候选版本**逐格打分。每格必须同时给出：

1. `score`：0–4 整数；
2. `evidence.locator`：证据定位（材料中的路径，如 `plans[1].sections.设备材料`、`采购合同.报价单.第2条`）；
3. `evidence.quote`：证据原文短引用（逐字摘录，禁止改写或凭印象概括）。

**证据为空（locator 或 quote 缺失/空白）的格子会被 `score_matrix.py` 直接拒绝（exit 2）。宁缺毋滥：找不到证据的版本标记 `无法评分`，禁止猜分。**

## 各维度锚点描述

### 1. hypothesis_variables 假设与变量（0.20）
- 0：无明确假设，自变量/因变量未定义或互相矛盾。
- 1：有假设陈述但变量定义含糊，无法据此设计测量。
- 2：假设与主要变量基本明确，但存在未控制的混杂变量且未说明。
- 3：假设可检验，变量定义清楚，主要混杂已识别并给出控制思路。
- 4：假设—变量—测量链条完整，混杂控制与材料原文一一对应，可直接转化为统计检验。

### 2. controls 对照组（0.15）
- 0：无对照设计。
- 1：提到对照但未说明类型、数量或设置方式。
- 2：有对照组但类型不完整（缺阴性/阳性/基线对照之一且无解释）。
- 3：对照类型、样本归属、随机/盲法安排明确，仅有小瑕疵。
- 4：对照体系完整（含必要的阴性/阳性/载体对照），随机化与盲法有原文依据。

### 3. equipment_materials 设备材料（0.15）
- 0：关键设备/材料未提及或显然不可得。
- 1：列出部分设备材料，但与合同/资源清单对不上，缺口未说明。
- 2：主要设备材料有着落，但存在未核实的可获得性、规格或批次问题。
- 3：设备材料与组织方合同/预约条款逐项对应，仅个别耗材需补确认。
- 4：全部设备材料有合同、报价或库存证据支撑，规格型号与方案要求一致。

### 4. time_cost 时间成本（0.15）
- 0：无时间表与预算，或明显不可能完成。
- 1：有粗略时间/费用估计，但与合同价格、预约档期矛盾。
- 2：时间表与预算大体合理，存在未计入的等待/审批/运输时间。
- 3：时间线覆盖主要环节（含审批与采购周期），预算与报价合同吻合，余量偏小。
- 4：时间—费用双账完整，关键路径与缓冲明确，所有数字可追溯到报价/档期条款。

### 5. parameter_ranges 参数范围（0.10）
- 0：关键参数缺失或超出设备/材料物理极限。
- 1：参数给出但无依据，且部分落在声明的有限域之外。
- 2：大部分参数在有限域内，个别参数越界或依据不足。
- 3：全部参数落在 case 声明的有限域内，依据基本充分。
- 4：每个关键参数都有域内取值 + 来源依据 + 灵敏度讨论。

### 6. risk_anomaly 风险与异常（0.15）
- 0：未考虑任何风险或异常分支。
- 1：泛泛提及风险，无触发信号与处置。
- 2：识别了部分主要风险，但缺触发信号或降级路径。
- 3：主要风险均有触发信号、后果与降级路径，个别缺转人工节点。
- 4：风险登记完整（触发信号/后果/降级路径/转人工节点），覆盖设备、材料、样本量、参数、伦理等类别。

### 7. ethics_safety 伦理与安全（0.10）
- 0：明显涉及伦理/安全对象（动物、人体样本、危化品、个人数据）但完全未提审批。
- 1：仅笼统声明"将遵守规定"，无对应审批路径。
- 2：识别了部分涉及项并给出审批名称，但存在把"未定"当"不涉及"或把"需办理"写成"已批准"的问题。
- 3：逐项判定涉及/未定/不涉及，审批路径正确，表述严谨。
- 4：在 3 分基础上给出审批材料清单、周期估计与对时间线的影响，且全部以机构规定为准作了限定。

## scores.json 模式

```json
{
  "plans": {
    "v1": {
      "dimensions": {
        "hypothesis_variables": {"score": 3, "evidence": {"locator": "plans[0].hypothesis", "quote": "……原文……"}},
        "controls":           {"score": 0, "evidence": {"locator": "...", "quote": "..."}},
        "equipment_materials": {"score": 0, "evidence": {"locator": "...", "quote": "..."}},
        "time_cost":          {"score": 0, "evidence": {"locator": "...", "quote": "..."}},
        "parameter_ranges":   {"score": 0, "evidence": {"locator": "...", "quote": "..."}},
        "risk_anomaly":       {"score": 0, "evidence": {"locator": "...", "quote": "..."}},
        "ethics_safety":      {"score": 0, "evidence": {"locator": "...", "quote": "..."}}
      }
    },
    "v_missing": {"status": "unscorable", "reason": "该版材料缺失，无法评分，不猜。"}
  }
}
```

权重覆盖：运行 `score_matrix.py --weights '{"hypothesis_variables":0.25,...}'`（权重和不必为 1，脚本会归一化）。
