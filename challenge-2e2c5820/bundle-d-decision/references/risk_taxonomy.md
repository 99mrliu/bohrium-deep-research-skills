# 风险分类学（risk taxonomy）

每条风险登记项**必须**包含 5 个字段：

| 字段 | 含义 |
|---|---|
| `risk` | 风险名称/描述 |
| `trigger_signal` | 触发信号：可观测、可监测的前兆或判据 |
| `consequence` | 后果：对进度、数据质量、经费、合规的影响 |
| `degradation_path` | 降级路径：触发后如何降级执行（降规格、换替代、缩范围、延后），保证结论仍有下限产出 |
| `escalation` | 转人工节点：什么条件下必须停下来交给 PI/专家/机构，禁止自动继续 |

另需给出 `category`，取值仅限以下六类之一：

## 1. 设备故障
- 典型触发：设备报错/停机、校准漂移超差、预约档期被取消、关键备件缺货。
- 标准降级路径：切换备用设备或校内共享平台 → 外送第三方检测 → 缩减测量指标集 → 调整采样时间窗。
- 转人工节点：替代设备改变测量原理或精度等级，需 PI 确认数据可比性。

## 2. 材料批次
- 典型触发：批次号变更、质检报告（COA）指标偏离历史批次、供应商断货、运输温控记录异常。
- 标准降级路径：启用备选供应商同规格材料 → 先做小批量预实验验证批次一致性 → 将批次作为协变量纳入分析 → 延后关键实验至新批次验证通过。
- 转人工节点：替代材料的规格/纯度等级与原方案不一致。

## 3. 样本量不足
- 典型触发：招募/获取速率低于计划 50%、不合格率超预设阈值、动物繁育数量不足、样本失访。
- 标准降级路径：延长采集窗口 → 合并中心/批次并控制批次效应 → 重算功效并下调效应量预期 → 缩减次要终点、保住主要终点。
- 转人工节点：主要终点功效跌破预设下限（如 80%），是否继续由 PI 决定。

## 4. 参数越界
- 典型触发：实测参数超出 case 声明的有限域、设备输出限幅、工艺窗口边缘良率骤降。
- 标准降级路径：回退到域内最近可行点 → 分步逼近（爬坡）而非跳变 → 将该维度从全因子降为单因素扫描 → 记录越界点但不外推结论。
- 转人工节点：任何越界参数的安全余量未知时，先停后议。

## 5. 伦理安全
- 典型触发：审批进度超期、伦理委员会要求补件、不良事件（动物异常死亡/人员暴露）、涉及范围判定从“未定”变为“涉及”。
- 标准降级路径：相关操作整体暂停 → 切换为不涉及伦理对象的替代版本（如离体/公开数据）→ 仅保留已获批范围内的实验。
- 转人工节点：任何不良事件、任何审批状态变化，一律立即转 PI 与机构伦理/EHS 部门。**伦理安全类风险没有自动继续的选项。**

## 6. 其他
- 凡不能归入以上五类者，须在 `risk` 描述中说明为何单列，并照常给出 5 字段。
