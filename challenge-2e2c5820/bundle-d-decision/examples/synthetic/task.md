# 任务（合成示例，非正式案例数据）

对 `/input` 中给出的课题（慢性社交挫败应激后小鼠社交行为与海马神经元活性）的 **3 个候选版本（v1 离体替代版 / v2 行为学观察版 / v3 行为学+组织学完整版）** 进行可行性评估与决策治理：

1. 逐版按 7 维度量规证据化打分（每格必须带证据定位与原文引文）；
2. 计算加权总分与排名，并对权重做 ±20% 敏感性分析；
3. 建立全案风险登记表（每条含触发信号/后果/降级路径/转人工节点）；
4. 逐版判定伦理涉及状态并给出审批路径（未定项列为确认项，涉及项写“需办理”）；
5. 给出逐版裁决与可执行条件清单，汇总 result.json。

预算约束：约 64 次模型请求 / 900 秒；产物写入 /app/output。
