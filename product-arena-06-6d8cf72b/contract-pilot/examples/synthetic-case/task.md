# 合成示例任务说明（SYNTHETIC EXAMPLE — 非正式案例）

阅读随附虚构论文 paper.txt，按 case.json 的 output_contract 交付：

1. `answer.summary`：不少于 10 字的笔记摘要。
2. `answer.measurements`：≥1 条测量值（name/value/unit，unit 限 mm、MPa、percent、cycles）。
3. `answer.open_question`：一个论文未回答的问题；确实没有则填 null 并给理由。

示例刻意包含一个先违规后修复的流程，演示 pilot 的诚实降级与修复清单。材料为虚构示例。
