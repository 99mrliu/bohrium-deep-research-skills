# 限制与边界（诚实声明）

1. **抽取由 Agent 完成，脚本只做约束与核验。**
   relation_validate / condition_lint / conflict_detect 检查的是
   “结构合法性与证据可回查”，不判断关系语义本身的科学真伪；
   语义确认属于阅读 Agent 的职责。
2. **引文匹配是鲁棒子串匹配，不是语义匹配。**
   NFKC 归一、弯引号/破折号直化、折叠空白可以吸收排版差异，
   但改写过的“引文”会被判不匹配——这是有意设计：宁可拒收也不放宽。
3. **定位只用组织方 JATS paragraph_id。** 输入包不提供 PDF 页码，
   自建页码不得声称是原 PDF 页码；不提供图像像素、补充附件、
   底层临床或实验数据，也不推断其中数值。
4. **不追求全量图谱。** 本 Skill 聚焦“条件化关系”这一个明确问题；
   实体识别覆盖面取决于 Agent 的阅读完整性，遗漏写入 uncertainty。
5. **冲突检测基于条件签名。** 两篇论文若用了文字不同但语义相同的
   条件描述而未被合并，数值冲突可能漏检；缓解办法是先把条件
   归一为条件节点再跑检测。
6. **根元数据只属于第一篇。** case.json 根部的 doi/title/authors
   仅描述 primary，不得套用到 secondary；语料内部以各自
   source_id 的元数据为准。
7. **查询 DSL 是固定的四类。** 任意自然语言问题需要 Agent 先翻译成
   查询规格；翻译失败时如实报告无法回答，而不是即兴检索。
8. **无外部依赖。** 纯 Python3 标准库；SVG 预览为脚本生成的简易
   圆形布局，graph.dot 供有 Graphviz 的环境渲染更美观的版本。
