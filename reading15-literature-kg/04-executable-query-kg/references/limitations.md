# 限制与诚实边界（limitations）

1. **语义抽取不在脚本内**：实体/关系/证据由 Agent 阅读原文撰写，脚本只做结构校验、
   证据精确核验、确定性查询与导出。Agent 漏抽的概念不会被脚本补出；这属于覆盖度
   限制，会在 `result.json` 的 uncertainty 中如实标注（如"仅覆盖方法/结果段落"）。
2. **证据核验是精确子串匹配**：quote 必须与 JATS 段落原文逐字一致（含标点）。
   好处是可机检、零歧义；代价是正文行内公式/上下标被线性化时，quote 必须按
   线性化后的文本照抄，不能按排版样式还原。可选 `secondary-publisher.xml` 仅用于
   人工核对，不做像素/图像级验证。
3. **无 PDF 页码**：本输入包的位置单位是组织方 JATS 段落 ID；任何 `page` 字段都会
   被拒绝。不要把自建分页称作"原 PDF 页码"。
4. **查询为精确匹配**：名称/别名（大小写不敏感）与关系名都是精确匹配，没有语义
   向量或模糊检索；别名没写进 `aliases` 的说法查不到（empty 是诚实结果，不是错误）。
5. **cross_source 以论文为单位**：只存在同篇多种文件格式（如同篇的 JSON 与
   Markdown）不算跨篇证据；不同来源必须对应 `sources` 中不同的论文声明。
6. **SVG 为静态分列预览**：适合数十节点规模的快速复核；大规模图（数百节点）会出现
   列内拥挤，此时以 `graph.md` 邻接表与 JSON/CSV 导出为准，SVG 仅作结构示意。
7. **不产出正式答案**：本 Skill 不携带任何针对组织方固定案例的预制结果；
   `examples/minimal/` 全部为 SYNTHETIC 合成示例，仅演示接口与流程。
8. **材料缺失时降级而非造假**：材料无法解析时只做结构校验，evidence_ok=null 并在
   uncertainty 说明"证据未核验"；绝不凭文件名或领域标签补造数据。
