# 限制与边界（limits）

本 Skill 的能力边界，按诚实原则明示：

## 输入边界

1. **仅文本段落**：输入是组织方提供的 JATS 段落文本（行内公式/上下标已线性化）。
   不提供图像像素、补充附件、底层临床或实验数据——这些来源中的数值**一律不推断**。
2. **无 PDF 页码**：定位只用 `source_id + paragraph_id`。evidence 中携带 `page`
   字段会被校验器拒绝；任何"第 N 页"说法都不得出现在输出中。
3. **根元数据只属于第一篇**：`case.json` 根部的 DOI/title/authors 只补到
   sources[0]；secondary 的元数据只取自 corpus-manifest / secondary-material，
   缺失时记入 `uncertainty`，绝不从第一篇抄。
4. `secondary-publisher.xml` 仅供人工核对线性化公式，脚本不解析 XML。

## 方法边界

5. **合并/区分/冲突的判断由 Agent 完成**，工具只强制"必须有证据、有理由、
   通用术语不能默认合并"。工具不能代替领域判断：两个别名是否真指同一对象，
   需要 Agent 引用原文显式证据；判错的风险由证据绑定与台账暴露给复核者。
6. **冲突不裁决**：CONFLICT 只并列保留双方；图谱不断言哪篇论文正确。
7. **数值不合并**：不同论文的条件、样本、数值结果分边保存；本 Skill 不提供
   跨篇聚合统计（平均、区间合并等），因为样品与条件不同，合并即错误。
8. **关系抽取限于有证据的关系**：共现、综述转述、推测不建边；无证据的候选在
   校验阶段即被拒绝。

## 规模与工程边界

9. 面向"一个主题、少量论文"的增量工作流；未做大规模实体消歧（如跨库学者
   消歧）、未接入外部本体。词表（节点类型/通用术语）可在
   `references/change-semantics.md` 扩充。
10. 查询算子是精确/子串匹配级别的图查询，不是全文检索或推理引擎；
    查询无结果时如实返回空，不编造。
11. `output_contract` 的非图谱类键（如要求翻译、幻灯片等本 Skill 范围外的产物）
    在 `result.json` 中填 `null` 并在 `uncertainty` 说明，不伪造内容。

## 失败处理约定

- 材料缺失/无法解析 → `status: partial` 或 `failed`，`status_reason` 说明缺口，
  人工接管点 = 编写/修正对应 JSON 后重跑相应脚本；
- 校验 ERROR → 不落盘，修正候选/变更集后重跑；
- 运行中断 → 已落盘的 partial `result.json` 与已封存基线仍然有效，
  从中断步骤继续即可（每一步都是幂等的）。
