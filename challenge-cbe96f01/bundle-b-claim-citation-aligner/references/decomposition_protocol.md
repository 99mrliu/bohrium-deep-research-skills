# 子主张分解协议（decomposition_protocol）

目标：把含引文的句子拆成**原子子主张**，使每格矩阵判定都只对一件事负责。

## 规则

1. **原子性**：一个子主张只含一个可独立真假的断言。含并列（"A 和 B"）、因果（"A 导致 B"）、比较（"A 优于 B"）的句子按断言数拆分。
2. **不丢不漏**：一个句子的全部子主张合起来覆盖句子的全部实质性内容；语气词、过渡语不算子主张。
3. **保留范围词**：子主张必须保留原句的范围限定（人群、条件、程度、数量），不得为了方便判定而丢掉限定词——范围词正是 over-claim 检查的对象。
4. **可判定性**：每个子主张必须能与一个具体引文比对范围。纯修辞、作者立场声明（"我们认为……"）不建矩阵行，但记入论证链审查。
5. **标识**：`sub_claim_id = <sentence_id>.c<n>`；`quote` 取宿主句中承载该子主张的**最短逐字片段**（通常是动词短语或名词短语），不得整句复制。
6. **多引文**：句子挂 `[2,5]` 时，每个子主张 × 每个引文各占一行；判定互相独立。

## 示例（合成）

原句："Optogenetic silencing of ripples proves that sleep consolidates memory in humans [3]."

分解：

- `c1`：光遗传抑制涟漪会破坏记忆（实验事实层）→ 与 [3] 比对。
- `c2`：该效应在人类中成立（人群维度）→ 若 [3] 是啮齿动物研究，`population=narrower_in_source`，verdict ≤ partially_supported。
- `c3`：因果关系强度为"证明"（causal_strength 维度）→ 若 [3] 是相关性或干预-行为关联，判 `narrower_in_source`。

c2/c3 的判定合起来构成典型的 over-claim finding。
