# 非机械统计审查清单（Agent 判断部分）

重算引擎覆盖不了的统计报告问题，按本清单逐项检查；每条结论在 basis 写明"非机械判定 + 推理过程"。

## 检验适配性

- 检验名称是否与数据类型匹配（连续/分类、独立/配对、分布假设）？
- 样本量依据：是否有功效分析或先例引用？小样本（n<10/组）用大样本渐近检验要提示。
- 多重比较：多处 p 值是否声明校正（Bonferroni/FDR）？未校正且依赖边缘 p 值的结论降级处理。

## 报告完整性

- p 值是否精确给出（而非只写 p<0.05）？检验统计量、自由度、效应量与置信区间是否齐备？
- mean±SD 还是 mean±SEM 是否写明？SEM 冒充 SD 会夸大精度——发现未注明时出 finding（证据不足，minor）。
- 摘要中的数字是否都能在正文/表格中找到出处？找不到出处的数字出 finding（证据不足）。

## 表述规范

- "trend toward significance"、"nearly significant"（p∈[0.05,0.10]）是弱证据的强化表述 → 建议性意见或 minor。
- 百分比基数：相对变化与绝对变化混用（"risk reduced 50%"实为 2%→1%）→ 建议补充绝对数；误导性强的升 major。
- 图注与正文的统计表述一致性（n、检验、显著性标记 * 的定义）。

## 严重度映射

| 情形 | severity |
|-|-|
| 核心结论的检验方法错误或显著性表述与数据矛盾 | major~critical |
| 效应量/CI/检验细节缺失导致结论不可复核 | minor~major |
| 表述欠规范但不改变结论 | minor / advisory |
