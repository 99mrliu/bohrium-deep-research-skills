Mini-Review: Sleep and Memory Consolidation (Synthetic Sample)

Sleep supports memory consolidation. Early work showed that hippocampal
replay during slow-wave sleep stabilizes declarative memory traces [1].
A large polysomnography cohort reported that total sleep time predicts
next-day recall accuracy [2]. Optogenetic disruption of sharp-wave
ripples impairs spatial memory in rodents [3]. Recent computational
models propose that synaptic homeostasis during sleep explains these
effects [4]. Finally, a disputed meta-analysis once claimed sleep
deprivation has no effect on memory [5]. A widely cited neurogenesis study
is still used to argue adult learning changes brain structure [6].
