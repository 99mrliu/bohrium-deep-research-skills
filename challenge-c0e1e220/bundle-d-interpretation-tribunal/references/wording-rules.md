# 结果解释句式模板与禁用语表（wording-rules）

本表是 `wording_lint.py` 的规则说明，也是人工微调报告措辞时的对照标准。
书面中文（本研究/该分析；不用第一、二人称），全角标点，数字半角。

## 1. 显著性句式（机器可检，P_WORDING）

凡句中出现 p 值（`p=`、`p<`、`p 值`、`p-value`），必须采用：

- 显著：`在 α={alpha} 水平下，{A}与{B}的 {结果变量} 差异具有统计学意义（{方法}，p={p}）。`
- 不显著：`在 α={alpha} 水平下，{A}与{B}的 {结果变量} 差异不具有统计学意义（{方法}，p={p}）；证据不足以支持「……存在差异」的结论。`
- 多重比较：`在 α={alpha} 水平下，经 Holm 校正，{A}与{B}的 差异（不）具有统计学意义（{方法}，调整后 p={p}）。`

检出「p=0.0x，证明/说明/表明有效」类组合直接判违例（P_WORDING）。
动词分级：不显著 → 「证据不足以支持」；中等效应 → 「提示」；大效应 → 「表明」。禁用「证明」。

## 2. 实际意义句（机器可检，MISSING_PRACTICAL）

含「具有统计学意义」结论的段落，必须另有独立一句实际意义句，且满足其一：
含效应量数值（`效应量 Hedges g = …`、`ω² = …`、`中位数差（Hodges-Lehmann）为 …`），
或含最小实际重要差异讨论（`最小实际重要差异 Δ`、`实际重要差异阈值`）。模板：

- 小/可忽略效应：`效应量 Hedges g = {g}，95% 置信区间为 [{lo}, {hi}]，按常用阈值属于小效应；统计显著并不等同于实际重要，该差异的实际意义有限，是否达到最小实际重要差异 Δ 需结合领域标准判断。`
- 中等效应：`…属于中等效应，提示该差异可能具有实际意义；是否达到实际重要需结合领域阈值 Δ 判断。`
- 大效应：`…属于大效应，表明该差异可能具有实际意义；其实际重要性仍需结合领域阈值判断。`
- 阴性结果：`不宜将「不具有统计学意义」解读为「不存在差异」；实际意义判断需结合效应量置信区间与领域阈值。`

效应量量级阈值：|g|/|d| 0.2/0.5/0.8；η²/ω²/ε² 0.01/0.06/0.14（小/中/大）。

## 3. 置信区间含义句（必备，防 CI_MISREAD）

`置信区间刻画的是估计量的不确定性，并非个体取值的范围。`

## 4. 禁用语表（BANNED_PHRASE，出现即违例）

| 禁用语 | 出处理由 |
|---|---|
| 证明 / 证实（了） | 统计检验只给出证据强度，不能逻辑证明；p=0.04 同样是概率性证据 |
| 完全无效 / 毫无作用 / 毫无效果 | 阴性结果只说明证据不足，不能断言效应为零 |
| 显著所以重要 / 统计上显著因此 | 把统计显著直接等同实际意义；大样本下微小差异也会显著 |
| 差异不存在 | 阴性结果的正确表述是「证据不足以支持存在差异」 |
| 导致 / 引起 | 观察性比较的组间差异不能推断因果，须用「相关/差异」表述 |

「p=0.0x，说明有效 / 表明有效」组合按 P_WORDING 判违例（p 值不能为
「有效性」背书，须先落在 α 水平句式内再谈效应量）。

## 5. 扫描范围

markdown 表格行（`|` 开头）与代码围栏内的原始统计量清单不属于解释性表述，
不参与措辞判定；散文句逐句判定。p 的展示精度为 4 位小数（`<0.0001` 记法），
该约定同时是 `claim_bind.py` 数值核对的容差来源。
