# 图形选择规则（figure-render-forge 规则引擎）

figure_forge.py 按**数据形态**选图，每条选择都写入 figures.md 的 `rationale` 字段，可机器审计。

## 规则表（按优先级）

| # | 数据形态 / 条件 | 图形 | 强制细节 |
|---|---|---|---|
| 1 | 分组数值比较（two_group / k_group） | **箱线图 + 抖动散点叠加** | 箱 = Tukey 五数；须 = 1.5×IQR **相邻值**（非栅栏端点）；每组 **n<10 强制叠加全部原始点**；10≤n≤50 全点；n>50 确定性子样本 50 点（seed 固定） |
| 2 | 分布形态（主检验为非参路线：Mann-Whitney / Kruskal-Wallis） | **追加 ECDF** | 阶梯点逐观测；多组不同色 + 图例含 n；避免箱线掩盖偏态/双峰 |
| 3 | 两数值变量（design=xy） | **散点 + OLS 参考线** | 标注斜率/截距/r；仅作参考线，不做因果解读 |
| 4 | 分类计数（design=count） | **频数条形图** | y 轴必须从 0 起；柱顶标频数 |

## 禁止规则（dynamite plot 陷阱）

- **任一组 n<30 时，禁止用 bar+SE/SD 柱形图展示组间比较**。小样本下均值±SE 柱形图掩盖分布形态、
  暗示对称与精度，是公认的误导图形。本引擎**永不自动生成**均值条形图；人工补画会被
  `figure_audit.py` 以 `RULE_VIOLATION_BAR` 拦截（exit 1）。
- n≥30 的均值条形图也不单独使用：必须搭配箱线/散点等分布背景（本引擎默认只出箱线叠加图）。

## 反例（会被审计或评审否决）

| 反例 | 问题 |
|---|---|
| 三组 n=8/9/10 画均值±SE 柱形图 | dynamite plot；应改箱线+全点叠加 |
| 右偏/双峰分布只给箱线图 | 箱线掩盖形态；非参路线必须追加 ECDF |
| 条形图 y 轴截断（不从 0 起） | 夸大差异 |
| 饼图做组间比较 | 面积/角度判断差 |
| 双 y 轴 | 制造虚假相关 |
| 3D/渐变填充 | 无信息增量 |
| 图注不含每组 n 或单位 | 不可解读、不可审计（`CAPTION_NUMBER_MISMATCH` 会拦） |

## 与检验路线的绑定

图形选择读取 analysis_data.json 中 pipeline 的 `method` / `route_nonparametric`：
非参路线（正态性或小样本触发）自动追加 ECDF；参数路线只出箱线叠加图。
图题一律含检验方法名（如 `petal length by class - Welch ANOVA`），图注含统计量与 p。
