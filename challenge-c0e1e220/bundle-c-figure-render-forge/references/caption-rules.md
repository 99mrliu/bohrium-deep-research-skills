# 图注必备要素（caption-rules）

figure_audit.py 按本节口径**机器校验**图注；写图注时逐条对照。

## 必备要素（缺一不可）

1. **图号与类型**：`图N｜箱线图+抖动散点｜…`。
2. **变量与分组**：结局变量名、分组变量名。
3. **单位**：`（单位：ms）`；单位来自 task.md 解析，缺失时写 `单位未注明` 并计入 limitations。
4. **每组 n、均值、SD**：机读格式 `组 <标签>：n=<int>，均值=<2位小数>，SD=<2位小数>`。
   审计将这些数字与 result.json 逐组比对（n 精确相等；均值/SD 容差 0.005，即 2 位小数四舍五入容差）。
5. **检验方法与统计量**：`检验：Kruskal-Wallis H(2)=14.36，p=0.0008，α=0.05`；
   p 用 4 位小数、`<0.0001` 记法，与 result.json 一致。
6. **散点叠加说明**：`全部 n 点` / `确定性子样本 50/n 点（seed 固定）`；n<10 标注 `强制全点`。
7. **数据区间**：`数据区间 [min, max]`（2 位小数）。
8. **选择理由**：写入 figures.md 的 `rationale` 字段（规则编号 + 每组 n）。

## 标准图注模板（单行，机读友好）

```
图1｜箱线图+抖动散点｜rt 按 group 分组比较（单位：ms）｜组 control：n=8，均值=9.84，SD=0.85；组 treatA：n=9，均值=11.77，SD=1.21；组 treatB：n=10，均值=13.06，SD=1.37｜检验：Kruskal-Wallis H(2)=14.36，p=0.0008，α=0.05｜散点：control 全部 8 点（n<10 强制全点）；…｜数据区间 [8.87, 14.78]
```

## 撰写纪律

- 组标签不得含 `：`、`|`、`；`（会被 figure_forge 清洗为 `-`，审计按清洗后标签匹配）。
- 图内文字用 ASCII（PNG 通道 DejaVu 字体无 CJK 字形）；中文放图注。
- 图题含检验方法；轴标签含变量名与单位。
- 禁止写「证明」「证实了」；显著性陈述写作 `p=…, α=…`。
- 篡改任何图注数字（哪怕是四舍五入位）都会被 `CAPTION_NUMBER_MISMATCH` 拦截。
