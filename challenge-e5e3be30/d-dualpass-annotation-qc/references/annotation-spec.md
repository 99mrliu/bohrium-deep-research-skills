# 标注规范：文献论断核验（v1.0）

本规范定义四级判定的操作标准、证据定位格式与边界情形处理。双通道标注（Pass A / Pass B）必须**各自独立**遵守本规范；任何一通道不得参照另一通道的产出。

## 1. 四级判定的操作定义

| 判定 | 操作定义 | 必要条件 |
|---|---|---|
| supported | 原文**明确陈述**与论断一致的内容，且数值、条件、对象全部吻合 | 能找到逐字或近逐字对应的原文句；论断的每个关键槽位（数值/样本量/条件/对象）均被原文覆盖 |
| partially_supported | 原文支持论断的一部分，但存在：部分槽位无依据、范围被论断扩大（如"所有"而原文只测了部分条件）、或原文仅有相关性陈述而论断断言因果 | 至少一个关键槽位有原文依据，且无任何槽位与原文直接冲突 |
| contradicted | 原文**明确陈述**与论断冲突的内容（数值方向相反、结论互斥） | 能找到逐字对应的原文句，且冲突是直接的，不是"未报告" |
| insufficient_evidence | 原文未报告论断所依赖的关键信息，或仅有主题相关但无法判定的内容 | 尽到检索义务（关键词 + 摘要/结论/图表说明）后仍无对应证据 |

**三条铁律**：
1. 主题相关 ≠ 支持：原文与论断同属一个主题，不等于支持该论断的具体断言；
2. 未报告 ≠ 反驳：查不到证据只能判 insufficient_evidence，不得判 contradicted；
3. 冲突并列：原文内部或通道之间存在冲突时，双方原话并列呈现，不悄悄选边。

## 2. 证据定位格式

每条标注记录必须包含：

```json
{
  "claim_id": "C1",
  "verdict": "supported",
  "evidence_pages": [3],
  "evidence_quote": "原文逐字引句，≤80 词，不得改写",
  "rationale": "判定理由，≤50 字，指出覆盖了哪些槽位"
}
```

- `evidence_pages`：1 起始的 PDF 物理页码整数数组，按升序、去重；多页证据全部列出；insufficient_evidence 通常为空数组 `[]`（若检索过相关页可列出所查页面）；
- `evidence_quote`：必须是原文逐字片段，禁止 paraphrase；引句须足以让复核人不翻原文即可理解判定依据；
- 页码分歧是可接受的（同一证据可能被引到不同页），但会被定位一致率度量捕捉。

## 3. 检索义务（判定前的最低动作）

判 insufficient_evidence 之前必须完成：
1. 论断关键实体/数值的全文关键词检索（含同义词/缩写/单位变体）；
2. 摘要、结论、图表标题与注释的通读确认；
3. 若论文有支撑信息（SI）且在输入内，同样检索。

## 4. 边界情形示例

| 情形 | 正确判定 | 说明 |
|---|---|---|
| 原文"提升约 30%"，论断"提升 30%" | supported | 约数与精确数吻合可接受，rationale 注明"约" |
| 原文"提升约 30%"，论断"提升 45%" | contradicted | 数值直接冲突 |
| 原文在 5 A/g 测得 265 mAh/g，论断"在所有倍率下 ≥250 mAh/g" | partially_supported | 范围扩大，未测倍率无依据 |
| 原文"性能提升可能与氮掺杂有关"，论断"性能提升归因于氮掺杂" | partially_supported 或 insufficient_evidence | 相关性→因果的断言升级；两通道易在此分歧，属正常现象，由仲裁收敛 |
| 原文只测 25 °C，论断"55 °C 下稳定" | insufficient_evidence | 未报告 ≠ 反驳 |
| 原文 Table 2 与正文数值不一致 | 按所引槽位判定，uncertainty 注明内部冲突，双方原话并列 | 不得只取有利一方 |
| 论断本身含多个子断言 | 全部子断言被支持 → supported；部分被支持且无冲突 → partially_supported；任一子断言被直接反驳 → contradicted | rationale 须逐子断言说明 |

## 5. 通道纪律

- Pass A：按 claims 原序（C1→CN），从关键词命中页起步；
- Pass B：按逆序（CN→C1），从摘要/结论反向追溯，复用同一原文页码索引但**不读 Pass A 输出**；
- 两通道使用同一版本的本规范与同一原文索引，差异只允许来自判定行为本身；
- 标注中遇到规范未覆盖的情形：按最接近的操作定义执行，并在 rationale 注明"规范外情形"。
