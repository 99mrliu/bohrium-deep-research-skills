# SYNTHETIC quantitative entailment task

All text, observations, targets and results in this example are **SYNTHETIC**. They do not describe real participants, experiments, papers or findings.

Read `paper.md` and answer each question in `claims-to-verify.json`. The claims are questions, not facts to be assumed. Distinguish the displayed report values from values derived from raw counts. Use the supplied source-linked observations to reproduce percentage-point and relative changes, the two-sided two-proportion z test and Wilson 95% intervals, and the unit conversion. Numeric evidence is not an automatic verdict.

The final result must use the dynamic `output_contract` in `case.json`, preserve all claims, include `case_id`, `status`, `sources`, `uncertainty` and `change_records`, and use only the four permitted verdicts.
