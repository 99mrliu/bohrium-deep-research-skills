# 归一化规范（normalization spec）

`quote_audit.py` 在匹配前对 quote 与页面文本施加同一套确定性归一化，
`num_drift.py` 对数值施加等价归一。目标：消除排版噪声，同时**不改变语义**，
使"真实存在于原文的 quote"必然通过、编造的 quote 必然失败。

## 1. 文本归一化步骤（严格按序执行）

| 步骤 | 操作 | 示例 |
|---|---|---|
| 1 | Unicode NFKC | 全角括号 `（`→`(`，全角逗号 `，`→`,`，全角数字→半角 |
| 2 | 弯引号→直引号 | `“”„‟〝〞«»`→`"`；`‘’‚‛‹›`→`'` |
| 3 | 跨行连字符拼接 | `exam-\nple`→`example`（仅 `字母-换行-小写字母` 场景，含连字符 U+2010/U+2011） |
| 4 | CJK 相邻空白删除 | 中文排版的换行不产生词间空格：`达到78%,\n较商业`→`达到78%,较商业`；凡空白的一侧为 CJK（U+2E80–U+9FFF、U+F900–U+FAFF、U+3000–U+303F）即删除 |
| 5 | 其余空白折叠 | 连续空格/制表/换行/不间断空格 → 单个 ASCII 空格，首尾去空白 |

性质：幂等、对 quote 与页面文本对称。若归一化改变了原始 quote 字节，
证据条目标注 `normalized: true`，交付时仍应引用**原文原始形式**的 quote
（归一化只用于机检，不用于展示）。

## 2. 匹配算法

1. 子串匹配：归一化 quote 是否为任一归一化页面文本的子串。
2. 子串失败 → 页内模糊匹配：`difflib.SequenceMatcher(autojunk=False)`，
   以匹配块位置为锚点取候选窗口，窗口长度取 `len(quote)+{0,12,24,40}`
   四档，报告最大 ratio 与所在页。
3. 判定阈值：ratio ≥ 0.95 → verbatim_ok；0.80–0.95 → near_match；
   < 0.80 → not_found。

## 3. 数值等价归一（num_drift.py）

| 写法 | 归一值 | 说明 |
|---|---|---|
| `30%` / `30 percent` / `30 per cent` / `30 个百分点` | 0.30 | 百分数统一折算为小数比值 |
| `30‰` | 0.030 | 千分数 |
| `百分之三十` / `百分之三点五` | 0.30 / 0.035 | 中文数字：支持十/百/千/万与"点"小数 |
| `3e5` / `3E+05` | 300000 | 科学计数法 |
| 普通整数、小数 | 原值 | 浮点比较，相对容差 1e-9 |

等价判定：两数归一值相对差 ≤ 1e-9 视为相等（`30% ≡ 0.3 ≡ 百分之三十`）。

### 数值抽取的排除规则（防止误报）

- 标识符中的数字不抽取：`CO2`、`SO2`（字母后紧跟）与 `NFO-700`、
  `EXMP-2024-001`（连字符标识符的尾部段）不参与比对。
- 仅抽取论断文本中的数值与 evidence quote 中的数值做比对；
  quote 中多出的数值不视为问题（证据可比论断更详细）。

## 4. 已知边界（诚实声明）

- NFKC 会把 `℃`（U+2103）归一为 `°C`，`μ` 兼容形式亦被归一；这对中英文
  混排论文是特性而非缺陷，但意味着机检不能区分这两种原始字形。
- CJK 空白删除规则会使"中文词 + 空格 + 中文词"与无空格形式等价；
  对日文人名间空格等少数场景可能过度合并，属可接受的保守方向
  （只会让真实 quote 更易通过，不会放过编造 quote）。
- 模糊匹配 ratio 是相似度指标，不是语义判断；near_match 一律转人工。
