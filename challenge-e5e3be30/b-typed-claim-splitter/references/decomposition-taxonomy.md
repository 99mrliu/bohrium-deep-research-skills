# 论断拆解类型学（Decomposition Taxonomy）

本文件定义类型化原子拆解的四种子判断类型与拆解规则。配套词表见
`references/cue-lexicon.json`，机检工具见 `scripts/cue_scan.py` 与
`scripts/coverage_matrix.py`。

## 为什么先拆解

复合论断核验出错的一半原因在"拆错了"：

- 复合句被当成单判断 → 部分正确被误判为整体正确；
- 比较方向丢失（"A 高于 B"拆成"A 高"）→ 核验对象消失；
- 否定词被吞（"无显著差异"拆成"显著差异"）→ 极性反转；
- 条件/范围限定被丢（"在 600°C 下"被略去）→ 支持条件改变；
- 子判断互相重叠 → 重复核验甚至循环论证（用论断的一部分证明另一部分）。

拆解的目标产出是**原子子判断清单**：每个子判断只含一个可判定的谓词，
且全体子判断合起来不遗漏、不重复地覆盖原论断的全部语义负载。

## 六种语义槽位

| 槽位 | 含义 | 典型线索（中/英） | 处置 |
|---|---|---|---|
| comparator | 比较与方向 | 高于/降低/30%；than, reduce | 决定子判断类型为 comparison，方向必须保留 |
| negation | 否定极性 | 无显著/并非；no, not | 作为修饰附着于所在子判断，核验时不得吞掉 |
| significance | 统计显著性限定 | 显著/p<0.05；significant | 修饰槽位；注意"未报告 p 值"≠"不显著" |
| condition | 前提条件 | 在…下/当/若；under, when | 保留在所属子判断内，支持判定须在同等条件下 |
| causal | 因果断言 | 因为/导致/归因于；because, due to | 单独拆为 causal 子判断，需机制性证据 |
| scope | 范围/量词限定 | 所有/仅/适用于；all, only, applies to | 单独拆为 scope 子判断；"所有"与"部分"之差即支持与反驳之差 |

## 四种原子子判断类型

### 1. fact（事实型）
- 定义：对单一事实的陈述，无比较、无因果、无普适量词。
- 例："HX-300 的密度为 2.71 g/cm³。"
- 所需证据：原文中对该事实的直接陈述。
- 判定要点：数值、单位、定义是否一致。

### 2. comparison（比较型）
- 定义：两个对象/条件之间的方向或量级比较（含"提高了 X%"这类
  跨条件比较）。
- 例："600°C 退火下抗拉强度比 500°C 退火提高约 30%。"
- 所需证据：两侧各自的数值/方向与样本信息。
- 判定要点：①比较方向必须保留在子判断文本中；②两个比较对象必须
  都在原文中找到对应数据；③只找到一侧数据 → insufficient_evidence，
  不得用"趋势合理"补足。

### 3. causal（因果型）
- 定义：断言机制或归因关系。
- 例："强度提升是因为晶粒细化与弥散相析出。"
- 所需证据：机制性证据（显微组织、对照实验、统计中介分析，或作者
  明确的因果表述）。
- 判定要点：相关≠因果；作者仅说"伴随"而论断说"导致"→ 至多是
  partially_supported；要区分"作者主张的因果"与"论断主张的因果"是否
  同一机制。

### 4. scope（范围型）
- 定义：关于适用对象/条件的普适性或排他性断言。
- 例："适用于所有铝合金。"
- 所需证据：原文关于适用范围/条件限定的明确表述。
- 判定要点：原文说"在 6xxx 系上验证"而论据说"所有铝合金"→
  contradicted（范围被直接收窄）；原文未讨论适用范围 →
  insufficient_evidence（未报告≠反驳）。

## 拆解规则

- D1 一条子判断只含一个可判定谓词；并列谓词（"提高且降低"）必须拆开。
- D2 拆分点优先级：强分隔符（并且/同时/分号）恒拆；弱分隔符
  （且/而/and/while/whereas/逗号）仅当两侧各有谓词时拆；因果与范围
  从句标记（因为/由于/适用于/because/due to/applies to）前恒拆，
  标记词留在右侧子句。
- D3 否定、显著性、条件槽位不单独成子判断，作为修饰附着于所在子判断，
  并写入其 modifiers 字段。
- D4 每个槽位必须被恰好一个子判断认领（coverage_matrix.py 机检：
  omission → exit 1 必须返工；overlap → 警告）。
- D5 类型判定优先级：causal > scope > comparison（含 comparator 槽位）
  > scope（仅 condition 槽位）> fact。
- D6 拆解不得改变原文语义：拆分后拼接各子判断应能还原原论断的全部
  断言；若发现拆解与原文冲突（如把转折误拆成并列），以原文为准重做。
- D7 单谓词论断直通：无线索词、无拆分点的论断按单一 fact 处理，
  不强行拆分。
- D8 启发式工具的输出是"建议拆解"：cue_scan.py 给出的拆分点、类型与
  槽位归属须经核验者复核；工具负责"不漏"，人负责"不错"。

## 常见拆解错误对照

| 错误 | 后果 | 防线 |
|---|---|---|
| 复合句当单判断 | partially 被误判 supported | D1 + 覆盖矩阵 |
| 比较方向丢失 | 核验对象消失 | comparator 槽位强制入子判断文本 |
| 否定词被吞 | 极性反转 | negation 槽位 + modifiers 字段 + 警告 |
| 条件范围丢失 | 支持条件改变 | condition/scope 槽位 omission 机检 |
| 子判断重叠 | 重复核验/循环论证 | overlap 机检（同槽位集+同谓词主干） |
