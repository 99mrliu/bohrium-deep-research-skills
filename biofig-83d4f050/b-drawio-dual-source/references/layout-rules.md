# 布局规则（geometry.py 的确定性布局）

## 区室顺序与泳道带

自上而下单向堆叠，y 范围固定（geometry.py: BANDS）：

| band | y 范围 | 说明 |
|---|---|---|
| extracellular | 40–170 | 细胞外 |
| membrane | 170–250 | 膜带（窄条，80px） |
| cytosol | 250–520 | 细胞质（主舞台） |
| nucleus | 520–700 | 细胞核 |

只有模型里声明的区室才被绘制；分泌到细胞外的配体放 extracellular，核内
转录因子/基因放 nucleus。画布 1200×700，下方追加 150px 图例条（总高 850）。

## 跨膜受体

`type=receptor` 的实体忽略本区室纵向堆叠，垂直中心钉在 membrane 带的中心线
（70×150 高矩形自然伸入相邻带），水平位置仍按列规则。配体-受体边从
extracellular 向下、受体-胞内信号边向 cytosol 向下，方向关系一目了然。

## 流向与列

- 信号流主方向：**左 → 右**。列号 = 边图上的最长路径分层（源点为 0），可用
  实体的 `"col"` 显式覆盖；同列内按 `"row"` 或 id 排序垂直堆叠，行距自适应
  带高（≥70px，≤110px），不重叠。
- 水平步长 `step_x = max(210, (W-2*MARGIN-150)/(maxcol+1))`，保证 150px 宽
  节点间至少 60px 间隙。

## 边路由（正交折线）

- 目标区室在源**下方**：源底出 → 中位水平线 → 目标顶入。
- 目标区室在源**上方**（反馈）：源底出 → 下到反馈通道
  `fb_y = min(画布底-20, max(源底,目标底)+55)` → 水平 → 目标底入；在 geometry
  中标记 `"route": "feedback"`。反馈永远走低处环路，不横穿主信号层。
- 同区室：右侧出/左侧入（目标在左时镜像），中位垂直线连接。
- **分支扇出**：同一源点的多条边出口沿边偏移 `(i-(n-1)/2)*16px`，避免共线重叠。
- 边标签放在中段中点上方 8px。

## 重叠避免

布局器依赖固定带高 + 列步长 + 行堆叠三个不变量；若同区室同列实体过多导致
行距被压到下限，会在 y 上钳制在带内（可能拥挤但不越界）——此时应增加区室
或拆分图面，并在 exceptions 中说明。
