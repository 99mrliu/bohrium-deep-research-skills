# SYNTHETIC EXAMPLE — 合成任务说明（非平台正式任务）

把 `materials/synthetic_paper.txt`（合成论文 CapFlow-3）组织成一场
**12 分钟、10 页**的系内评审汇报，听众为评审委员会（熟悉微流控背景，
但不了解本项目）。

要求：

1. 提取研究问题、方法、结果与限制，形成主线；
2. 每页恰好一个主张，图表引用与页内结论对应；
3. 生成可编辑演示文件与逐页讲稿备注，保留每页到材料的定位；
4. 完成问答预演：预判机制、数据、对照、局限四类追问，准备口径一致的
   回答要点与备用页，题库须通过 `scripts/qa_gate.py` 的 G1–G5 门控。

本文件为合成示例输入，不构成正式测试案例。
