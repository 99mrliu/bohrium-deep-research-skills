# SYNTHETIC EXAMPLE / 合成示例 —— task.md（演示用，非正式案例）

把 `materials/synthetic_paper.txt`（合成短文）组织成一份 4 页、8 分钟、
面向组会听众的学术汇报：

1. 提取研究问题、方法、结果与限制，形成主线；
2. 每页恰好一个主张，标注证据定位（file / page / section / exhibit）；
3. 生成可编辑 pptx（含讲稿备注），并导出 PDF；
4. 对导出 PDF 执行渲染取证（R1–R5），交付 render_report.json。

本 task.md 仅用于 bundle 自检演示，内容是编造的。
