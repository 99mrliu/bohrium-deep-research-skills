# Minimal runnable example (SYNTHETIC — illustrative, not an official case)

From the skill root:

```bash
python examples/make_synthetic_case.py
```

It fabricates a toy case (a semilogx dose–response figure, one table,
a two-field contract) under `./synthetic_run_c/` and executes the real
runbook twice:

**Run 1 — disciplined run.** `start_run.py` writes the skeleton
result.json; gate artifacts are produced (inventory, axis card, element
ledger, crosscheck); gates 1–5 pass; the agent fills the contract fields;
`finalize.py` decides `success` and emits `run_report.md`.

**Run 2 — broken run.** The same case, but the axis card declares the
log dose axis `linear`. `gate.py --gate 2` exits 2 with an
`axis_type_gate` finding; the agent claims success anyway at finalize
time, and `finalize.py` overrides it to `partial` naming the failing
gate:

```
run 2 decided: partial - failing gates: g2; null contract fields: answer, extracted_values
```

The two `run_report.md` files (under `synthetic_run_c/output/` and
`output_bad/`) show exactly what a reviewer sees: per-gate findings,
timeline, and the reason for the shipped status. All content is synthetic
and generated by the example itself.
