# Minimal end-to-end example — 合成示例 / synthetic 示意输出

Everything below is **synthetic** (all data generated by
`make_synthetic_case.py`; no real measurements). Excerpts are real output from
one run; pixel values may shift slightly across matplotlib versions.

## 0. Generate the synthetic case

```bash
python3 examples/make_synthetic_case.py --out /tmp/f35e-e-demo
# prints the output dir; contains:
#   figure.png  figure_card.json  case.json  task.md  measurements.csv
```

The figure combines traps in two stacked panels: **Panel A** is a line plot with
a LOG-y axis (1e-3..1e1) whose y unit is `mV` — but the card deliberately
declares the axis `linear`, and the companion CSV uses `V`. **Panel B** is a
grouped bar chart whose y-axis starts at **40** (truncated origin), with error
bars, a lone `*` above one bar, and a `**` + significance bracket above the two
Treatment bars. Tick pixel positions in `figure_card.json` are measured from the
rendered figure via matplotlib transforms, so the card is accurate.

## 1. Axis geometry screen

```bash
python3 scripts/detect_axis_geometry.py \
  --card /tmp/f35e-e-demo/figure_card.json --work /tmp/f35e-e-demo
# exit code: 2  (>=1 live mode)
```

Excerpt from `axis_diagnosis.json` — the log axis is caught **despite being
declared "linear"**, the truncated origin is quantified, and the mV/V unit risk
is flagged against `table_units: ["V"]`:

```json
{"id": "top_y", "declared_type": "linear",
 "fit": {"linear": {"relative_residual": 0.2299},
         "log":    {"a": -73.72, "b": 181.72, "relative_residual": 0.0000},
         "verdict": "log", "confidence": 0.99}}
```

```
LOG_AXIS_AS_LINEAR -> declared 'linear' but tick geometry fits log10
  (rel. residual 0.0000 vs linear 0.2299); read values as 10**((pixel-b)/a)
TRUNCATED_ORIGIN   -> bar chart value axis starts at 40 (>0); visible fraction
  0.652, zero-baseline exaggeration ratio 1.53
UNIT_PREFIX        -> axis unit 'mV' vs table unit 'V' share base 'V' but
  differ by factor 0.001 — prefix mix-up risk
```

## 3. Repair plan

```bash
python3 scripts/repair_plan.py \
  --axis-diag /tmp/f35e-e-demo/axis_diagnosis.json \
  --nondata   /tmp/f35e-e-demo/nondata_elements.json \
  --card      /tmp/f35e-e-demo/figure_card.json \
  --work /tmp/f35e-e-demo --out /tmp/f35e-e-demo/repair_plan.json
# exit code: 2  (repairs issued)
```

`repair_plan.json` merges all five live modes with per-mode repairs and a
post-read self-check list; `misread_report.json` (skeleton, 5 entries,
`applied: null`) is written alongside for the agent to complete:

```
repair_plan.json — 5 live mode(s):
  LOG_AXIS_AS_LINEAR  re-read via 10**((pixel-b)/a); think in decades
  UNIT_PREFIX         mV -> V, x1e-3, state the conversion in sources
  TRUNCATED_ORIGIN    report absolute values AND the 1.53x distortion;
                      never quote bar-height ratios as value ratios
  NONDATA_BRACKET     exclude; record which two groups it compares
  NONDATA_STAR        exclude; record as significance annotation
post_read_self_check: 5 questions, one per mode
```

## What the agent does next (not scripted)

Read the figure **under** the repairs (e.g. Panel A value at x=5 via the log
law, then ×1e-3 to volts; Panel B ratio 102/55 ≈ 1.85 as *values*, noting the
height-ratio exaggeration from the truncated axis), fill every
`misread_report.json` entry with evidence, resolve every `agent_confirm` item on
the zoomed image, and fold conversions/exclusions into `result.json`'s
`sources`/`uncertainty` with an honest `status`.
