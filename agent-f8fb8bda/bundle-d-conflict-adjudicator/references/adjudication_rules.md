# 冲突裁定框架（Conflict Adjudication Rules）

本文档定义 `conflict_adjudicate.py` 的 C1–C2 门控背后的裁定学理。目标：相互矛盾的研究结论不得取一方、不得和稀泥，每个冲突对必须留下机器可查的裁定依据。

## 1. 冲突的定义与检出

冲突对（conflict pair）：同一 `outcome_domain` 内，一项研究 `direction=positive`，另一项 `direction=negative`。`null` 与 `mixed` 不自动构成冲突，但应在 `consistency_note` 中作为背景证据提及。

检出是机械过程（C1），裁定是论证过程（C2）。机器负责"不得遗漏"，人/Agent 负责"给出依据"。

## 2. 裁定的四个维度

每个 adjudication 必须沿以下维度展开（前三维至少两项落成非空文字）：

1. **design_comparison（设计层级比较）**
   证据设计层级（由高至低）：
   `meta_analysis（高质量）≥ rct > cohort > case_control > cross_sectional > in_vitro / in_silico`；`review` 与 `other` 按其纳入证据的实际层级对待。
   层级差本身不直接定胜负：一个执行差的小样本 RCT 不必然压倒一个严谨的大样本队列。必须同时说明两研究的偏倚方向（混杂、选择偏倚、测量偏倚）是否足以解释方向相反的结果。

2. **n_comparison（样本量与统计功效）**
   小样本研究的 null/negative 结果可能是功效不足（II 型错误）而非真阴性；大样本观察性研究的显著效应可能是残余混杂。比较时应写明各方 n 及其对结论可信度的含义。

3. **consistency_note（一致性与异质性）**
   冲突双方与域内其余证据的关系：是否有第三、第四项研究支持某一方？异质性是否有结构性来源（见第 3 节）？

4. **verdict（裁定结论）**，四选一：
   - `favor_a` / `favor_b`：一方在层级、功效、偏倚控制上**显著**占优，且不存在可用适用条件差异解释的异质性。允许 favor 的最低条件：占优方层级更高 **且** 样本量不劣 **且** 劣势方存在已识别的具体偏倚来源。三者缺一即不得 favor。
   - `coexist_by_context`：两个相反结论在各自适用条件下可同时为真（见第 3 节）。
   - `undecidable`：现有信息无法区分真伪，必须并置双方。

## 3. 适用条件差异：何时"共存为真"

人群、剂量/暴露强度、随访时长、结局测量方式、基线风险不同，都可使同一问题出现方向相反但都成立的答案。典型模式：

- 干预在老年社区人群有效（positive），在年轻轮班人群中观察到负相关（negative）——暴露定义与人群均不同，二者不是同一问题的两个答案，而是两个问题的各自答案。
- 短期随访有效、长期随访无效，可能反映效应衰减而非矛盾。

判 `coexist_by_context` 时，`consistency_note` 必须点名具体是哪个适用条件维度（人群/剂量/随访/测量）解释了方向差异，并在综合结论中把两条结论分别限定在各自条件下。

## 4. 何时必须并置双方（undecidable）

- 双方层级相当、功效相当，偏倚评估无法分出高下；
- 材料未提供完成比较所需的关键信息（如剂量、随访、效应量精度）；
- 域内其余证据本身分裂。

`undecidable` 的 `consistency_note` 必须包含三要素：①已比较了哪些维度；②每个维度为何分不出胜负；③什么新证据可以使冲突可裁定。少于 20 字或仅为"尚存争议"类短语即被 C2 判为违例。

## 5. 为什么"尚存争议"是失败产物

裸写"尚存争议"在四个层面上不合格：

1. **不可复核**：没有断言任何可检验的内容，读者无法判断裁定是否成立；
2. **无信息量**：它与"未做任何分析"在字面上不可区分；
3. **掩盖结构**：多数"争议"经设计层级与适用条件分解后可降级为 favor 或 coexist，裸短语放弃了这一步；
4. **阻断行动**：合格的 undecidable 会指明需要什么证据来解开冲突（即可转化为研究空白），裸短语不能。

因此 C2 将裸短语与过短说明设为硬违例（exit 1）。
