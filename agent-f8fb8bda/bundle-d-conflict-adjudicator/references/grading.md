# 证据分级（Evidence Grading A–D）与结论边界

本文档定义 `conflict_adjudicate.py` 的 C3 门控背后的分级规则，以及结论与综合文本的写法要求。

## 1. 分级定义

| 等级 | 定义 | 机械判据（C3 强制执行部分） |
|------|------|------------------------------|
| A | 多研究一致的高层级设计证据 | evidence 中 ≥2 个 `direction` 一致且 `design ∈ {rct, meta_analysis, cohort}` 的研究 |
| B | 方向一致但层级或数量有缺 | 同 A 的机械底线，但综合判断层级/总量/一致性存在缺口时可由 A 降为 B |
| C | 单一研究、低层级设计，或涉及已裁定冲突（结论被限定在某一适用条件下） | 不满足 A/B 底线；涉及**未裁定**冲突对的结论不得高于 C |
| D | 间接证据或外推（如 in_vitro 外推人体、替代终点外推临床结局） | 无机械底线，但 statement 必须写明外推链条与断点 |

机械判据是底线而非充分条件：满足 A 的机械条件仍可能因异质性、发表偏倚等降为 B/C；不满足机械条件则**必须**为 C 或 D，脚本直接判违例。

"未裁定冲突对"指：该冲突对无 adjudication 条目、verdict 非法，或 verdict=undecidable。已裁定（favor_a / favor_b / coexist_by_context）的冲突不触发封顶，但被 favor 淘汰一方的研究不应再作为支撑证据出现在 A/B 结论的 evidence 中。

## 2. 结论边界写法

每条 conclusion 的 `statement` 必须自带适用条件，至少覆盖能限定其外延的维度：

- 人群（年龄、基线状态、合并症）；
- 干预/暴露（剂量、时长、形式）；
- 随访窗口；
- 结局域（哪个 outcome_domain，何种测量）。

反例："运动改善情绪"（无边界）。正例："规律有氧运动与 18 岁以上成人抑郁症状改善相关（适用条件：可耐受运动者、干预 ≥8 周）"。

涉及 `coexist_by_context` 冲突的结论，statement 中必须显式写出其所适用的一侧条件，不得合并成无条件的全称命题。

## 3. 研究空白与无法确定的区分

二者都写入 result.json，但归属不同区块，不得混用：

- **研究空白（research gap）**：证据**缺失**。检索覆盖范围内没有研究回答该子问题。写法：指出缺失的研究设计（如"缺少 n>500、随访 ≥1 年的 RCT"），它是未来研究的任务书。
- **无法确定（undetermined）**：证据**存在**但不足以定论——冲突未裁定、仅单一低层级研究、或精度不足。写法：引用现有哪些 study_id、卡在哪个裁定维度、需要什么证据解开。

判别口诀：没有证据 → 空白；有证据但定不了 → 无法确定。综合文本中前者不出现 [事实] 句，后者通常以 [无法确定] 句呈现并回链相关 study_id。
