# 逐字引用规则（Quotation Rules）

本规则配合 `scripts/quote_verify.py` 使用。目标：证据台账中的每条
`quote` 都能在语料原文中逐字找回（经归一化：NFKC、大小写折叠、
空白压缩、连字符换行修复）。

## 1. 不得改写

- quote 必须与原文逐字符一致（归一化意义下）：不得同义替换、
  不得调整语序、不得"顺手"修正原文的语法或单位写法。
- 原文的拼写错误照抄，可在 note 中以 `[sic]` 说明。
- 数字、单位、符号必须原样（如 `41 mS/cm`、`1 mA/cm2`）；不得把
  上标改写成普通字符以外的形式。
- 需要概括时，概括写在结论字段，quote 仍然只放原文。

## 2. 省略号与节选

- 允许截取原文的连续片段；不要求整句，但片段本身必须连续出现。
- 中间省略用省略号时，**ledger 中应拆成两条证据**（省略号连接的
  文本无法通过子串匹配），或用 note 说明"两段之间省略 N 字"。
- 跨段引用同样拆条：一段一条 evidence。

## 3. 跨页引用

- 一条证据只声明一个 page。引用内容跨页时，按主要承载页拆为多条，
  或取单页内连续片段。
- 页码以 corpus_index.json 的 page_spans 为准（PDF 为 pdftotext 的
  `\f` 分页序，可能与印刷页眉页码不同）；note 中可同时记印刷页码，
  但 page 字段必须填语料页序。
- page_mismatch 是门控违例：按 verified_ledger.jsonl 中的
  found_page 修正后重跑。

## 4. 表格与图中数字

- 表格文字经 pdftotext 抽取后可逐字引用；注意 -layout 模式会保留
  对齐空格，归一化已压缩空白，按连续文字片段摘录即可。
- **图中**的数字/曲线无法逐字核验：引用时在 note 中明确标注
  `读自图 X（非文本层，未经逐字核验）`，并在 uncertainty 中登记
  其置信度；此类证据不计入 verified 回链率，结论中降权表述。
- 坐标轴读数、目测比例等二次解读，必须写成"据图 X 读得约 …"，
  不得伪装成原文陈述。

## 5. 登记纪律

- 先摘录后写作：quote 进入 ledger 且 verified 之后，才允许把对应
  结论写入 result.json。
- evidence_id 在 result.json 的各区块中回引，保证结论句 →
  evidence → doc/page/quote 三级可追溯。
- 删除结论时必须同步删除或孤立其 evidence，保持 ledger 与
  result.json 一致。
