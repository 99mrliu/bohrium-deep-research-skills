# 合成示例任务 / Synthetic Task

> 合成示例 / synthetic：本任务、材料与结论均为虚构，仅用于演示 dr-contract-forge 的五阶段流程与门控。

## 综述问题

"在虚构的冷聚变催化剂研究中，铂-镧合金（Pt-La）是否比纯铂催化剂在室温下具有更高的表观能量增益？现有证据是否存在冲突，研究空白是什么？"

## 要求

依据 examples/materials/ 下的两篇合成文献完成迷你综述，交付契约字段：review_report、evidence_matrix、limitations、search_log，并保证六要点区块齐备、状态诚实。
