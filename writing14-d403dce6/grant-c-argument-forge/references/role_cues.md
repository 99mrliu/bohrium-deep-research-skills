# 立项依据句子角色分类线索词表（argument_map.py 使用）

本文件同时供人阅读与机器解析。机器可解析块格式固定为：

```
## 角色：<角色名>
- 线索词：<词1>|<词2>|...（竖线分隔，任一命中即视为该类候选）
- 优先级：<整数，越大越优先>
- 需引文：<是|否>（"是"表示该角色属事实类句子，计入引文覆盖率统计）
```

分类规则：对每句话按优先级从高到低匹配各角色线索词，首个命中角色即为该句角色；
全部未命中记为"未分类"。一句话命中多角色时，以优先级高者为准。

## 角色：口号
- 线索词：重要意义|重大意义|国家战略|重大需求|势在必行|刻不容缓|战略性|国计民生|双碳|健康中国|科技强国|自主可控|卡脖子|两个一百年|新质生产力|高度重视
- 优先级：100
- 需引文：否

## 角色：团队凭据
- 线索词：申请人|本团队|我们已|前期工作|预实验|已发表|已建立|已搭建|积累了|主持了|获批|授权专利
- 优先级：80
- 需引文：是

## 角色：切入点
- 线索词：本研究拟|本项目拟|为此我们|切入点|拟从|拟采用|拟通过|为此提出|据此提出
- 优先级：70
- 需引文：否

## 角色：差距
- 线索词：尚未|仍未|缺乏|不足|空白点|未能解决|难以解释|仍不清楚|仍然缺乏|有待|缺口|尚无
- 优先级：60
- 需引文：是

## 角色：瓶颈
- 线索词：瓶颈|挑战|难题|制约|受限于|困难|障碍|核心问题|关键问题|局限
- 优先级：50
- 需引文：是

## 角色：已有进展
- 线索词：已提出|已报道|已实现|已开发|已成功|已有研究|最新进展|近年来.*提出|等报道了|等提出|等开发
- 优先级：40
- 需引文：是

## 角色：时机
- 线索词：随着|近年来|当前|近期|刚刚|正逢|恰逢|得益于|新发布的|新一代|的时机
- 优先级：30
- 需引文：是

## 角色：现状
- 线索词：目前|现有|现今|已广泛应用|广泛采用|主流方法|领域|研究表明|普遍认为|已成为
- 优先级：20
- 需引文：是

## 链完整性判定

必要性论证链的必要角色为：现状 → 瓶颈 → 差距 → 切入点。
- 四个角色均须至少出现一次；
- 首次出现的先后次序应满足 现状 早于 瓶颈 早于 差距 早于 切入点（论证链自然流向：
  先交代领域现状，再指出关键瓶颈，再说明已有进展之后仍存在的差距，最后给出本研究切入点）。
- 其余角色（已有进展、团队凭据、时机、口号）不作强制要求，但"口号"角色过多是危险信号，
  请参考 argument_patterns.md 的论证版写法改写。
