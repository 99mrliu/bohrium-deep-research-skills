# 引用核验规则

目标：章节稿中每条参考文献"查得到"，且查不到时如实标注，绝不补造。

## 核验层级

| 层级 | 含义 | 章节稿标注 |
|---|---|---|
| 已核验 | 引用条目能在 /input 材料中定位到原文（PDF/节选/记录），且与 evidence_map quote 一致 | 正常引用，附证据编号 |
| 未核验 | 材料中只有转述或二手提及，无法定位原文 | 条目末尾标注"（未核验）"，并列入缺口清单 |

## 要件检查（anchor_audit.py 执行，缺件仅 warning）

- 对象形式 citation：必须含 `authors`、`year`、`title` 三要件；
- 字符串形式 citation：必须含 4 位年份（19xx/20xx）、可辨识文字，且长度足以包含标题信息；
- 要件缺失 → warning，不判 error，但交付前必须人工处理。

## 红线

1. **查不到就标"未核验"**：不得凭记忆补全卷、期、页码、DOI；这些字段只有在外观核验（材料原文给出）时才允许出现。
2. **不得虚构文献**：任何在材料中完全找不到踪迹的文献不得进入申请书。
3. **外部工作归外部作者**：引用条目对应的成果在正文中必须以"外部工作"态陈述（见 status_taxonomy.md）。
4. **二手引用要标明转引来源**：若数字来自综述对他人工作的转述，quote 锚定综述原文，正文写"XX 综述转引的 YY 工作报道了…"。
5. **DOI/页码出现在材料原文中才可引用**：quote 中未出现的书目细节视为未核验信息。

## 建议的条目格式（章节稿内）

```
[n] 作者. 标题. 出处, 年份.（证据 En；已核验 / 未核验）
```
