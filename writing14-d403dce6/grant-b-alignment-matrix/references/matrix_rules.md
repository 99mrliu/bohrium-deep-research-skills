# 一致性矩阵机器回检规则 M1–M8 全文与判定示例

matrix_check.py 实现的全部规则。severity=error 使退出码为 1（不通过）；
severity=warning 不影响退出码。每条发现写入 check_report.json 的 findings，
含 rule / severity / message / detail。

## 矩阵模型

矩阵为 JSON：nodes 含 q/g/c/r/k 五类节点数组（节点对象至少含 id，可含 title），
edges 为边数组。边方向统一为「子 → 父」（即支撑方 → 被支撑方）：

| 边型 | 语义 |
| --- | --- |
| G→Q | 研究目标回应科学问题 |
| C→G | 研究内容支撑研究目标 |
| R→C | 技术路线步骤落实研究内容 |
| K→G | 考核指标锚定研究目标 |

即覆盖链 Q←G←C←R，且 K→G。「入边/出边」均以此方向论。

## M1 矩阵结构合法（error）

- 顶层为对象，含 nodes（对象，只允许 q/g/c/r/k 五个键，值为数组）与 edges（数组）。
- 每个节点含 id，id 匹配 `^[QGCRK][0-9]+$`，前缀与所在类别一致，全矩阵不重复。
- 每条边含 from/to，端点 id 形态合法，边型 ∈ {G→Q, C→G, R→C, K→G}。
- 例：边 `{"from":"R1","to":"G1"}` 判 error（R 只允许指向 C）。

## M2 覆盖链闭合（error）

- 每个 Q 至少被一条 G→Q 覆盖；每个 G 至少被一条 C→G 支撑；
  每个 C 至少被一条 R→C 覆盖；每个 K 至少有一条 K→G 出边。
- 典型失败：目标三个、路线两条——第三个内容没有任何路线步骤，
  即「研究内容 C3 没有任何技术路线步骤覆盖（缺 R->C）」。
- M2 只检查「是否存在相应边型的边」，端点是否真实登记由 M4 负责
  （例如 K1→G4 而 G4 未登记：M2 通过、M4 报错，二者分工不重叠）。

## M3 无孤儿节点（error）

- 每个 G/C/R/K 节点至少有一条指向其上层类别的出边
  （G→Q、C→G、R→C、K→G）；否则该节点未挂进对齐链，判孤儿。
- M3 与 M2 互补：M2 防止「上层无人覆盖」，M3 防止「下层无处挂靠」。
- 例：矩阵登记了 G3 但没有任何 G3→Q 边 → 「孤儿节点：G3」。

## M4 无悬空引用（error)

- 每条边的 from、to 必须都是 nodes 中已登记的 id。
- 例：边 `{"from":"K1","to":"G4"}` 而矩阵只登记 G1–G3 →
  「悬空引用：边 K1->G4 指向未登记的 ID G4」。

## M5 矩阵 ID 与正文双向一致（error）

- 正向：矩阵登记的每个 id 必须在 draft 正文中出现（正则见
  numbering_convention.md 第 3 节）。
- 反向：正文中出现的每个 Q#/G#/C#/R#/K# 编号必须已登记进矩阵对应类别。
- 例：正文写「拟视进展拓展 C4」而矩阵无 C4 →
  「正文出现的编号 C4 未登记进矩阵（研究内容类）」。

## M6 七要素标题齐备（error）

- 以 plan.json 的 elements 为准；缺省用 SPEC 默认七要素。
- 对 markdown 标题行做别名包含匹配（别名表见 numbering_convention.md 第 4 节）。
- 例：章节稿缺「创新点」标题 → 「七要素标题缺失：未找到『创新点』…对应的
  markdown 标题」。

## M7 厚度平衡（warning / error）

- 统计每个要素标题至下一标题之间的正文字符数（去空白）。
- error：标题存在但正文为空。
- warning：某要素字符数 < 全部出现要素均值 × 阈值（--threshold，默认 0.35）。
- 缺失要素（M6 已报 error）不参与均值与比较，避免重复计数。

## M8 计数表述一致（error）

- 若正文出现「科学问题/研究目标/研究内容/技术路线/考核指标 + 数量 + 个/项/条/步」
  类表述（阿拉伯或中文数字），数量必须等于矩阵对应类别节点数。
- 例：矩阵 G 节点 3 个，正文写「研究目标共 4 个」→ error。
- 不写计数句则本规则不触发；写了就必须与矩阵一致。

## 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 通过（可有 warning） |
| 1 | 存在 error 级发现（含矩阵 JSON 无法解析，按 M1 处理） |
| 2 | 参数错误或输入文件缺失/不可读 |
