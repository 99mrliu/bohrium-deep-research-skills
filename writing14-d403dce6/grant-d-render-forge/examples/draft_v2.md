# 研究内容与技术路线（合成示例修订稿 v2）

## 研究内容

本项目围绕冻融循环作用下寒区路基粗粒土的强度劣化机理与预测问题，设置三方面研究内容，分别对应研究目标一至三：

- 冻融循环下粗粒土孔隙结构演化规律的试验观测（对应目标一）；
- 孔隙结构—力学性质关联模型的建立（对应目标二）；
- 路基服役性能劣化预测方法的构建与工程算例验证（对应目标三）。

## 技术路线

按"试验观测—模型建立—方法验证"三步推进，每步产出可核验的中间成果。试验方案的关键参数如下表。

| 参数 | 取值 | 依据 |
| --- | --- | --- |
| 冻融循环次数 | 0–12 次，间隔 3 次取样 | 材料中已有试验方案 |
| 试样含水率 | 【待申请人确认：最优含水率±2% 的具体取值】 | 需申请人按既有土工试验报告确认 |
| 加载方式 | 静三轴，围压 50/100/200 kPa | 材料中已有试验方案 |
