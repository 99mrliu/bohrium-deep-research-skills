# Markdown → DOCX 样式映射表与局限

md2docx.py 支持的映射（权威版本以 Markdown 母稿为准，docx 为其渲染件）：

| Markdown | DOCX 呈现 | 说明 |
| --- | --- | --- |
| `# 文本` | Heading1（黑体 16pt，加粗，outlineLvl 0） | 一级标题 |
| `## 文本` | Heading2（黑体 14pt，outlineLvl 1） | 二级标题 |
| `### 文本` | Heading3（黑体 12pt，outlineLvl 2） | 三级标题 |
| 普通行（连续非空行合并） | Normal 段落（宋体/Times New Roman 10.5pt） | 段内换行折叠为空格 |
| `- 条目` 或 `* 条目` | ListParagraph 样式 + "• " 字面前缀 | 未用 numbering.xml，项目符号是字符，不可自动编号 |
| `\| a \| b \|` + `\|---\|` 分隔行 | 单线边框表格，首行（表头）加粗，列宽均分 | 第二行必须是分隔行，否则按普通段落处理 |
| `**加粗**` | 加粗 run | 不支持嵌套、不支持跨行 |

## 不支持项及其标注约定

母稿中出现下列写法时，**不要在 docx 中假装支持**，按约定处理：

| 写法 | docx 实际呈现 | 处理约定 |
| --- | --- | --- |
| `####` 及更深标题 | 按普通段落 | 改稿时提升到三级以内 |
| `1.` 有序列表 | 按普通段落（保留字面 "1."） | 序号保留在文本中，可接受 |
| `*斜体*` / `~~删除线~~` | 星号/波浪线原样输出 | 改为纯文字表述或 **加粗** |
| `[文字](链接)` | 字面输出 | 基金稿一般无超链接；来源写入 result.json 的 sources |
| 图片 `![…](…)` | 字面输出 | 图片不入 docx；在母稿以【图位：…】占位并在 change_record 标注 |
| 代码块 ``` | 各行按普通段落 | 基金稿少用；保留缩进空格（xml:space=preserve） |
| 行内脚注/尾注 | 不支持 | 参考文献以"作者. 题名. 刊名, 年"文本列出 |
| 上下标（H₂O、x²） | 不支持上下标格式 | 用 Unicode 字符（₂²）或改述 |

局限总原则：docx 是**可编辑交付稿**，排版以"打开不乱、结构正确、字体正确"为验收线；精细排版（页眉页脚、图表、公式）由申请人在 Word 中完成，并在 change_record.md 的人工确认项中提醒。
