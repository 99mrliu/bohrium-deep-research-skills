# 方法与阈值依据（formula-symbol-fidelity）

本文件记录各阈值与规则的理由。所有规则都是**测量 + 对账**，不是猜测。

## 1. 数学行检测（math_detect.py）

| 信号 | 权重 | 依据 |
|---|---|---|
| 行尾编号 `(n)` / `(n.m)` | +0.45 | 期刊惯例：显示公式的编号置于行尾括号内，是显示公式最强的单一证据；但编号也可能出现在非公式行（如"见式 (3)"段落恰好断行），故不单独构成判定 |
| 希腊字母出现 | +0.15 | 正文体极少含希腊字母；数学行常见 |
| 运算符出现（= + − ± × ÷ < > ≤ ≥ ≠ ≈ ∝ …） | +0.10 | 等号是公式的核心特征，但正文也含连字符/斜杠，权重压低 |
| 短行（宽 ≤ 0.6 × 页宽） | +0.05 | 显示公式通常远短于正文行 |
| 居中（行中心距页中心 ≤ 0.08 × 页宽） | +0.05 | 显示公式排版约定；页宽由 `max(x1)+min(x0)` 按对称页边距估计，也可用 `--page-width` 覆盖 |
| 符号密度（符号集字符占比 × 1.5，封顶 0.30） | ≤ +0.30 | 符号集 = 运算符 + 希腊区（U+0370–U+03FF）+ `symbol-map.tsv` 全部字形；密度是连续量，比二元特征更稳健 |

判定阈值 `confidence ≥ 0.5`（可用 `--min-confidence` 调整）。典型显示公式
（编号 + 运算符 + 短 + 居中 + 密度）得分 0.8–1.0；正文行通常为 0。
所有权重写入每条记录的 `reasons`，可审计、可复现。

### 行分组容差

词按 (page, y0, x0) 排序后聚合：`|y0 − 行锚点| ≤ 0.6 × 页中位字号` 即入行。
0.6 倍字号足够宽，能把偏移约 0.3–0.5 x-height 的上下标词留在父行内，
又小于常规行距（≥ 1.0 倍字号），不会串行。

## 2. 上下标还原（symbol_fidelity.py）

- 基线 = 行内各词 `y1`（下边缘）的中位数。坐标系 y 向下。
- 偏移 `dev = word.y1 − 基线`；`|dev| > 0.25 × 该词字号` 判定为上下标：
  `dev < 0`（词整体抬升）⇒ 上标 `^{...}`；`dev > 0` ⇒ 下标 `_{...}`。
- 0.25×字号 的理由：排印上标的典型抬升为 x-height 的 30–60%（≈ 字号的
  20–40%），下标下沉 10–30%；0.25 落在两类之间，配合上下标本身字号更小
  （阈值随自身字号缩小）可稳定区分。低于阈值一律不判（保守：宁漏判不误判，
  漏判的结果仍是可读基线文本）。
- 上下标附着于**前一个** token；行首出现上下标（无基符）时保留为独立
  `^{...}` 并在 `script_notes` 中标记 `*_no_base`，不伪造基符。

## 3. 符号映射与审计

- 映射唯一来源：`references/symbol-map.tsv`（字形 → 名称 → LaTeX）。代码不含
  个案硬编码；扩展覆盖范围 = 改数据表。
- 审计：对每个**实际出现**的字形，统计原始文本出现次数与线性化输出中其
  LaTeX 形式的出现次数（用负向环视防止 `\in` 误配 `\int` 这类子串），
  两者必须相等，否则 `status=issues`。
- 非 ASCII 且不在表中的字符：原样保留在输出文本中，同时连同码位
  （U+XXXX）、页码、行号列入 `unknown`。**不映射到近似符号，不删除。**

## 4. 为什么几何优于猜测

1. **可复现**：同一 TSV 永远得到同一结果；语言模型对"这个 PUA 字符是不是
   ∈"的猜测不可复现且无法审计。
2. **可审计**：每个判定都带数值理由（密度、偏移、置信度、reasons）。
3. **失败可见**：几何失效（旋转、图像型公式）表现为漏检/低置信 + 明确的
   reasons，而不是一个貌似合理实则错误的符号。

## 5. 限制

- 堆叠结构（分数、矩阵、多行对齐、上下限叠置的 ∑/∫）超出线性 `^/_`
  表达能力：逐行输出并在 uncertainty 中说明。
- `−`（U+2212）映射为 ASCII `-` 这类"映射到普通字符"的条目，对账计数可能
  与原文已有字符混淆；以 unknown 列表为最终依据。
- 行分组与基线估计假设水平排版；旋转数学会漏检。
- 图像型公式在词级 TSV 中不可见；本流水线不猜测其内容，只建议在
  uncertainty 中标记疑似区域。
