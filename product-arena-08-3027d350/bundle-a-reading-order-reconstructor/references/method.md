# 方法说明：版面几何驱动的阅读顺序重建

## 设计动机

通用抽取器（`pdftotext` 默认模式、多数 LLM 直读）对双栏论文的典型错误是
**串栏**：按物理 y 序把左右两栏同一水平带的两句话拼成一段。本技能的判据全部
来自版面几何（坐标、空白带、重复模式），不依赖语言内容，因此对任何学科、
中英混排同样成立，且每个决定都能在 PDF 页面上指认。

## 流水线与判据

### 1. 词级抽取（extract_words.py）

- 回退链：PyMuPDF `page.get_text("words")` → `pdftotext -bbox`（解析 XHTML
  `<word xMin yMin xMax yMax>`，同时取 `<page width height>`）→ `pdftotext -layout`
  （无坐标，仅兜底并标 partial）。
- 统一中间格式 `words.tsv`：`page x0 y0 x1 y1 text`，PDF point，左上原点。
  外部词表（如 OCR 结果）只要符合该格式即可经 `--tsv` 进入流水线。

### 2. 行/块聚类（order_blocks.py）

- 词→行：按 y0 排序，垂直重叠 > 词高的 50%（或 y0 差 < 0.4×词高）归并入行；
  只回看最近 4 行，近似 O(n)。
- 行→块：栏内相邻行纵间距 > 1.35×本页中位行高即切块。系数对常见 10pt 正文、
  1.2–1.5 倍行距稳健；段间距通常为 1.5 倍行距以上。

### 3. 页眉页脚

- 位置条件：行块整体位于页面顶部 9% 或底部 7% 内；
- 重复条件：文本归一化（去空白、数字→`#`、小写化）后在 ≥40% 页面出现。
- 两者同时满足才剔除，剔除字符量记入 `coverage.json` 的 `dropped.header_footer`，
  不静默丢弃。只在个别页出现的页边内容（如首页收稿日期）不会被误删。

### 4. 分栏与阅读顺序

- 候选空白带：内容区内不被任何行覆盖、宽度 ≥12pt 的竖直带，取最宽者；
  带两侧各有 ≥3 行才确认双栏，避免把悬挂缩进误判为栏缝。
- 整宽屏障：跨全部栏缝且宽度 > 80% 版心的行（标题、作者、摘要、通栏图表题注）
  自成一块，并把页面切成纵向带。
- 阅读顺序：按带自上而下；带内按栏从左到右、栏内按块自上而下。这与排版学
  的 column-balance 约定一致，可处理"通栏图插入双栏正文"的常见版式。

### 5. 块类型启发式

| kind | 判据 |
|-|-|
| title | 首页上 30% 区域内、行高 > 1.3×中位行高的整宽块 |
| heading | ≤2 行、行高 > 1.02×中位、匹配 `1.`/`1.2`/`IV.`/`A.` 编号 |
| caption | 以 Figure/Fig./Table/Scheme/Algorithm/图/表 开头 |
| equation | ≤3 短行且含数学符号或末尾编号 `(n)`；按结构元素整行保留 |
| reference | 首个匹配 References/参考文献 的标题块之后的块 |
| header/footer | 见第 3 节 |

启发式可能判错（如无编号标题）；判错的代价低：类型只影响 sections.json 的
层级与交付归类，不影响 fulltext.md 的文字与顺序。

### 6. 续接标记

块 A 末行不以句读（`。！？.!?;:`）结尾、块 B 非同栏标题块，且二者
（i）同页相邻栏，或（ii）相邻页，则记 `B.continues_from = A.block_id`。
只记关系不合并文本：合并属于语义决定，留给下游任务。

## 覆盖率与诚实性

`assemble_output.py` 记账：保留字符（正文/题注/公式/参考文献）+ 剔除字符
（页眉页脚，有类别）必须 ≈ 原始词字符总量。凡抽取报告中的
`no_text_layer`、判栏降级、契约字段无法填充，一律写入 result.json 的
`uncertainty` 并把 `status` 降为 `partial`——读不出的部分标注，不靠猜补齐。

## 已知边界

- 三栏以上：空白带算法只找最宽一条，多栏页按双栏处理可能并栏，uncertainty 会逐页列出。
- 栏内嵌套边注（marginalia）：边注通常不满足重复条件且位于版心外，会被判为独立小块，
  顺序上排在所在带末尾；语义归属留给下游。
- 竖排、旋转文本、Text-as-curve（矢量描边字）：未支持，词坐标异常时报告 partial。
