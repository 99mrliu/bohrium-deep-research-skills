# 方法说明：证据驱动的表格网格重建

## 设计动机

`pdftotext` 默认输出把表格压成一串空格分隔的词，列归属全失；LLM 直读表格
截图则常把"not detected"这类折行单元格拆成两行数据。本技能的结构判断全部
来自版式证据（空白列位共识、缩进、线框字符），每个单元格都能指回
`page + source_region`（页码与源行区间），歧义如实落盘。

## 1. 保版式抽取（extract_layout.py）

`pdftotext -layout` 保留空格列对齐，是空白对齐表检测的前提；PyMuPDF
`sort=True` 文本作降级（列对齐弱，报告注明置信度下降）。加密与无文字层
分别报 `encrypted_pdf` / `no_text_layer`，后者移交 OCR 后可经
`--layout-dir` 回灌。

## 2. 区域检测（detect_tables.py）

- **空白对齐表**：行内宽空白（≥2 空格）用环视正则 `(?<=\S)(  +)(?=\S)`
  提取——普通 `\S(  +)\S` 会因消耗前导字符而漏掉相邻空隙。
- **共识分列位**：先按 ±3 列把各行空白中心聚类，再保留覆盖 ≥60% 核心行
  的簇。先聚类再阈值，避免逐位置计数被 ±2 列抖动打散。
- **折行续接行**：缩进 ≥6 列、空隙不足 2 处的行允许留在区域内（不参与
  共识），使"not detected / (below 1 %)"这类折行不被截断。
- **线框表**：`─-+|=` 行簇识别；与空白区域重叠者剔除，避免一表两检。
- **行间空行容忍**：`pdftotext -layout` 在行距大于约 1.5 倍字号时会在
  表格行间插入空行；连续区允许 ≤2 个空行且下一个非空行仍是成员
  （空行不参与分列共识）。
- **题注绑定**：区域上下 8 行内最近的 `Table n`/`表 n`，距离按非空行计
  （题注与表格之间的空行不放大距离）；缺失或偏远时
  在条目上标 unresolved，置信度相应下调。

## 3. 网格重建（reconstruct_grid.py）

- **分列位吸附**：共识位可能落在某行文字中间（表头与数据列宽不同）。
  吸附在 ±4 列内选"最多行是空白"的列，保证切分不切断任何单元格。
- **折行合并**：首格为空且仅一格非空 → 并入上一行该列（标 `wrapped`），
  恢复视觉折行对应的逻辑单元格。
- **合并表头**：表头文字跨过分列位 → `colspan`，被跨列标 `merged_into`；
  只对首行生效，多层表头在 notes 中说明而不硬猜层级。
- **空数据格**：可能是纵向合并（上一格向下延伸）也可能是缺失值——
  两种语义不同，不判定，标 `unresolved`，交由任务方结合原文裁定。

## 4. 三态输出的分工

| 形态 | 面向 | 说明 |
|-|-|-|
| JSON | 溯源与程序处理 | 每格带 row/col/rowspan/colspan/wrapped/merged_into/unresolved |
| Markdown | 人与 LLM 阅读 | ⚠ 标未判定，〔跨n列〕标合并 |
| CSV | 计算复用 | 纯净网格，空格保持为空（不填猜测值） |

## 已知边界

- 跨页续表按页独立重建，`source_region` 自带页码，可在 result.json 中
  注明同源关系后由任务方并表；本技能不自动跨页合并（合并语义需题注证据）。
- 完全无对齐空白也无线框的"隐形表格"检不出，如实 partial。
- 竖排表头、斜线表头未支持；检出后在 notes 标注。
