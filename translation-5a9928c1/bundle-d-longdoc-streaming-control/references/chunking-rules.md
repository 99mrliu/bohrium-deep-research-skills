# 切块规则（Bundle D）

- 单元（unit）：空行/分页分隔的语义块；标题、题注独立单元；**永不切断段落**。
- 估计词元：`ceil(字符数 / 4)`，仅用于切块与预算提示，与真实模型计费无关。
- 打包：顺序累计 ≤ `budget_tokens` 成块；单单元超预算 → 独占一块并警告（exit 1），
  此时应提高预算或预先将该单元分段处理。
- 块 ID `c001…`、单元 ID `u0001…` 全任务稳定。

## 与段级台账的关系

Bundle D 的台账管"块/批"级续跑与预算（批不漏、不重、不续错位）；
Bundle B 的段级台账管"段"级一一对应。长文案例可先用 D 完成分批翻译，
再用 B 的 `coverage.py` 做段级完整性核验。
