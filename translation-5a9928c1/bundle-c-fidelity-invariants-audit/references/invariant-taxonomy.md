# 保真不变量分类与归一化（Bundle C）

## 类别

| 类别 | 说明 | 示例 |
|-|-|-|
| quantity | 数值+单位（含范围 range、科学计数 ×10^n） | `10 mg`、`0.61–0.85`、`1.2 个百分点` |
| statistic | p 值、n=、CI、HR/OR/RR | `p < 0.01`、`n = 214`、`95% CI`、`HR = 0.72` |
| citation | 方括号引用编号（范围展开） | `[1, 2]`、`[1–3]` → `1,2,3` |
| ref | 图表/公式/章节编号（含中文 图/表） | `Figure 2`、`Table 1`、`图 2` → `figure2` |
| negation | 否定标记（英/中） | `no/not/did not/without`；`未/无/不/缺乏/并未` |
| qualifier | 限定/情态标记 | `may/suggests/approximately`；`可能/提示/约` |

## 归一化规则

- 数字：全角→半角；千分位逗号去除；`−/–/—`→`-`；`×10^n`→`{m}e{n}`。
- 单位：小写、`µ`→`μ`；中文单位映射（周→weeks、天→d、小时→h、分钟→min、
  毫升→ml、毫克→mg、微克→μg、毫米→mm、厘米→cm、纳米→nm、千帕→kpa、
  个百分点/percentage points→pctpt …）。
- 引用范围 `[a–b]` 展开为编号集合后比较。
- 方括号内的编号不作为 quantity（避免引用号被当数值）。

## 差异分级

| 判定 | 含义 | 处置 |
|-|-|-|
| missing / added | 源有译无 / 译有源无 | 硬性差异，须修订或说明 |
| changed | 同单位统计量或带单位数值的值改变 | 硬性差异 |
| negation_lost / qualifier_lost | 源句否定/限定在译句消失 | 硬性差异 |
| unit_convention | 值相同、单位相同（映射后）或裸数↔带单位 | 非硬性，入人工确认 |
| sentence_count_mismatch | 段内句数不齐 | 非硬性，提示对齐风险 |

## 已知限制

- 中文数字（"三折""十余"）只标记不换算；`point/points` 不视为单位（靠裸数↔带单位惯例抵消）。
- 句对齐按段内句序号；跨句合并/拆分会产生对齐风险信号。
- 审计差异是修订信号，不是自动改译指令。
