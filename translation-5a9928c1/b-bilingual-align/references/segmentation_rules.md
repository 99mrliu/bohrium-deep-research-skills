# 分段规则(Segmentation Rules)

本文是 `scripts/segment_text.py` 的完整规则说明。所有规则确定性执行:相同输入必然得到相同输出。

## 1. 输入与分页

- 输入 `.pdf` 时,脚本调用 `pdftotext -layout <src> <tmp>`,再读取临时文本。
- `pdftotext` 以**换页符 `\f`(form-feed, U+000C)**分隔页;脚本按 `\f` split 得到页序列,页码从 1 起。
- 输入 `.txt` / `.md` 时直接读取(同样支持字面 `\f` 分页)。
- 文件每行做 `rstrip`;空行(空白-only)是段落边界信号。

## 2. 断词修复(Hyphenation repair)

规则:当前行以 `-` 结尾,且下一行**以小写字母开头**时,合并两行并删除连字符
(`charge-` + `transport` → `chargetransport`),`hyphen_joins` 计数 +1。

- **续行必须小写开头**的条件:大写开头几乎总是新句子或专名(如
  `... methods.` 换行后 `Figure 2 shows ...`),不应拼接;只有小写续行才符合
  英语断词习惯(词中部断开)。该条件把误合并概率降到最低。
- 修复**只在同一段落内进行**:段落跨越页边界时,页尾的 `-` 不与下一页首行拼接
  (跨页断词极少见,保守处理,宁可留 `-` 也不误拼)。
- 修复发生在软换行合并**之前**,因此一个物理段落内允许多处断词。

## 3. 软换行合并(Soft unwrap)

- 连续非空行合并为一个段落,行间以单个空格连接。
- 空行(完全空白)是段落边界。

## 4. 页眉 / 页脚剔除(Running header/footer)

- 统计每页**第一个**与**最后一个**非空行;某一行字符串在 **≥3 页**的页首或页尾出现,
  即判定为页眉/页脚,全部剔除,并记入 `dropped_repeated_lines`。
- 阈值 ≥3 的理由:正文短句偶然出现在页首/页尾的概率不低,但同一字符串在 3 页及以上
  的边缘位置重复,几乎只能是运行性页眉/页脚。
- 仅剔除出现在边缘位置的实例;同字符串出现在段落中间不受影响。

## 5. 页码行剔除

- 纯数字行(`^\d{1,4}$`)一律剔除,计数 `page_number_lines_dropped`。
- 位于段落中间的数字行(前后行非空)仍保留在段落内。

## 6. 段 ID 方案

- ID 形如 `P0001`、`P0002`…(P + 四位零填充序号),按段落出现顺序分配。
- **ID 稳定**:ID 只依赖分段结果;同一输入文件重复运行,ID 不变。
- 每条记录字段:`seg_id`、`page_start`、`page_end`、`char_count`、`text`。
- 跨页段落的 `page_start` / `page_end` 记录其起止页码。

## 7. 报告字段(seg_report.json)

| 字段 | 含义 |
| --- | --- |
| `pages` | 非空页数 |
| `paragraphs` | 产出段落数 |
| `hyphen_joins` | 断词修复次数 |
| `dropped_repeated_lines` | 被剔除的页眉/页脚行(排序后的字符串列表) |
| `page_number_lines_dropped` | 被剔除的纯页码行数 |
| `warnings` | 警告(如 PDF 无文本层、产出 0 段) |

## 8. 已知限制

- **双栏交错**:双栏论文用 `-layout` 可保持视觉行序,但栏间阅读顺序仍可能错乱,
  需要人工核对块序(尤其跨栏引用的图表);本技能不猜测栏序,错乱时在报告中显式说明。
- **扫描版 PDF**:`pdftotext` 产出为空,脚本在 `warnings` 中提示需先 OCR
  (OCR 超出本技能范围)。
- **公式/图表为图片**:无文本可抽,相关段落可能缺失;不编造内容,缺失在对齐阶段显式登记。
- **列表/小节标题**:不加特殊处理,与普通行一样参与合并;空行仍是最可靠的结构信号。
