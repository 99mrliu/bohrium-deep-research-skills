# Locked Glossary（锁定术语表，翻译时必须执行）

- **grain boundary**（缩写 GB） → 晶界；禁用变体：颗粒边界、晶粒边缘
- **segregation** → 偏聚；义项：溶质在晶界处的富集，非种族隔离义
- **solid oxide fuel cell**（缩写 SOFC） → 固体氧化物燃料电池；禁用变体：固态氧化物燃料电池
- **yttria-stabilized zirconia**（缩写 YSZ） → 氧化钇稳定氧化锆；禁用变体：钇稳定锆石
- **Σ3** → Σ3

规则：同一义项全篇同一译名；标题/摘要/正文/图注/结论一致；禁用变体出现即违规；keep_original 条目允许零译名。
