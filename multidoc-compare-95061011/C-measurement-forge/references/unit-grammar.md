# 单位语法与换算规则（unit-grammar）

本文件定义 `scripts/units.py` 的单位代数语义，以及机检与 agent 处置规则。

## 1. 解析模型

每个单位解析为：

```
{ "dimensions": {量纲符号: 指数}, "scale": 到 SI 的换算因子, "canonical": 规范写法 }
```

- 量纲符号集：`L` 长度、`M` 质量、`T` 时间、`A` 电流、`K` 温度、`N` 物质的量、`I` 发光强度、`DIM` 无量纲计数。
- SI 基本单位：`m`、`kg`、`s`、`A`、`K`、`mol`、`cd`。注意 **质量的 SI 基本单位是 kg，不是 g**：`g` 的 scale = 1e-3；因此 `g/L` 的 scale 恰好为 1.0（与 kg/m³ 等价），`mg/L` 的 scale = 1.0（与 g/m³ 等价）。

## 2. 支持的语法

| 写法 | 例 | 解析 |
|---|---|---|
| 乘积 | `mg*L`、空格连接 `mg L` | 因子相乘 |
| 商 | `mg/L`（一条 `/`，分母可再含乘积） | 分子/分母 |
| 指数 | `s^-1`、`L^-3`、`m2/g` 的 `^n` 数字形式 | 幂 |
| 上标异体 | `min⁻¹`、`m²`、`m³`、`s⁻²` | 统一为 `^` 形式 |
| 倒数 1/x | `1/min` | = `min^-1` |
| per 短语 | `per minute` | = `min^-1` |
| 百分数/比率 | `%`、`‰`、`ppm`、`ppb`、`1`（无量纲） | `DIM=1`，scale 0.01 / 1e-3 / 1e-6 / 1e-9 / 1.0 |
| 温度 | `°C`、`℃` | 仿射换算：K = °C + 273.15 |
| 摩尔浓度 | `M`（= mol/L）、`mM`、`µM`、`nM` | 注意单写 `M` 判为 mol/L，不做兆词头 |
| 派生单位 | `W`、`V`、`J`、`eV`、`Pa`、`Hz`、`L`(=1e-3 m³) | 展开为量纲向量 |

## 3. 词头表

`Y` 1e24 · `Z` 1e21 · `E` 1e18 · `P` 1e15 · `T` 1e12 · `G` 1e9 ·
`M` 1e6 · `k` 1e3 · `h` 1e2 · `da` 1e1 · `d` 1e-1 · `c` 1e-2 ·
`m` 1e-3 · `u`/`µ`/`μ` 1e-6 · `n` 1e-9 · `p` 1e-12 · `f` 1e-15

词头最长匹配（`da` 优先于 `d`）。`kg` 是基础单位，**不允许**再加词头（`mkg` 非法）。

## 4. 可换算判定

- 量纲向量（去零指数后）**一致** → 可换算。换算因子 = `scale(u1) / scale(u2)`。
- 量纲向量**不同** → 不可换算，`convert` 返回 `None`；比较矩阵中该格标"不可换算"，不给出数字。
- 任一单位无法解析 → `None` / `convertible` 返回 `False`。

常用判定示例（均可由 `python3 scripts/units.py --selftest` 复验）：

| u1 | u2 | 结果 |
|---|---|---|
| `%` | `fraction`（纯小数） | 可换算：96 % ↔ 0.96 |
| `mg/L` | `g/L` | 可换算：500 mg/L = 0.5 g/L |
| `min⁻¹` | `s^-1` | 可换算：0.031 min⁻¹ ≈ 5.17e-4 s^-1 |
| `mg/L` | `%` | **不可换算**（量纲不同） |
| `min^-1` | `%` | **不可换算**（速率常数 vs 效率，量纲不同） |

## 5. 不可换算 / 未登记单位的处置

| 情形 | 处置 |
|---|---|
| 量纲不同 | 判不可比；矩阵保留原值原文，不换算、不合并 |
| 单位无法解析（如 `mL/min/cm²` 未登记写法、`quanta`） | 记录保留**原单位原文**，置 `unregistered_unit_accepted: true`，不换算；台账 SI 列显示 `unregistered(不换算)`；机检给出 WARNING 并提示登记 |
| 温度 °C ↔ K | 仿射换算，结果标 derived |
| 换算值 | **一律标 `status: "derived"`**，原值原文永远保留；比较矩阵"换算到规范单位"列显示 derived 值 |

## 6. 与 quantity_kind 的联动

- 单位可换算**不等于**可比较。`%` 与 `min^-1` 即使各自可解析，因 quantity_kind 不同（degradation_efficiency vs rate_constant）而**机检直接判不可比**。
- 每类量的规范比较单位见 `references/quantity-kinds.json` 的 `canonical_unit`；矩阵把同组记录换算到该单位显示。
