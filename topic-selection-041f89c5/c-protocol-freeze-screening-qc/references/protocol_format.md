# 筛选协议格式（protocol.md）

## 骨架

```markdown
# 筛选协议

研究问题：在【对象/场景】下，【方法】相比【基线】是否影响【结局】，可通过【测量】检验。

冻结时间: 2026-11-24T10:00:00+08:00

证据来源：/input 文献集（N 条记录）；联网检索通道：无（覆盖边界=输入文献集）。

## 纳入标准
- [I1] 研究任务与上述研究问题相同或为其子任务，报告了可比较的结局指标。
- [I2] 发表/记录时间在 2015-01-01 之后。

## 排除标准
- [E1] 仅为观点性评论，无任何实验或数据支撑。
- [E2] 结局指标与本问题不可比较且未给出可换算信息。
- [E3] 与已纳入记录为同一工作的重复报告（保留信息最全者）。

## 修订记录
- 2026-11-24 初版冻结。
```

## 写作规则

1. 每条标准必须是**对单条文献记录可机械执行的判定句**：含明确阈值、时间窗、研究类型；禁止"相关者纳入""质量低者排除"这类需要再解释的空标准。
2. 标准在打开文献全文之前定稿并写冻结时间；lint 通过后才允许开始筛选。
3. 冻结后可以修订（发现协议遗漏是正常现象），但修订只允许**追加**到 `## 修订记录` 区，格式 `- <日期> <原因与内容>`；不得改写已冻结条目而不留痕。修订后受影响的已决策记录应复核并在日志 note 中说明。
4. 证据来源声明必须诚实：没有联网通道就写覆盖边界，综述结论只在该边界内成立。
