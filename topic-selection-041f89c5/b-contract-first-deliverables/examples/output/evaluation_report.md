# （合成示例）图检索筛选加速提案评估报告

case_id：`SYNTH-DEMO-001`

## 1. 研究问题定义

- 可检验陈述：在系统综述题摘筛选场景下，图检索增强流程相比关键词基线是否在 95% 召回约束下降低人工筛选量，可通过 WSS@95%R 对比检验。
- 研究对象：系统综述题摘筛选
- 关键变量：自变量=检索策略；因变量=WSS@95%R；混杂=语料不均衡度
- 比较基线：关键词检索基线
- 可证伪条件：图检索流程的 WSS@95%R 不显著高于关键词基线
