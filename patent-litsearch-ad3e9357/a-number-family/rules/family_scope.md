# 同族口径规则（rules/family_scope.md）

与 `scripts/merge_family.py` 同步。

## 两种口径（必须并列输出、明确标注）

- **简单族（simple）**：优先权集合完全相同的记录归为一族。集合用规范化优先权键（国家|序号）比较，忽略申请号/公开号的种类差异。
- **扩展族（extended）**：共享至少一项优先权的记录构成连通分量（并查集）。覆盖范围恒不小于简单族。

两口径语义不同：简单族偏"同一申请的各国同族"，扩展族偏"技术关联族"。输出中必须写清每个族列表用的哪一口径（`scope_note` 字段）。

## 边界与限制（必须随结果声明）

1. 归并**仅基于输入记录中观察到的优先权/号码链接**；未观察到的族成员不在结果中，不得据此声明"完整同族"，不得据此断言等效权利要求范围。
2. 优先权缺失或无法规范化的记录单列（`records_without_priority`），族归属不确定，输出 warning。
3. 同一规范化号码重复出现时去重，保留首条，被去重记录的 locator 保留在 `dedup_events` 可追溯。
4. 同号不同题名等字段冲突不合并，双方 locator 列入 `conflicts` 并写入 uncertainty。

## 法律状态纪律

本 Skill 不核验法律状态。凡任务涉及授权/失效/审中等状态：一律标注"官方登记未核验（查询日期：<当天 ISO 日期>）"；不引用转载聚合页作为登记依据；状态结论需要官方登记来源时，列入人工复核建议。
