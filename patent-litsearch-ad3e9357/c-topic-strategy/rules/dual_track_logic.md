# 规则：专利文献 vs 非专利文献的双轨检索逻辑

专利与技术论文是两种不同性质的文献，用同一套关键词逻辑检索两者是典型错误。
本 Skill 按记录特征自动分轨，并对两轨采用不同逻辑。

## 1. 轨道判定（search_corpus.py 实现）

| 信号 | 方向 |
| --- | --- |
| 公开号/专利号（`XX1234567A1` 型）、kind code、IPC/CPC、申请人/专利权人、权利要求字段、优先权号、同族号 | 专利轨道 |
| DOI（`10.xxxx/`）、期刊名、作者列表、卷期页、ISSN、PMID | NPL 轨道 |
| 两边信号都不足或打平 | **unclassified**：原样列出（hits.json 的 unclassified 与 omissions），不强行归轨 |

判定只看记录内容，不看文件名（文件名标签可能是误导）。

## 2. 专利轨道：分类号优先 + 同族去重 + kind code 感知

- **分类号优先**：IPC/CPC 是专利特有的受控标引。classification 分面与关键词块是
  **OR 召回**关系——仅分类号命中（无关键词命中）的记录也进入命中池（matched_via=
  "classification"），由查准阶段决定纳排；关键词命中 + 分类号重合是强相关信号（I2）。
- **字段限定匹配**：关键词块在 标题/摘要/权利要求/分类号/申请人 字段内匹配；
  权利要求命中权重最高（见 screening_protocol.md）。
- **同族去重**（优先级递减）：family 字段 → 优先权号 → 规范化公开号（去 kind code）。
  保留字段最丰富的一条为代表，其余记入该条的 `duplicates`（file#loc 可追溯）。
  **注意：观察到的链接/引用不构成完整同族**——只信语料内字段，不得凭外部知识合并。
- **kind code 语义**：A1=公开、B1=授权等同族不同阶段；规范化时剥离末尾 kind code
  比较，号码查询中 "XX1000002" 可命中 "XX1000002B1"（双向容忍）。

## 3. NPL 轨道：关键词优先 + DOI 去重

- **关键词优先**：论文无分类号体系，关键词块只在 标题/摘要（或全文 _text）匹配；
  classification 分面对 NPL 不生效。
- **去重**：DOI 规范化（小写）→ 无 DOI 时标题规范化（小写、去非字母数字）。
- 年份取 year/date 字段，用于 year_range 过滤与排序的年份接近度。

## 4. 两轨共用

- year_range：记录年份**已知**且越界才剔除；年份未知不剔除（诚实，不过度过滤），
  排序时给中性分。
- applicant 分面：仅在申请人/专利权人字段做子串匹配，声明后未命中即剔除。
- NOT 词项：命中即整条排除该记录（块内排除逻辑，见 topic_query_construction.md R4）。

## 5. OCR 合并文献（如 WO 传真合订）处理

- PDF 先 `pdftotext -layout`；扫描件先渲染再 OCR。抽不出文本的文件列入
  skipped_files 与 omissions，不得臆造内容。
- 多件文献 OCR 合并在一个文件、且边界标记被保留时：**先按边界标记拆成多个
  txt 再放入语料目录**，使每条记录可独立定位；无法可靠拆分时按单条记录处理
  （loc="file"），并在 uncertainty 注明"定位粒度为整文件"。

## 6. 法律状态

当前官方法律状态一律视为**未知**：不得输出"有效/失效"结论；如需提及，写
"法律状态未核验"并列入 uncertainty。权利要求类任务只做带来源定位的事实摘录。
