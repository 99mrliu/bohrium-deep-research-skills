# Runbook 章节格式规范

本规范定义"方法与实验"章节的 runbook 化排版：步骤表、环境矩阵、复现清单三件套，
外加正文叙述。所有事实性内容（命令、版本、种子、路径、指标）必须可定位到材料
`file:line`；定位不到的一律写"材料未提供"，并进入人工确认项。

## 1. 步骤表列定义

| 列 | 含义 | 填写规则 |
|---|---|---|
| 步骤号 | 执行顺序编号 | 有日志时间线按时间线；无则在表下注明"顺序为材料出现顺序，待确认" |
| 名称 | 步骤短名 | 如 数据获取 / 数据预处理 / 模型训练 / 模型评估 |
| 输入 | 本步消费的数据或产物 | 路径照抄材料；来自前步产物时注明"步骤 N 的输出" |
| 命令/操作 | 完整命令行 | **逐字照抄** commands.json 中的真实命令，含全部 flag；禁止凭记忆重写 |
| 预期输出 | 本步产物 | 文件路径、日志完成标记或指标值，注明来源（如 `run.log:8`） |
| 判断条件 | 如何判定本步成功 | 可观察、可判定（见第 3 节）；每条注明依据来源 |
| 来源 | 命令出处的 `file:line` | 由脚本自动填入；正文引用时不得删除 |

## 2. 环境矩阵表模板

| 项目 | 取值 | 来源 | 状态 |
|---|---|---|---|
| 硬件 | 如 NVIDIA A100-SXM4-80GB ×1 | run.log:2 | 已给 |
| CUDA | 如 12.1 | README.md:6 | 已给 |
| 框架 | 如 torch 2.1.0+cu121 | requirements.txt:1 | 已给 |
| Python | 如 3.10.12 | run.log:1 | 已给 |
| 其他关键库 | 如 transformers 4.38.2 | requirements.txt:2 | 已给 |
| 代码版本 | commit/tag/仓库地址 | — | 缺失 → 人工确认项 |

状态只能是：已给（注明来源）/ 缺失（列入人工确认项）。**禁止写 "latest"、"最新版"**
等含混版本（见 repro_failures.md）。

## 3. 判断条件写法示例

判断条件必须让不参与实验的读者也能客观判定"这一步成了没有"。

- 弱写法（禁止）："运行训练脚本，等待完成。"
- 合格写法："退出码为 0，且 `outputs/best.pt` 存在；日志出现 `train done` 字样
  （依据 run.log:6）。"
- 含指标的写法："评估日志输出 `test acc`，应不低于 0.87（材料实得 0.879，run.log:8）；
  低于该值说明环境或数据与材料不一致，应停止后续步骤并排查。"
- 数据步骤写法："`data/clean.csv` 存在且行数约为 12843（run.log:4 报告 12843 行）；
  行数偏差超过 1% 视为预处理结果不一致。"

要点：每个判断条件 = 一个可观察信号 + 一个判定阈值/标志 + 一个材料来源。

## 4. 复现清单模板

| 编号 | 检查项 | 内容 | 状态（已给/缺失） | 来源或缺口说明 |
|---|---|---|---|---|
| G1 | 代码版本 | commit / tag / 仓库地址 | | |
| G2 | 运行环境 | 硬件、CUDA、框架、Python 版本 | | |
| G3 | 依赖 | 安装命令与锁定版本 | | |
| G4 | 完整命令 | 逐步命令（与步骤表一致） | | |
| G5 | 数据获取 | 下载命令 / 数据版本 / 划分方式 | | |
| G6 | 随机种子 | 种子值及作用范围 | | |
| G7 | 预期校验 | 预期产物与指标阈值、校验方式 | | |

- 该表由 repro_check.py 自动核验（present/missing/unknown）；章节中的表格必须与其
  结论一致。
- "缺失"行必须同时出现在文末**人工确认项**列表中，格式：
  `- [人工确认] G6 随机种子：材料（README、脚本、日志）均未记录种子，需作者补充。`

## 5. 章节整体结构建议

1. 实验设置（环境矩阵 + 依赖 + 代码版本）；
2. 数据（来源、获取命令、规模、划分；缺划分信息时如实说明）；
3. 方法步骤（步骤表 + 每步一段简要叙述，叙述不得引入步骤表之外的命令）；
4. 对照设置（baseline / 消融；材料未提供时写明"材料未包含对照实验记录"）；
5. 复现清单与预期校验（复现清单表 + 判断条件汇总）；
6. 限制与不确定性（材料缺口、顺序不确定、版本含混等）；
7. 人工确认项（汇总所有缺失）。
