# 方法与实验（合成示例草稿，非正式案例结果）

## 模型与优化

本节为待修草稿，数值尚未核对。实验采用 ResNet-18 作为骨干网络，
使用 Adam 优化器，初始学习率 0.0003，权重衰减 0.0001，共训练 50 个 epoch，
批大小为 32。为防止过拟合，dropout 比率设为 0.5。

## 数据划分

数据集按 0.8 / 0.1 / 0.1 划分为训练集、验证集与测试集，随机种子固定为 42。

## 备注

训练日志显示实际生效的学习率与 config.yaml 不一致（见 train.log），
此处按 config.yaml 记录，冲突项待人工确认。
