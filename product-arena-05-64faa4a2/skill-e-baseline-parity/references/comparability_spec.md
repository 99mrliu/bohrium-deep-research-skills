# 可比性规范（comparability spec）

> 本规范定义“对照实验结论可比”的最低工程标准。核心命题：**“优于基线”只有在基线身份明确、同预算、同数据划分、指标与统计方式写清时，才是可比结论。**

## 1. 基线身份五要素

台账中每个基线必须尽力补全以下五项，缺项记为“未知”并列入人工确认项：

| 要素 | 说明 | 示例 |
|---|---|---|
| 名称 | 方法 canonical 名称 | ResNet-50 |
| 版本 | 版本号 / 模型规模 / 代码库 commit | v1.2、-large、7B |
| 来源类型 | 自复现 / 原报 / 未知 | 自复现 |
| 出处 | 引文标记或仓库/配置位置 | [3]、config_base.yaml |
| 关联指标 | 该基线出现的指标与数值及证据 file:line | accuracy=91.10（results.log:5） |

## 2. 同预算定义

对照组之间以下维度取值一致（或差异已显式声明并给出理由）时，方称“同预算”：

1. **训练预算**：epochs / steps / wall-clock 上限；
2. **数据预算**：训练样本量、数据划分、预处理与增强管线；
3. **调参预算**：超参搜索空间、trial 次数、早停准则；
4. **推理预算**（若比较效率）：batch size、硬件、精度（fp32/fp16）。

核验规则：任一维度在对照组间取值不同 → parity 违规，必须在对照实验小节中**显式声明差异**；某组取值缺失 → 记“未知”，不得默认其与本组一致。

## 3. 原报值引用规则

1. 引用原论文报告值（原报值）必须带引文标记（[n] 或 (Author, year)）；
2. 必须在其首次出现处注明“**非同等条件**”（数据划分、预处理、评价协议通常不同）；
3. 原报值不得与自复现结果直接放入同一排名断言；只能作为背景参考；
4. 若原报值与本工作复现值同时存在，两者分行列出并各自标注来源。

## 4. 统计协议最低要求

| 要素 | 最低要求 | 缺失时的处理 |
|---|---|---|
| 重复次数 | ≥3 次独立运行（不同随机种子），声明种子数 | 声明缺口，禁用“显著”类措辞 |
| 均值±标准差 | 主指标报告 mean ± std | 只报单次值时声明“单次运行结果” |
| 显著性检验 | 注明检验方法与置信水平（如 paired t-test, p<0.05） | 降级比较级论断为描述性陈述 |
| 指标定义 | 主指标给出口径（如 top-1 accuracy, macro-F1） | 视为缺口，列入人工确认项 |

## 5. 可比性矩阵表模板

行 = 对照项，列 = 各基线与本文方法；单元格取值 **同 / 异 / 未知**：

| 对照项 | 基线A | 基线B | 本文 |
|---|---|---|---|
| 基线身份（名称+版本+来源） | 同（自复现，config 可定位） | 异（原报值，非同等条件） | — |
| 数据划分 | 同 | 未知 | 同 |
| 训练预算（epochs/steps） | 异（50 vs 200，已声明） | 未知 | 200 |
| 调参预算 | 未知 | 未知 | 未知 |
| 主指标与口径 | 同 | 异（原报口径） | 同 |
| 重复次数 / 统计检验 | 异（单次运行，无检验） | 未知 | 异 |

填表纪律：凡是材料中没有直接证据的单元格一律填“未知”，禁止用“同”占位；含“异/未知”的列参与的所有比较结论都必须附限定语。

## 6. 对照实验小节骨架

1. **对照设置**：基线清单（身份五要素）+ 选择理由；
2. **可比性声明**：同预算核验结果 + 可比性矩阵表 + 差异的显式声明；
3. **结果**：主指标表（mean ± std，注明重复次数），自复现与原报分行；
4. **统计检验**：方法、置信水平、p 值；
5. **复现与限制**：随机种子、代码/配置位置、已知不可比之处。
