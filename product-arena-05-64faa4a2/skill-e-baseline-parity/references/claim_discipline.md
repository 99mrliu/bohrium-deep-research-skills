# 比较论断的写作纪律（claim discipline）

> 目标：章节中每一句“优于/相当/超过”类论断都有指标、数值、统计依据三件套支撑；缺一件就降级为描述性陈述或标注 **[待确认]**。

## 1. 论断-证据配对

每条比较性论断必须能在同句或同段落内配齐：

1. **指标名**：明确口径（top-1 accuracy、macro-F1，而非笼统的“性能”）；
2. **数值**：本文与基线的数值同时出现，且能在材料/台账中定位（file:line）；
3. **统计依据**：重复次数 + mean ± std；使用“显著”时必须另有检验方法与置信水平。

配对不上时的处置优先级：
- 能从材料补数值 → 补数值后保留论断；
- 补不了 → 降级为描述性写法；
- 连描述性数值都缺 → 标注 **[待确认]** 并列入 result.json 的人工确认项。

## 2. 无同预算时如何措辞

| 情形 | 禁用 | 推荐措辞 |
|---|---|---|
| 训练预算不同（如 epochs 50 vs 200） | “显著优于” | “在基线训练预算（50 epochs）低于本文（200 epochs）的条件下，本文取得 X，基线为 Y；该差异包含预算因素的影响” |
| 仅有原报值（非同等条件） | “超过 SOTA” | “原论文报告值为 Z（非同等条件，仅供背景参考）；本文在自身协议下取得 X” |
| 单次运行、无重复 | “稳定优于”“显著” | “单次运行结果为 X vs Y，未做重复实验，差异的统计可靠性未知” |
| 调参预算未知 | “公平对比下优于” | “基线调参预算未在材料中记录，对比结论以当前配置为准” |

## 3. 常见夸大模式与降级改写示例

| 夸大模式 | 原句 | 降级改写 |
|---|---|---|
| 无支撑全称 | “我们的方法显著优于所有基线。” | “在相同数据划分下，本文方法 test accuracy 为 92.40，自复现 ResNet-50 为 91.10（各单次运行，未做显著性检验）[待确认]。” |
| 原报值混入排名 | “超过 VGG-16 报告值，达到新 SOTA。” | “VGG-16 原论文报告 71.3（非同等条件）；本文协议下结果为 92.40，二者不直接可比。” |
| 隐藏预算差异 | “在相同设置下优于基线。” | “本文训练 200 epochs，基线为 50 epochs（预算不一致，已声明）；在该条件下结果为 …” |
| 模糊指标 | “性能更好。” | “主指标 macro-F1：本文 0.812 ± 0.004（3 seeds），基线 0.798 ± 0.006（3 seeds），paired t-test p=0.03。” |
| 绝对化 | “全面领先。” | 逐指标列出数值，只在有统计支撑的指标上使用“优于”，其余用“相当/差异未知”。 |

## 4. 强措辞门槛

- “显著 / significantly”：必须同时满足（a）≥3 次重复；（b）报告 mean ± std；（c）注明检验方法与置信水平。三者缺一即降级。
- “所有基线 / all baselines”：台账中若存在原报值基线或任何“未知/异”单元格，论断范围必须收窄到同等条件对照组。
- “相当 / comparable”：需给出数值区间或检验结论支持“差异不显著”，否则改为“数值分别为 …，差异是否显著未知”。
