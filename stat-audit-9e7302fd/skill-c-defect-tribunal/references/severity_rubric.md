# 严重度四级评定标准（按对论文结论的后果校准）

定级只看**后果**：该缺陷若成立，对论文结论造成多大损害。不看缺陷"听起来多严重"。
默认就低不就高；升级必须给出后果论证（critical 必须填 `consequence`）。

## critical — 主要结论可能不成立

**判定问题**：若该缺陷成立，论文的主要结论（主要终点/核心主张）是否可能不成立或反转？

**校准锚点**：

- 结论称干预组显著优于对照组，但其自身表 2 显示组间 p=0.31 且方向相反 → 显著性声称
  与方向同时无据，主要结论反转。
- 主要终点在结果节被调换（注册/方法中的主要终点 A 被替换为事后显著的 B 且未声明）。
- 研究设计根本不能回答研究问题（如用横断面设计声称估计干预因果效应并据此提出
  干预建议）。

**反锚点（达不到 critical）**：

- 次要/探索性终点的统计瑕疵，主要结论不受影响 → 至多 major。
- 缺精确 p 值、缺自由度，但显著性方向与幅度无争议 → minor。
- 需要外部材料才能确认的数值疑点 → 待复核，不得直接定 critical。

## major — 结论可信度受损，但未必推翻

**判定问题**：该缺陷是否实质性削弱主要结论的可信度，但尚不足以断定结论反转？

**校准锚点**：

- 关键混杂/协变量（如基线不均衡且与结局相关的变量）未控制，主要比较可能因此偏倚。
- 多重比较未校正**且涉及主要终点相关的一族检验**，显著性可能依赖多重性。
- 主要结论依赖的效应断言无任何不确定度度量（无 CI、无精确 p），强度无法评估。

**反锚点（达不到 major）**：

- 仅报告层面缺失（缺 df、缺检验名称），结果本身自洽 → minor。
- 图形呈现可改进但不缺任何数据 → editorial/建议。
- 仅摘要遗漏、正文完整 → minor 以下。

## minor — 报告完整性受损

**判定问题**：该缺陷是否只影响可复核性/报告完整性，不影响结论方向与强度？

**校准锚点**：

- 仅报 "p<0.05"，未给精确 p 值、检验统计量或自由度。
- 分组切点依据未说明，但切点本身常见且结果不敏感。
- 未报告具体所用检验名称（无证据表明误用）。

**反锚点（达不到 minor）**：格式、措辞、图表美观问题 → editorial。

## editorial — 表达/格式

**判定问题**：是否纯属文字、格式、呈现层面？

**校准锚点**：术语前后不统一；图表标题信息不全但数据完整；参考文献格式错误。

**反锚点**：任何涉及数据、方法、结论实质的内容都不属 editorial。

## 升降级口诀

- 想升一级：必须回答"升一级后，后果论证是什么？"答不出 → 维持原级。
- 想降一级：辩护四问 q4"严重度若降一级是否仍成立？"答"成立"→ 必须降级。
- critical 无 `consequence` → 校验脚本直接拒绝。
