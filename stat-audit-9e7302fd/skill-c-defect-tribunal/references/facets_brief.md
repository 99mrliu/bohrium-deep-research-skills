# 五面候选发现问题清单（宽进阶段用）

逐面对全文发问，产出候选发现。此阶段只负责"找全"，每条带逐字 quote + location；
定性定级由裁决庭裁定，此处不必谨慎。

## 1. 研究设计

- 研究问题与研究设计是否匹配（因果问题用了观察设计？）
- 对照/比较组是否合适、是否描述清楚？
- 随机化、分配隐藏、盲法是否报告？报告了什么？
- 主要/次要终点是否预先定义、前后一致？
- 纳排标准是否清晰、是否可能导致选择偏倚？

## 2. 变量定义

- 关键变量（暴露、结局、协变量）是否有操作化定义？
- 测量方式、时间点、单位是否写明？
- 分组/切点依据是否说明？定义前后是否一致？
- 衍生变量（差值、变化率、分类化）的计算是否交代？

## 3. 统计方法

- 所用检验/模型是否写明名称与版本设定？
- 检验与数据类型/分布/设计（配对、重复测量）是否匹配？
- 多重比较是否说明与校正？涉及哪些终点？
- 缺失值处理、协变量调整、假设检验条件是否交代？
- 软件与显著性阈值是否写明？

## 4. 样本量

- 样本量/功效计算是否报告？参数（效应量、SD、α、power）是否齐全？
- 实际入组/分析样本与计划是否一致？脱落如何交代？
- 各组样本量、分析集（ITT/PP）是否写明？
- 亚组分析的样本量是否足以支撑其结论？

## 5. 结果报告

- 效应量、精确 p 值、CI、自由度、检验统计量是否报告？
- 正文数字与表/图是否一致？百分比、合计是否自洽？
- 结论措辞（显著性、因果、外推）是否超出结果？
- 阴性/不显著结果是否如实报告？终点是否被调换？
- 图表是否完整自明（标题、单位、误差棒说明）？
