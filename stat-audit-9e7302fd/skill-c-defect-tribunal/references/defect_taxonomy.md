# 缺陷四分类与待复核：操作化判定规则

本文件定义裁决庭使用的缺陷类别体系。定性的目标是**正确**，不是严厉：类别答错
（把"没报告"当成"做错了"，或把真正的内部矛盾降级为"建议"）比漏报更损害审查价值。

## 类别总览

| 类别 | 一句话定义 | 判定核心 |
|---|---|---|
| 事实错误 | 原文陈述与原文自身证据/方法学事实冲突 | 有**原文内部证据**证明"做了且做错" |
| 证据不足 | 主张的强度超出所给证据能支撑的范围 | 证据在，但撑不住措辞 |
| 规范问题 | 违反报告/方法规范，但无证据证明结果因此错误 | 报告不完整、不规范 |
| 建议 | 可改进但不构成缺陷 | 无规范依据、无后果 |
| 待复核 | 现有材料无法确认是否构成缺陷 | 缺材料，写明缺什么 |

## 1. 事实错误

**定义**：原文的某条陈述与原文自身的证据（数据表、图、方法描述、统计量）或公认方法学
事实相冲突，即"作者做了，且做错了/说错了"。

**典型情形**：

- 数据内部矛盾：正文数字与表格数字不一致；百分比合计≠100%；均值落在所报范围之外。
- 检验与数据类型不匹配：对明显偏态/等级数据使用仅限正态连续数据的参数检验，
  **且原文写明用了该检验**；对配对数据用独立样本检验且原文写明设计为配对。
- 结论与自身结果相反：文字称"显著高于"，其自身表格显示更低或 p 不显著。
- 显著性声称与自身 p 值/CI 冲突：CI 跨 0（或 1）仍称"显著"。

**举证要求**：定事实错误**必须**在裁决记录中填 `internal_evidence`，逐字引用与指控
相冲突的原文证据（含位置）。没有内部证据的"做错"指控一律不得定事实错误。

## 2. 证据不足

**定义**：主张本身可能成立，但原文给出的证据不足以支撑其强度。不是"做错了"，而是
"说多了"。

**典型情形**：

- 因果措辞出自相关/观察性设计："X 导致/改善/降低 Y"出自横断面或无对照设计。
- 无 CI/精确 p 的效应断言，却给出强方向性强结论（注意：仅"未报告精确 p"本身是
  规范问题；只有当**结论措辞依赖该不确定度信息**时才升级为证据不足）。
- 小样本探索性分析被当作确证性结论陈述。
- 亚组/事后分析结果被提升为主要结论。

**与事实错误的边界**：证据不足时，原文证据与主张**方向一致但力度不够**；事实错误时，
原文证据与主张**冲突**。方向一致 → 不是事实错误。

## 3. 规范问题

**定义**：违反报告规范（如 CONSORT/STROBE 类条目）或方法学披露惯例，但现有材料
不能证明结果因此错误。**"未报告"的默认归宿是这里。**

**典型情形**：

- 未报告随机化方法/分配隐藏（但也没有证据表明未随机）。
- 未报告所用统计检验名称、自由度、精确 p 值、效应量。
- 未做多重比较说明；切点/分组依据未说明。
- 样本量/功效计算参数未完整披露。

**与事实错误的边界**：未报告 ≠ 做错。"未写明用了什么检验"是规范问题；"写明用了
t 检验而数据为等级资料"才是事实错误。消歧见下。

## 4. 建议

**定义**：不改变结论可信度、不违反强制性规范的改进空间。

**典型情形**：图形可加误差棒（而不确定度数据正文已给出）；术语可统一；表格排版可
改善；可补充敏感性分析作为加分项。

**底线测试**：若拒绝采纳该建议，论文的任何结论或规范合规性会受损吗？不会 → 建议。

## 5. 待复核

**定义**：根据现有材料无法确认是否构成缺陷。绝不是垃圾桶类别。

**使用条件**：必须写 `missing_material`——缺什么材料、取得后如何判定。例：
"声称 power=80% 但未给效应量与标准差假设，需功效计算参数或补充材料方可复核"。

## 关键消歧规则（裁决时逐条核对）

1. **未报告 ≠ 做错**：证据只到"原文没写"为止 → 规范问题（或建议），不得定事实错误。
2. **做了但做错 → 事实错误**：必须同时满足 (a) 原文表明做了该操作，(b) 原文内部证据
   表明该操作/陈述是错的，(c) `internal_evidence` 逐字引用该证据。
3. **方向一致但拔高 → 证据不足**；**方向冲突 → 事实错误**。
4. **无法确认 → 待复核**：缺材料、文本损坏、需外部事实核验而本技能不做外部检索时，
   一律 待复核 + `missing_material`，禁止猜测式定性。
5. **一事一定性**：同一缺陷取**最高可成立**的类别；但升级必须经辩护四问失败方可成立
   （见 adjudication_protocol.md）。
