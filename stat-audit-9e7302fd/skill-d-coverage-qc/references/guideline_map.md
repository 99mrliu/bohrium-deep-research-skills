# 设计类型识别与默认适用表(guideline_map)

第 3 步工作流程用:先识别研究设计类型,再决定哪些清单项默认适用、哪些默认
"不适用"。默认表只是起点;凡实际研究涉及某环节(如观察性研究做了倾向评分
匹配),应把对应条目改回"适用"并正常裁决。

## 一、设计类型识别线索

| 设计类型 | 识别线索(关键词/结构) | 对应报告规范 |
|----------|------------------------|--------------|
| RCT | "随机""随机分为""randomized";干预+对照+随机分配 | CONSORT |
| 队列研究 | "队列""随访""暴露组/非暴露组""cohort";由暴露看向结局 | STROBE(cohort) |
| 病例对照 | "病例组/对照组""按是否患病分组""case-control";由结局回看暴露 | STROBE(case-control) |
| 横断面 | "横断面""现况调查""患病率""cross-sectional";单时点测量 | STROBE(cross-sectional) |
| 诊断准确性 | "敏感度/特异度""ROC""金标准""诊断试验" | STARD |
| 其他 | 无法归入以上(定性、生态学研究、综述等) | 视情形 |

## 二、默认不适用矩阵(✕ = 默认不适用,须写一句理由;其余默认适用)

| 清单项 | RCT | 队列 | 病例对照 | 横断面 | 诊断准确性 |

| D-03 随机序列 | | ✕ | ✕ | ✕ | ✕ |
| D-04 分配隐藏 | | ✕ | ✕ | ✕ | ✕ |
| D-05 盲法实施 | | | | | |

| D-09 随访与失访 | | | ✕ | ✕ | |
| N-08 EPV 要求 | ✕(除非回归模型) | | | | ✕ |
| N-10 中止规则 | | ✕ | ✕ | ✕ | ✕ |
| R-06 研究注册 | | | | | |

说明:
- 留空 = 默认适用。即使默认适用,遇到具体研究确无此环节时仍可判"不适用",
  但理由必须具体(例:"本研究为单臂描述性研究,无对照组,故 D-06 不适用")。
- 诊断准确性研究:统计面重点移至 S-01/S-02(敏感度/特异度须带 CI),
  S-03、S-04 视分析而定。
- 识别为"其他"时:五个检查面全部保留,逐项判断适用性,并在审查单
  完备性声明中说明归类依据。
