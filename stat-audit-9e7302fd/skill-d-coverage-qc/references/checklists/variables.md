# 检查面清单:variables(变量与测量)

本清单为变量定义与测量面的底集检查项,由 CONSORT / STROBE 的变量报告要点自行提炼
改写。每项含稳定 ID、一句检查问题、映射的审查面。

| ID | 检查问题 | 映射审查面 |
|----|----------|------------|
| V-01 | 主要结局指标是否唯一、预先定义且可测量? | 方法设计, 统计报告 |
| V-02 | 次要结局是否与研究问题对应,而非堆砌? | 方法设计 |
| V-03 | 各变量的测量工具、来源与信效度依据是否说明? | 方法设计, 事实核验 |
| V-04 | 基线特征是否分组报告,数值是否可与正文/表格互核? | 事实核验, 统计报告 |
| V-05 | 缺失数据的比例、模式与处理方法是否报告? | 统计报告, 学术规范 |
| V-06 | 连续变量分组切点是否有预设依据或文献来源? | 方法设计, 引用支持 |
| V-07 | 结局评估者是否独立于分组/暴露信息? | 方法设计 |
| V-08 | 复合结局的各组分是否分别交代定义与结果? | 统计报告, 学术规范 |
| V-09 | 关键变量的定义是否与所引用来源中的定义一致? | 引用支持, 事实核验 |
| V-10 | 代理指标与目标构念之间的效度关系是否有论证? | 论证链 |
| V-11 | 测量时点是否明确,且各组测量时点一致? | 方法设计, 事实核验 |
| V-12 | 亚组划分变量是否预设,而非事后挑选? | 学术规范, 统计报告 |

使用规则:同 design.md(五态裁决、不适用须一句理由、清单外发现记 X-新发现-N)。
