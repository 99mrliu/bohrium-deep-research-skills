# 检查面清单:design(研究设计)

本清单为研究设计面(check facet = design)的底集检查项,由 CONSORT / STROBE / SAMPL
的方法学要点自行提炼改写(非原文摘抄)。每项含稳定 ID、一句检查问题、映射的审查面
(六面之一或多面,见 ../coverage_matrix.md)。

| ID | 检查问题 | 映射审查面 |
|----|----------|------------|
| D-01 | 研究设计类型是否在方法部分明确声明,且与实际执行一致? | 方法设计 |
| D-02 | 研究问题或假设是否在设计层面预先、具体地给出? | 方法设计, 论证链 |
| D-03 | 随机化序列的产生方法(如区组、分层、随机数字表)是否具体描述? | 方法设计 |
| D-04 | 分配隐藏机制(谁入组、如何遮蔽分配序列)是否说明? | 方法设计 |
| D-05 | 盲法的对象(受试者/施测者/评估者)与实施方式是否明确? | 方法设计 |
| D-06 | 对照组的类型与设置是否与研究问题匹配? | 方法设计, 论证链 |
| D-07 | 纳入与排除标准是否具体到可独立复现执行? | 方法设计, 学术规范 |
| D-08 | 暴露或干预的定义是否操作化(剂量、时长、执行者)? | 方法设计 |
| D-09 | 随访时长、随访节点与失访处理规则是否预先设定? | 方法设计, 统计报告 |
| D-10 | 已知混杂因素的识别与控制策略(配对/分层/调整)是否说明? | 方法设计, 论证链 |
| D-11 | 研究场景、纳入时间范围是否交代,足以判断外推性? | 方法设计, 学术规范 |
| D-12 | 设计所能支持的因果强度与结论声称的因果强度是否匹配? | 论证链 |

使用规则:
- 每条必须落入五态之一(通过/问题/待复核/不适用/未检查),不允许跳过不记。
- 判"不适用"须写一句理由(如"横断面研究无随机化环节")。
- 清单外发现另记为 X-新发现-N,不占本表 ID。
