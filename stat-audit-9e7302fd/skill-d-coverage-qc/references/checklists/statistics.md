# 检查面清单:statistics(统计分析)

本清单为统计分析与统计报告面的底集检查项,由 SAMPL 及 CONSORT/STROBE 统计条目
要点自行提炼改写。每项含稳定 ID、一句检查问题、映射的审查面。

| ID | 检查问题 | 映射审查面 |
|----|----------|------------|
| S-01 | 主要分析的统计方法是否与数据类型及分布特征匹配? | 统计报告 |
| S-02 | 是否报告效应量与置信区间,而非仅报告 P 值? | 统计报告 |
| S-03 | 检验前提(正态性、方差齐性等)是否被核查或说明? | 统计报告, 方法设计 |
| S-04 | 多重比较是否做了校正,或明确说明未校正的理由? | 统计报告, 学术规范 |
| S-05 | 正文报告的统计数值与表格/图形中的数值是否一致? | 事实核验 |
| S-06 | P 值是否尽量精确报告(而非仅写 <0.05 或 NS)? | 统计报告 |
| S-07 | 模型中协变量的选择是否有临床/理论依据而非数据驱动? | 方法设计, 统计报告 |
| S-08 | 分析集(ITT / 符合方案集)是否明确定义并一致执行? | 统计报告, 方法设计 |
| S-09 | 原始数据或分析代码的可得性是否有明确声明? | 学术规范, 事实核验 |
| S-10 | 统计软件名称与版本是否注明? | 学术规范, 统计报告 |
| S-11 | 主要统计结果的数量级是否可由文中数据复算核实? | 事实核验 |
| S-12 | 阴性结果是否按预设假设解释,而非事后编造机制? | 论证链, 学术规范 |
| S-13 | 相关性与因果性的语言使用是否严格区分? | 论证链 |
| S-14 | 是否进行了敏感性分析并报告其结果? | 统计报告, 论证链 |

使用规则:同 design.md。数值复算非本套件重心:S-05/S-11 只需核对文中自洽性,
无法复算时判"待复核"并写明缺少什么。
