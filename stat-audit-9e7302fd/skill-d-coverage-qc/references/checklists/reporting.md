# 检查面清单:reporting(报告规范与学术规范)

本清单为报告规范与学术规范面的底集检查项,由 CONSORT/STROBE 报告条目及出版伦理
通行要求自行提炼改写。每项含稳定 ID、一句检查问题、映射的审查面。

| ID | 检查问题 | 映射审查面 |
|----|----------|------------|
| R-01 | 是否声明遵循对应报告规范(CONSORT/STROBE/STARD 等)? | 学术规范 |
| R-02 | 抽查引用:被引文献是否真实支持正文对应论断? | 引用支持 |
| R-03 | 图表是否自明(标题、单位、例数),且与正文叙述一致? | 统计报告, 事实核验 |
| R-04 | 利益冲突声明是否完整覆盖全体作者? | 学术规范 |
| R-05 | 伦理审批与知情同意是否报告(批件号/豁免理由)? | 学术规范 |
| R-06 | 研究注册信息(注册号、平台)是否提供且可核对? | 学术规范, 事实核验 |
| R-07 | 局限性讨论是否覆盖主要偏倚来源,而非泛泛而谈? | 论证链, 学术规范 |
| R-08 | 结论是否超出结果数据所能支持的范围? | 论证链 |
| R-09 | 摘要中的结论与正文结果是否一致(方向、量级、措辞)? | 事实核验, 论证链 |
| R-10 | 资助来源及资助方在研究中的角色是否说明? | 学术规范 |
| R-11 | 术语与缩写是否在首次出现时定义? | 学术规范 |
| R-12 | 数据共享声明是否具体(获取途径、条件),而非口号? | 学术规范, 事实核验 |

使用规则:同 design.md。引用抽查(R-02)只针对文中可获得的引文信息;无法取得
被引原文时判"待复核"并注明,不得臆断为通过或问题。
