# 检查面清单:sample_size(样本量与功效)

本清单为样本量与统计功效面的底集检查项,由 CONSORT/STROBE 样本量条目要点自行
提炼改写。每项含稳定 ID、一句检查问题、映射的审查面。

| ID | 检查问题 | 映射审查面 |
|----|----------|------------|
| N-01 | 是否报告了样本量估算或功效计算? | 方法设计, 统计报告 |
| N-02 | 估算所用参数(预期效应量、α、power、方差)是否有来源? | 引用支持, 统计报告 |
| N-03 | 实际入组样本量是否达到计划值;未达到时是否解释并讨论影响? | 统计报告, 论证链 |
| N-04 | 预期流失/脱落率是否纳入样本量估算? | 方法设计 |
| N-05 | 各组样本量在摘要、正文、表格、流程图各处是否一致? | 事实核验 |
| N-06 | 排除/剔除病例的数量与理由是否以流程化方式报告? | 统计报告, 学术规范 |
| N-07 | 小样本研究的结论是否伴随功效不足的谨慎表述? | 论证链 |
| N-08 | 事件数是否满足模型变量数要求(如 EPV≥10)? | 统计报告, 方法设计 |
| N-09 | 是否以方便样本却直接作总体层面的推断? | 论证链, 学术规范 |
| N-10 | 中途中止或扩展样本量的规则是否预先设定? | 方法设计, 学术规范 |

使用规则:同 design.md。判"不适用"示例:"描述性横断面调查且不做假设检验时
N-02 可不适用",仍需一句理由。
