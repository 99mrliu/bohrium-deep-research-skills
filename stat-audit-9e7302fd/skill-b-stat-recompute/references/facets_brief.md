# 非数值五面审查清单（facets_brief.md）

数值重算由脚本完成；本清单指导模型做**非数值**的定性审查。
每条发现必须给出定位：章节 + 表号/图号（如有）+ 原句摘录。
无法核实的标「待复核」，不得臆造。

## 面 1　研究设计
- [ ] 研究类型（RCT/队列/病例对照/横断面）是否明示且与实际做法一致？
- [ ] 随机化方法、分配隐藏、盲法是否描述（RCT 必需）？
- [ ] 对照组设置是否合理；是否存在明显混杂未处理？
- [ ] 主要结局是否事先指定；有无疑似事后改换主要结局/主要终点？

## 面 2　变量定义
- [ ] 暴露、结局、协变量是否给出可复现的操作性定义？
- [ ] 测量工具、临界值、时间点是否写明？
- [ ] 同一变量前后定义是否一致（如“应答”标准在方法与结果中是否相同）？

## 面 3　统计方法
- [ ] 所用检验与数据类型/分布假设是否匹配（正态、方差齐、配对/独立）？
- [ ] 多重比较是否校正（多个结局、亚组、期中分析）？
- [ ] 缺失值处理方法是否说明？
- [ ] 统计软件与版本是否注明？
- [ ] 混合模型/贝叶斯/复杂生存分析等超出脚本范围者：仅核对
      “方法描述是否完整、报告是否规范”，数值一律标待复核。

## 面 4　样本量
- [ ] 是否有事前样本量/把握度计算；四要素（α、power、效应量、n）是否齐全？
- [ ] 实际入组 n 与计划 n 是否一致；脱落率是否交代？
- [ ] 各表格/正文中的 n 是否前后一致？

## 面 5　结果报告
- [ ] 统计量是否带自由度与精确 p 值（而非仅 p<.05 / “NS”）？
- [ ] 效应量与 95%CI 是否随主要结局一并报告？
- [ ] 图表与正文数字是否一致；表内合计是否等于各分项之和（可指给脚本复核）？
- [ ] 绝对效应与相对效应是否同时给出（仅有相对数易夸大）？
- [ ] 阴性结果是否如实报告，有无“趋势显著”式措辞美化？

## 输出约定
- 发现条目字段：章节定位 / 原句 / 缺陷类型（事实错误·证据不足·规范问题·建议）/
  严重度 / 依据 / 修改建议。
- 与数值相关的发现以 `findings.jsonl` 为准，本清单发现与之合并进
  `audit_sheet.md`，冲突时按 SKILL.md「注意事项」处理。
