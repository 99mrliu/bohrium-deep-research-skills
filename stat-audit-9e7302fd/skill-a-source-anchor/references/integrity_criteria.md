# 提取保真度判定标准(Integrity Criteria)

本文档给出 `scripts/source_integrity.py` 的判定阈值与理由。
**阈值常量必须与脚本顶部常量逐一一致;修改任何一侧必须同步另一侧。**

## 1. 阈值表(与脚本常量一一对应)

| 常量 | 取值 | 含义 | 触发后果 |
|---|---|---|---|
| MIN_TOTAL_CHARS | 1500 | 全文最少字符数 | 低于 → failed |
| MAX_GARBLE_RATIO | 0.001 | U+FFFD 替换字符占比上限 | 超过 → failed |
| WARN_GARBLE_RATIO | 0.0002 | 乱码占比告警线 | 超过(未达 failed)→ degraded |
| MAX_EMPTY_PAGE_RATIO | 0.30 | 空页占比上限(页数 ≥2 时判定) | 超过 → failed |
| EMPTY_PAGE_MIN_CHARS | 5 | 页内非空白字符少于此数即判空页 | (构成空页计数) |
| LONG_LINE_LEN | 400 | 单行超长阈值 | (构成超长行计数) |
| MAX_LONG_LINE_RATIO | 0.05 | 超长行占比上限 | 超过 → degraded |
| MIN_MEAN_LINE_LEN | 8 | 平均行长下限 | 低于 → degraded |
| MAX_MEAN_LINE_LEN | 300 | 平均行长上限 | 高于 → degraded |
| MIN_CJK_LATIN_RATIO | 0.30 | (汉字+拉丁字母)占总字符比例下限 | 低于 → failed |

判定优先级:存在任一 failed 原因 → `failed`;否则存在任一告警 → `degraded`;
否则 `ok`。脚本在 `failed` 时以退出码 1 结束(门是真实的),
`ok`/`degraded` 退出码 0,输入/运行错误退出码 2。

## 2. 阈值理由

- **MIN_TOTAL_CHARS = 1500**:一篇含方法+结果的论文正文(即使短篇)通常远超
  1500 字符;低于此值几乎必然只提取到首页、摘要或元数据。此时继续审查等于
  只凭摘要下结论,必须走材料不足分支。
- **乱码率 0.001 / 0.0002**:U+FFFD 是 UTF-8 解码失败的替换字符,出现即意味着
  原文字节流损坏或编码误判。千分之一的文本损坏足以毁掉一条数字引用
  (例如把标准差变成乱码),故 failed 线设在 0.1%;万分之一量级告警,
  要求涉及段落逐字复核。
- **空页占比 0.30**:扫描件未 OCR 的典型形态是整页为空(只有页眉页脚字符,
  故空页阈值取非空白字符 < 5 而非 0)。三成以上页面为空说明主体内容丢失;
  少量空页多为纯图/表页,降级为 degraded 并要求回查原件。
- **行长指标**:pdftotext -layout 的正常输出平均行长在 20–80 字符区间。
  平均行长 < 8 提示竖排/双栏被逐字切碎;> 300 或超长行占比 > 5% 提示换行
  结构丢失(整段粘成一行),此时"行号"锚点精度大打折扣,故降级。
- **MIN_CJK_LATIN_RATIO = 0.30**:正常论文文本中汉字与拉丁字母合计占比远高于
  30%;低于此值说明大部分"字符"是控制符、图片占位或二进制泄漏——典型为
  图像型 PDF 被强行按文本解码。

## 3. 判定后的处置

- **ok**:进入五面审查,正常走锚定门。
- **degraded**:可审查,但须:① 在审查单中披露受损指标;② 涉及受损页/段的
  发现,quote 核验失败时优先怀疑提取失真,回查原件后重提取重摘录;
  ③ 在 uncertainty 中说明提取质量对结论覆盖面的影响。
- **failed**:**材料不足分支**——不得产出任何实质审查发现。
  result.json 置 `status="failed"`,在 uncertainty 中如实说明失败原因
  (引用 fail_reasons),sources 仅列出已尝试的提取途径。

## 4. OCR 失败 / 扫描件应对 playbook

1. **识别信号**:failed 原因中出现"可识别文字占比过低"或"空页占比过高",
  基本可判定为图像型 PDF / OCR 失败。
2. **换工具重试**:优先尝试带 OCR 的提取途径(如 pdf-text-tool 的 OCR 模式,
  或 pdftoppm + tesseract chi_sim/eng)。重试后重新跑 source_integrity。
3. **OCR 后仍 degraded**:OCR 文本常见字形混淆(0/O、1/l、± 丢失)。
  此情形下:quote 选取避开易混淆字符密集句;数字类发现一律标注
  "OCR 文本,数值建议对照原件图复核";必要时整发现降级为「待复核」。
4. **多途径均失败**:按第 3 节 failed 处置,诚实交付,绝不编造。
5. **留痕**:无论成败,在审查单完备性声明中记录尝试过的提取途径及各自
  的 integrity verdict。
