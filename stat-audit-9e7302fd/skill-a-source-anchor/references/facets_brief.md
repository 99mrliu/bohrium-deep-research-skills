# 五面审查问题清单(Facets Brief)

本清单保证在锚定取证之外,审查仍覆盖研究方法与统计的五个基本面。
每条由此产生的发现**同样必须通过锚定门**(quote + 三级锚点),无例外。
本技能只做轻量一致性提示,数值重算非重心;发现分类限
事实错误 / 证据不足 / 规范问题 / 建议,无法证实者标「待复核」。

## 1. 研究设计
- 研究类型(随机对照/准实验/队列/横断面)是否明确声明?声明与设计特征是否一致?
- 是否有对照组?组间可比性如何论证?
- 随机化、分配隐藏、盲法是否报告?未报告即「证据不足」而非"未做"。
- 是否预注册或有方案可查?(仅提示,不外部检索。)

## 2. 变量定义
- 主要/次要结局是否明确定义(测量时点、工具、单位)?
- 暴露/干预的定义是否可操作(剂量、频次、周期)?
- 纳入/排除标准是否具体、无循环定义?
- 混杂因素如何识别与控制?

## 3. 统计方法
- 每类数据对应的检验方法是否点名(如 t 检验/卡方/秩和/回归)?
- 检验前提(正态性、方差齐性)是否说明?
- 单/双侧、显著性水平、多重比较校正是否交代?
- 统计软件与版本是否报告?
- 轻量一致性提示:P 值与"差异有/无统计学意义"的文字结论是否自洽;
  效应量与区间是否同向(只做符号/量级层面核对,不重新计算)。

## 4. 样本量
- 是否报告样本量估算(检验效能、α、预期效应量、脱落率)?
- 未估算是否说明理由?"根据可及病例数确定"属规范问题,需如实锚定原文。
- 实际纳入数、脱落数、分析数是否一致( CONSORT 式流向)?
- 分组例数合计是否等于总例数(轻量加总核对)。

## 5. 结果报告
- 主要结局是否报告效应量、精确 P 值与置信区间,而非仅"P<0.05"?
- 文中数值与表/图数值是否一致(轻量一致性提示)?
- 结论是否超出数据支持范围(相关→因果、亚组→总体)?
- 局限性是否如实报告?

## 使用纪律
- 五面逐条过,无发现的面向在审查单中注明"经审查未见异常",不要留白;
- 任何一面产生候选发现 → 立即复制 quote → 送锚定门;
- 时间/预算紧张时优先保证:主要结局相关的 3、5 两面,其余如实标注"因预算未覆盖"。
