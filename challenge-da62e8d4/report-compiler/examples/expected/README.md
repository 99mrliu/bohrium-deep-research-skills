# expected/ —— 合成示例（synthetic），非正式案例结果

本目录是 `run_example.sh <输出目录> --svg` 在 `examples/ledgers/` 上的**预期产物副本**，
用于肉眼比对与回归校验：

- `report.md`：编译器以纯标准库 SVG 渲染（`--svg`）生成的报告全文；
- `audit.json`：审计器对该报告与台账对账的 PASS 结果。

说明：
- 编译输出是确定的（无时间戳、无随机性），同一台账重跑应逐字节一致；
- 若使用默认渲染器且环境有 matplotlib，报告头部“渲染器”行与图文件扩展名
  （.png 而非 .svg）会与副本不同，属预期差异，数字内容必须一致；
- 本目录刻意只放文本产物（.md/.json），图文件请在自测输出目录中查看。
