# 证据规则：论文目标值的最低可采信标准

本文件约束哪些证据可以进入 `targets.json`。规则的目的不是“尽量多收数值”，而是防止把模型记忆、二手资料或视觉估读误当作论文报告值。

## 1. 逐字引文的最小充分长度

- 引文必须是从指定 PDF 物理页文本层逐字复制的连续片段，不接受复述、翻译或拼接。
- 至少包含目标数值、指标/参数名称和足够的限定语；通常一整句最稳妥。
- 如果表格数值没有完整句子，可取该表的**整行**作为引文，并同时保留表题或列名所在文本作为定位依据。
- 引文应长到能避免同页多个相同数值造成歧义；但不要跨页拼接。
- 不要把引文先改成“更通顺”的版本。大小写、符号、单位和数量级都必须按原文复制；归一化只用于机器匹配，不改变证据原文。

## 2. 数值口径不得混用

- 均值、中位数、单次运行值、最好值、最终值、验证集值、测试集值必须分别登记，不能互相替代。
- 标准差、标准误、置信区间和样本量不是指标本体；如需比较，应作为独立字段或独立目标。
- 百分比与小数不能 silently 互转：`72.1%` 与 `0.721` 只有在论文明确同义且任务要求换算时，才可另建“换算值”，原字面值仍须保留。
- 四舍五入后的“看起来像”不等于同一报告值。`0.152` 不能自动替代 `0.1517`。
- 图中估读值不能当表值；只有论文文字或表格明确给出的数值才能作为论文目标值。

## 3. 页码与文件定位

- `page` 一律是物理 PDF 页，从 1 开始；不是论文页脚编号，也不是阅读器显示的其他偏移。
- 如果同一 PDF 内含封面、附录或补充材料，物理页仍连续计数。
- 最终 `result.json` 应同时给出 PDF 文件路径/哈希、物理页、逐字引文；仅给 DOI 或论文标题不充分。
- 发现 `page_mismatch` 时，可以把声明页改成 `gate.py` 找到的实际页并重新过门；修正动作必须进入变更记录。

## 4. 常见臆造模式清单

1. **把 SOTA 当别人报告值。** 论文说“X 是 SOTA”，不等于 X 的数值就是本文方法的结果。
2. **把图中估读当表值。** 坐标轴上的约数、肉眼读数或像素测量不能充当论文报告值。
3. **四舍五入后的“看起来像”。** 把摘要中的 `0.15` 当正文表格的 `0.152`，或反向补零。
4. **跨表格/跨数据集拼接。** 引文来自 A 数据集，指标名却写成 B 数据集。
5. **均值、中位数和单次结果混用。** 尤其代码只输出单次运行时，不得与中位数目标直接比较。
6. **把合成代码输出当作者原始结果。** 组织方代码或合成数据只支持方法级自检，不支持论文数值复现声明。
7. **页码凭印象填写。** 物理页错就是未过门；找到正确页后必须重跑证据门。
8. **二手来源倒灌。** 排行榜、博客、综述或 README 中的数值不能直接当作该论文报告值。
9. **单位丢失或缩放。** ms/s、MB/MiB、百分比/小数、绝对误差/相对误差必须原样登记。
10. **静默删除失败证据。** 查不到的引文必须保留在隔离清单，并说明它未参与比较。

## 5. 最低放行条件

一个目标值只有同时满足以下条件才可进入比较：

- `quote` 归一化后是指定物理页文本归一化后的子串；
- `value` 字面出现在 `quote` 内（允许去千分位逗号）；
- 指标口径、单位、数据集/拆分和统计方式已由人工核对；
- 未通过项没有被静默删除，而是进入隔离与不确定性记录。
