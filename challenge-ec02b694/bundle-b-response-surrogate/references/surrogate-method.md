# surrogate-method.md — 代理模型方法的数学依据与局限

本文是 `scripts/fit_surrogate.py` 与 `scripts/predict.py` 的方法学依据。
目标读者：使用本技能的 Agent 与审阅产物的人。

## 1. 编码变量（coded variables）

每个因子 x_j 按训练数据的 [min, max] 线性映射到 [-1, 1]：

```
coded = 2 * (x - mid) / (max - min),  mid = (max + min) / 2
```

理由：编码后各因子量纲一致，系数大小可直接比较效应强弱；正规方程的条件数也更好。
代价：编码依赖训练 min/max，因此**有效域盒与编码规则必须随 surrogate.json 一起保存**
（本技能已这么做）；新数据扩大范围后必须重新编码、重新拟合。
退化维（max == min）编码置 0，其效应不可识别，脚本会给出 warning。

## 2. 线性 / 完全二次 RSM 与 OLS

k 个编码因子上的完全二次模型含 p = 1 + 2k + k(k-1)/2 个参数
（截距、k 个一次项、k 个纯二次项、k(k-1)/2 个交互项）。
k=2 时 p=6，k=3 时 p=10。

估计用普通最小二乘：解正规方程 (FᵀF)β = Fᵀy。实现为高斯消元（部分主元），
主元 < 1e-12 判定奇异。对 n ≤ 数十、p ≤ 10 的小规模问题数值上足够；
大规模或病态问题应使用 QR/SVD（标准库之外，本技能刻意不做）。

**为什么要求 n ≥ p + 2**：p 个参数占去 p 个自由度，至少还需 1 个自由度估计误差
方差 σ²，再留 1 个余量避免 σ² 由单点决定。n < p + 2 时拟合不是"差一点"，
而是区间估计根本不可构造——所以脚本**拒绝拟合**而不是给出无不确定度的预测。
降级路径（均值/最近邻 + 放大区间）是诚实的"我不知道"，不是折中解。

**奇异的常见原因**：因子共线（如温度与升温速率完全锁步）、常数因子、
重复点占满设计。奇异时脚本拒绝拟合并说明原因，调用方应检查实验设计而非换工具硬解。

## 3. R² 与 LOO-CV RMSE

- R² = 1 − SS_res/SS_tot：训练集内拟合优度。**小样本高 R² 经常为过拟合假象**，
  尤其 n 接近 p 时；本技能要求 n ≥ p+2 只是下限，n < 2p 时 R² 不可信。
- LOO-CV RMSE：留一交叉验证的均方根误差。实现为逐点重拟合
  （某折奇异时该折退化为均值预测并计数）。它估计的是**对未见点的预测误差量级**，
  比 R² 诚实。局限：小样本下方差大、对有强相关的空间设计偏乐观；
  只能作量级参考，不能当作精度承诺。
- 判读经验法则：LOO-RMSE 远大于指标注册表中的 acceptable_fluctuation 时，
  模型精度不足以区分"可接受波动"与"真实改进"，结论必须保守。

## 4. 预测区间

域内候选点 x₀ 的 95% 预测区间：

```
ŷ ± t(0.975, df) · sqrt( σ̂² · (1 + f₀ᵀ(FᵀF)⁻¹f₀) )
```

其中 f₀ 是 x₀ 的特征向量，f₀ᵀ(FᵀF)⁻¹f₀ 是杠杆值（leverage），
df = n − p，t 取 95% 双侧分位数（内置 t 表，df > 120 用 1.96 近似）。
这是**预测区间**（含新观测噪声），不是均值的置信区间——用于"下一次实验
会测到什么"才是正确口径。
若 (FᵀF)⁻¹ 不可得，用 σ̂²(1 + 1/n) 近似并显式标记偏窄。

## 5. 外推规则

有效域定义为训练点各维 min/max 的轴对齐盒。候选点任一维越界即
`extrapolation = true`，区间乘以 (1 + 3 × 相对越界距离)
（相对越界距离 = 越界量 / 该维训练跨度，取各维最大），并附加固定措辞：
"该预测为待确认假设，不得作为可执行事实"。

依据与局限：

- 多项式在域外发散无界，二次模型域外的曲率方向没有数据支持；
  杠杆值 f₀ᵀ(FᵀF)⁻¹f₀ 在域外快速增长（合成示例中域外点 leverage ≈ 13.7，
  而域内典型值 < 1），放大的区间主要正是来自这一项——放大系数 3 是
  保守的启发式，不是理论常数；
- 轴对齐盒**不能识别盒内空洞**：盒内无数据的角落同样不可信，
  杠杆值大是唯一线索，调用方应同时检查 leverage；
- 降级模式（fallback）下不存在可外推的模型，故**所有**预测强制
  extrapolation 级警告，区间（max(3σ, 半极差)）只是探索性尺度，
  不具统计覆盖率含义。

## 6. 总局限声明

RSM 是训练数据邻域内的局部二阶近似；它不能替代实测、不提供机理、
不承诺全局最优。任何写进实验计划的模型预测都必须携带区间并标注来源，
任何外推/降级预测都必须先经实验确认。
