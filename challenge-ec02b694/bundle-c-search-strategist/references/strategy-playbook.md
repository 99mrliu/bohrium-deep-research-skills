# 搜索策略手册：网格 / 筛选 / 局部加密 / 贝叶斯优化的适用条件

本手册是 `plan_search.py` 内置决策表的展开论证。决策表（按顺序应用）：

| 规则 | 条件 | 策略 | 一句话理由 |
|---|---|---|---|
| 1 | budget ≤ 0 | `none` | 没有预算就没有搜索，登记历史点即可 |
| 2 | 可行组合总数 ≤ budget | `full_grid` | 穷举 affordable 时任何抽样都是次优 |
| 3 | 0 < budget < 4 | `screening_only` | 预算撑不起"筛选+加密+确认"三阶段，全部用于覆盖空间 |
| 4 | 其他 | `staged_sequential` | 空间覆盖 → 局部收敛 → 噪声确认 |

## 各策略的适用条件

### 全网格（full grid）

- **适用**：组合总数 ≤ 预算；响应面形状未知且不希望漏掉任何离散组合；评估成本低、可并行。
- **优点**：无抽样偏差，最优解有保证（在网格分辨率内），结果天然可复核。
- **缺点**：组合爆炸（d 维各 k 水平 → k^d）；本例 3 参数 21×11×26 = 6006 组合对 10 点预算完全不可行。
- **失效**：组合数略超预算时仍硬跑网格 ⇒ 预算中途耗尽且无停止判据——决策表规则 2 用"≤ budget"硬门槛避免。

### 种子化拉丁超立方筛选（screening LHS）

- **适用**：预算只够覆盖空间的一小部分（典型 30–50%），目标是找到"有希望的区域"而非直接定位最优；各参数边缘分层（每维每层恰一个点）保证一维投影均匀。
- **本技能的实现**：`random.Random(seed)` 驱动每层置换 + 层内均匀偏移，吸附到 step 网格并确定性去重。**给定 (参数空间, n, seed)，候选点逐字节确定**——这是可复核性的根基。
- **优点**：比纯随机更均匀地覆盖边缘；比网格省点；种子化后完全可复现。
- **缺点/失效**：点少时可能漏掉窄最优区；吸附网格后分层性略退化；对强交互项无能为力（筛选轮本来就不负责收敛）。

### 局部加密（local refinement，坐标式有限差分步进）

- **适用**：筛选已给出可靠的最优点；响应面在最优点邻域近似平滑单峰；剩余预算只够小步移动。
- **本技能的实现**：固定维度顺序、每维先 −step 后 +step、越界裁剪、剔除已评估点；候选全重复时回退到距最优点最近的未访问网格点（确定性扩展扫描）。步长严格遵守各参数的 `step`，不产生实验设备无法执行的坐标。
- **优点**：零模型假设、每步理由可写成人话（"沿温度 −10°C 因为当前最优在边界内侧"）、确定性。
- **缺点/失效**：对旋转谷地/强交互收敛慢（坐标步进只走轴向）；步长固定不会自适应收缩；峰很窄时 ±step 可能直接跨过峰顶。

### 贝叶斯优化（BO）：本技能为何不用

- **BO 适用**：评估昂贵、预算中等、允许模型假设（GP 先验 + 采集函数）、追求样本效率。
- **本技能不用的两条硬理由**：
  1. **标准库限制**：运行契约要求纯 Python 3 标准库、无网络。GP 需要数值线性代数（核矩阵求逆/ Cholesky），标准库没有，手写既慢又易错；
  2. **可复核性权衡**：BO 的下一步依赖模型内部状态（超参数优化结果、采集函数数值细节），第三方没有同款数值栈就**复现不出同一套建议**——这正是本技能要消灭的失败模式。确定性序贯设计的每一步只依赖（计划 + 结果 CSV + 种子），任何人在任何机器上都能逐字节重放。
- **代价**：样本效率低于 BO；在"评估极贵、预算极小且允许依赖科学计算栈"的场景，应如实说明并建议改用 BO，而不是假装本技能适用。

### 确认性重复（confirmation repeats）

- **适用**：任何声称"找到最优"的搜索——不重复就无法区分"真改进"与"噪声幸运"。
- **规则**：对最终最优点做 ≥2 次同坐标重复；重复点坐标相同但 replicate 编号不同，便于区分系统漂移与纯噪声。
- **失效**：只有 2 次重复时噪声估计自由度极低，只能给量级判断；存在时间漂移时同坐标重复并不独立。

## 预算分配启发式（规则 4）

- 筛选 ≈ 40%（min 2）：保证空间覆盖的下限；
- 确认 = max(2, ≈20%)：噪声估计的下限是 2 次重复；
- 加密 = 剩余全部（≥1）：把预算的大头留给"利用已学信息"的阶段。
- 该比例是显式启发式而非最优分配；改动理由必须写进决策日志（`search_log.py append`）。
